# 小驴雷切（LvSpeed Switch）

[![Version](https://img.shields.io/badge/version-0.32.0-blue)](./plugin.json) [![License: MIT](https://img.shields.io/badge/license-MIT-green)](./LICENSE) [![SiYuan](https://img.shields.io/badge/SiYuan-%E6%80%9D%E6%BA%90%E7%AC%94%E8%AE%B0-ff5c67)](https://b3log.org/siyuan)

小驴雷切是思源笔记的轻量导航工作区：以**已打开页签**为第一优先级，通过实时缩略图完成快速预览和切换；需要时再展开到**收藏夹、全库文档搜索、58 个组件的聚合面板、日记和自定义快捷入口**。桌面弹窗、右侧栏和手机端共享同一套数据与命令，但会根据空间和输入方式采用不同布局。

## 核心能力

### 页签切换与实时刷新

- **实时缩略图**：每个页签以卡片展示当前文档内容；后台未渲染文档按需通过内核 API 补齐，视口外内容延迟渲染。
- **分栏原生支持**：按思源窗口/分栏分组，切换时激活正确分栏；页签打开、关闭或批量变化会通知所有已打开的插件视图立即刷新。
- **键盘与鼠标**：方向键和 `Tab` 按真实网格移动，`Enter` 打开，`Esc` 关闭；卡片支持置顶、收藏、关闭和右键菜单。
- **六种排序**：最近使用、打开顺序、打开倒序、最近编辑、标题升序、标题降序，修改后持久化。
- **统一历史入口**：桌面弹窗、侧栏和手机工具栏共享时钟入口；最近打开与最近关闭分区展示，已关闭文档可点击重新打开，失效记录可单项清理。
- **桌面全屏**：仅桌面弹窗提供全屏切换；侧栏和手机端不显示无效的全屏操作。

### 收藏夹与顺序管理

- 收藏使用稳定的文档 rootID，页签关闭或思源重启后仍可重新打开。
- 收藏夹显示序号和数量，可折叠、重命名、删除、上移和下移；桌面端还支持拖拽收藏夹排序。
- 收藏内容收纳在所属收藏夹内部，显示组内序号，可移动到其他组、组内上移/下移；桌面端支持组内拖拽。
- 手机设置页禁用整行拖拽，避免与上下滚动冲突，使用明确的移动按钮完成相同操作。
- 收藏夹可一键打开或关闭组内页签，并对重复文档、失败项和无需处理的状态分别反馈。

### 分层卡片搜索

搜索结果保持固定优先级：

1. **已打开页签**：本地即时过滤，继续保留窗口分组、置顶、排序和键盘导航。
2. **已打开文档内容**：在最多 6 个已打开根文档内调用思源搜索，命中时仍只恢复已有页签，不新增重复卡片。
3. **全库文档**：先按标题查询；标题无结果或启用高级筛选时，回退到受限原生全文搜索，按根文档聚合为卡片和少量片段。

**页签过滤查询语法**（本地层）：空格分隔多个词 = 全部命中（AND）；`-词` = 排除含该词的页签；`"多词短语"` = 整体匹配。例：`项目 -周报 "会议记录"`。

搜索请求使用 180ms 防抖、容量受限的内存缓存、请求版本校验和取消机制。桌面弹窗、右侧栏和手机端各自持有独立搜索会话，互不取消或覆盖。当前工作树支持笔记本、内容类型、子类型、搜索方式和结果排序筛选；仅笔记本/路径筛选保留标题快路径，其他筛选会直接使用受限的原生块级全文请求。全库结果一次最多拉取 33 条，首屏渲染 12 条，超出时通过面板内「加载更多」按钮纯客户端增量展开（不换缓存 key、不发新请求），全部展开后才回落到思源原生搜索出口。路径树选择仍未开放 UI，且本功能不替代思源原生搜索页。后续计划见 [ROADMAP.md](./ROADMAP.md)。

### 工作上下文、命令与动作（新增）

- **关联内容**：打开切换器即呈现与当前文档相关的反链和提及（内核官方接口，有界投影并标注总量与截断），点击直达目标文档。
- **保存的搜索**：筛选菜单一键保存当前查询与筛选；零词条工作台与筛选菜单均可快速回放，右键可删除。
- **命令模式**：输入 `>` 只列可执行动作（内建动作 + 思源宿主命令），文本过滤后点击执行——切换器即命令面板。
- **marks 书签**：命令面板提供「标记当前位置 / 跳回最近标记」，按滚动比例精确回到工作位置（会话级）。
- **多目标快速捕获**：今日日记 / 当前文档双目标切换，目的地预览、受控写入与失败原因回执。
- **预览打开**：`Alt+点击` 搜索结果以只读预览页签打开，窥视后再决定是否正式打开。
- **数字直达**：前 9 个可见卡片带数字角标，按对应数字键直接打开。
- **文档集版本历史**：覆盖保存自动保留最近 3 版，可任选版本回滚（可逆）；Essentials 常驻层随恢复带回执。
- **可迁移配置包**：设置页一键导出/导入「设置白名单 + 文档集」版本化包，导入整体校验后原子应用。
- **移动端悬浮球防误触加固**：宿主 `data-prevent-swipe` 契约 + 事件流拦截 + 拖动滚动链阻断三层叠加，拖球不再触发思源左滑右滑，球外手势不受影响。

### 面板、日记与快捷入口

- **左侧面板栏**：快速打开文件树、大纲、书签、标签、关系图、反链以及插件 Dock；支持完整显示、仅图标和完全隐藏。
- **右侧栏模式**：页签卡片常驻思源右侧 Dock，缩略图随宽度缩放，可选择放大填满或自动增加列数。
- **当日日记**：桌面与手机工具栏均保留独立入口；可设置默认日记本，未设置时首次使用会要求选择。
- **快捷入口工作区**：桌面默认显示在底部，也可切换到更窄的右侧栏；侧栏和手机端按各自配置显示。
- **文档集**：设置页支持保存当前文档、同名覆盖、行内重命名、删除、恢复预览、受控恢复以及 JSON 导入/导出；导入文件限制为 512 KiB 且合并前需要确认，恢复按保存顺序执行，恢复前会有界预检缺失和无法确认项，支持取消并显示成功、失败、已打开跳过和缺失跳过计数，跨端宿主行为仍需最终验证。
- **四类动作来源**：内置动作、思源 Dock 面板、其他插件公开的命令、第三方插件通过 `registerQuickAction()` 注册的运行时适配器。
- **可配置项**：四字以内短标签、图标、桌面/侧栏/手机端开关、启用状态、排序，以及配置导入导出；`+` 按钮直接进入快捷入口设置。
- 外部插件未加载时只保留入口配置并安全跳过，不轮询、不注入 DOM，不影响页签主体性能。

### 性能、数据与主题

- 页签本地过滤和切换不等待全库 API 或第三方插件；搜索失败仍保留已打开页签，标题搜索 API 不可用时继续尝试已打开文档内容和受限全文层，只有兼容回退全部不可用才显示错误态。
- 缩略图按视口懒渲染，缓存按文档保存并设置单条上限；关闭无关页签后清理失效缓存。
- 持久化数据在读取时校验与去重；收藏最多 512 条、置顶最多 64 条、收藏分组最多 64 条，运行时读取也会防御性清洗损坏数据，并可生成只读容量状态摘要，写入采用防抖并在卸载前等待完成。
- UI 使用思源主题变量和原生图标，约束按钮、卡片、开关和文字尺寸，统一空态、载入态、失败态的视觉层级与读屏语义，兼容默认明暗主题及 Neo 等第三方主题。
- 对缺少 `AbortController`、`IntersectionObserver`、`ResizeObserver` 或 `MutationObserver` 的旧 WebView，搜索取消、缩略图懒加载和尺寸/收藏监听会自动降级，不阻断页签切换主流程。

### 三端界面策略

| 界面 | 主要入口与交互 |
| --- | --- |
| 桌面弹窗 | 搜索、收藏、最近打开、排序、全屏、侧栏、日记、设置；左侧面板栏；底部或右侧快捷入口 |
| 右侧栏 | 紧凑搜索和工具栏；响应式页签/搜索卡片；侧栏快捷入口；不显示全屏 |
| 手机端 | 紧凑排序菜单、收藏、日记、设置；单/双/自动列；底部自定义入口和 `+`；不显示全屏 |

手机端首次打开时会等待 WebView 得到稳定尺寸后再显示卡片，并在缩略图容器获得真实宽度后计算缩放，减少首次进入的瞬时错位。手机设置页采用顶部横向标签和单列控件，收藏与快捷入口使用按钮排序，避免拖拽和页面滚动争抢手势。

## 组件面板：58 个开箱即用的组件

## 思源智能体（Agent）能力

在支持 `addAgentCapability` 的思源版本（当前按 3.8.4 源码契约适配）中，插件会按宿主能力检测注册十一项能力：

| 能力 | 类型 | 说明 |
| --- | --- | --- |
| `navigation-state` | 只读 | 当前页签、最近打开、最近关闭和收藏摘要（均为有界快照） |
| `search-documents` | 只读 | 受限文档搜索（笔记本、路径、内容类型、子类型、搜索方式、结果排序筛选；支持有界 `limit/offset` 分页并返回 `total/truncated`） |
| `get-document-outline` | 只读 | 指定文档的标题大纲（标题文本 + 层级 + 标题块 ID，可配合打开文档定位章节） |
| `home-widget-snapshot` | 只读 | 组件面板数据快照：按 `moduleId` 查询任意已注册组件（含第三方接入组件）的有界条目 |
| `workspace-context` | 只读 | 工作区一次快照：设备端、活动文档、打开页签、最近关闭、文档集、快捷入口、今日日记状态（只探测不创建）与存储演练健康（有界投影） |
| `home-adapter-diagnostics` | 只读 | 组件适配器诊断摘要：最近成功、缓存、超时和失败状态的有界投影（不含异常对象与敏感文本） |
| `workspace-plan` | 只读 | 智能体执行链入口：把请求步骤归一化为 ≤8 步的动作计划（带过期时间），只出计划不执行 |
| `execute-workspace-plan` | 受控执行 | 整份计划一次宿主确认后按序执行并返回有界回执 |
| `open-document` | 受控导航 | 打开指定文档并定位（仅切换页签，不修改任何笔记数据） |
| `open-documents` | 受控导航 | 批量打开最多 5 篇文档组成工作区（弹窗列出全部标题确认，拒绝或超时一篇不开） |
| `update-task-status` / `create-document` / `append-to-journal` | 受控写 | 切换任务勾选 / 新建文档 / 追加今日日记；执行前强制确认，30 秒超时视为拒绝 |

只读能力声明 `localRead` 且不声明写入、外传或外部成本；受控导航不声明写入。所有能力的输入、输出和文本长度均有边界；旧版思源会自动跳过注册，不影响页签切换和手机端加载。设置中的「智能体受控动作」总开关可一键停用全部写入与批量动作（只读能力保留）。能力由思源 Agent 的策略和生命周期统一管理，插件卸载时由宿主清理，详见 [ROADMAP.md](./ROADMAP.md) 的 AI 能力专项。

## 快速上手

1. **打开**：顶部工具栏右侧布局图标，或快捷键 `Alt+Shift+S`（可在 **设置 → 快捷键** 修改）；手机端点顶栏入口或悬浮按钮。
2. **切换**：点击卡片，或方向键 / `Tab` 移动后 `Enter`；左侧点击面板直达。
3. **管理**：卡片图钉置顶、星标收藏（点击星标弹出分组菜单）；右上角 × 关闭页签，右键卡片还有完整菜单（手机端长按卡片）。
4. **搜索**：在同一输入框中先看匹配页签，再看全库文档标题卡片。
5. **常驻**：桌面端通过侧栏按钮把切换器固定到右侧 Dock。
6. **第二面板**：顶栏「第二面板」按钮或 `Alt+Shift+P` 打开聚合页（最近打开与收藏），底部快捷入口栏也有固定入口。
7. **自定义**：点击底部或右侧入口栏中的 `+`，选择 Dock、其他插件命令或调整三端可见性。
8. **尺寸**：桌面端面板默认按屏幕比例自适应打开；弹窗内全屏按钮可临时铺满，再点或按 `Esc` 恢复。

## 设置

**设置 → 插件 → 小驴雷切 → 设置**（切换器内齿轮按钮直达）。桌面端使用左侧标签，手机端使用顶部可横向滚动标签；改动即时保存：

| 标签页 | 可配置项 |
| --- | --- |
| 外观 | 面板尺寸模式（自适应屏幕比例 / 固定尺寸 / 全屏铺满）、自适应比例（50–100）、固定宽高（480–1920 × 360–1280）、缩略图列数（自动 / 2–8）、缩略图高度（72–360） |
| 分组与排序 | 顶栏「分组 · 排序」按钮一体化设定：分组方式（按笔记本 / 按收藏 / 按创建月份 / 不分组，默认按笔记本）+ 组内排序（六种）；分组块按内容宽度并排流动，组头可折叠 |
| 行为 | 默认排序方式、最近打开记录、智能体受控动作总开关 |
| 面板 | 左侧面板列表显示 / 隐藏、显示方式（完整 / 折叠图标 / 隐藏）、侧边栏缩略图布局（放大 / 自动增列） |
| 收藏 | 收藏夹折叠、序号、新建 / 重命名 / 删除 / 排序，组内收藏排序和分组调整 |
| 快捷入口 | 标签、图标、三端可见性、启用、拖拽或按钮排序、右侧入口栏、配置导入导出 |

## 架构与测试

<p align="center"><img src="docs/architecture.svg" width="860" alt="LvSpeed Switch 六层运行时架构"/></p>

插件按 6 层组织。三种界面共用导航服务和持久化结构，但每个界面独立持有 DOM、搜索会话与生命周期：

| 层 | 入口文件 / 类 | 职责 |
| --- | --- | --- |
| 界面层 | `showSwitcher` / `renderSidebarPanel` / `showMobileSwitcher` | 桌面弹窗/全屏、右侧栏和手机端的端侧布局与交互 |
| 编排层 | `registerSwitcherRefresh` / SearchSession / 动作执行器 | 视图刷新广播、独立异步状态、共享命令路由 |
| 导航服务层 | 页签 / 收藏 / 搜索 / 快捷入口 / 日记 / 面板 | 排序、去重、批量操作和渐进式功能组合 |
| 思源集成层 | `getAllTabs` / MobileTabs / 内核 API / Dock / 插件命令 | 统一封装宿主能力和第三方插件边界 |
| 持久化层 | `loadData` / `saveDataDebounced` / `storage-migration.js` | 15 个校验后的 storage key（12 个托管迁移 + 2 个检视型 + 1 个版本戳）、防抖写入、卸载前 flush、只读迁移演练、配置导入导出 |
| 基础设施层 | `util.js` / `search-session.js` / `quick-actions.js` / 类型与常量 | 零宿主依赖纯函数、类型、边界值、日志和自动化测试 |

**性能隔离**：已开页签切换只依赖本地状态；全库请求、缩略图补全和第三方动作都是可失败的附加层。每个搜索界面拥有独立请求序号、取消控制器、定时器和缓存，销毁时集中释放。

**数据边界**：15 个 storage key 分项保存（清单见 `src/constants.ts` 的 `PERSISTENT_KEYS`，逐 key 迁移与容量边界见 [`docs/storage-compatibility-matrix.md`](docs/storage-compatibility-matrix.md)）。收藏最多 512 条、置顶最多 64 条、收藏分组最多 64 个；加载和写入都会去重、裁剪并安全回写。可重新查询的搜索结果和临时界面状态不写入插件数据。

**组件面板开放协议**：第三方插件可以通过 `registerHomeModule` 注册只读、按端隔离的组件，出现在组件面板的组件商店里（支持尺寸型号声明、描述、失败跳转回调）。完整接入指南见 [`docs/widget-protocol.md`](docs/widget-protocol.md)。插件不会自动改变默认切换器首页，也不会保存外部函数引用；调用方卸载时应执行注册返回的清理函数和控制器 `dispose()`。

```ts
const unregister = speedSwitch.registerHomeModule({
    moduleId: "my-readonly-module",
    title: "我的摘要",
    supportedDevices: ["desktop", "sidebar"],
    read: async (config, device) => ({items: await readSummary(config, device)}),
});
// 由调用方在自己的容器中显式创建并管理面板生命周期。
```

### 第三方快捷动作适配

如果第三方插件已经通过思源 `addCommand()` 注册命令，该命令会自动出现在快捷入口设置的"添加"列表中，无需额外适配。需要传递参数或执行自定义流程时，可以获取小驴雷切插件实例并直接注册一个可见入口：

```ts
const speedSwitch = this.app.plugins.find(
    (plugin) => plugin.name === "siyuan-speed-switch",
);

this.unregisterSpeedSwitchAction = speedSwitch?.registerQuickAction({
    id: "xiaolv-checkin",
    label: "打卡",
    icon: "iconCalendar",
    value: "open",
    targets: ["desktop", "sidebar", "mobile"],
    handler: (value) => openClock(value),
});

// 在提供方插件的 onunload() 中调用：
this.unregisterSpeedSwitchAction?.();
```

注册后入口会写入快捷入口设置，并可按端侧单独启用。回调仅保存在内存中，持久化配置不保存函数；提供方卸载后入口配置仍在，但点击时会安全跳过。低层接口 `registerQuickActionAdapter(id, handler)` 可用于接管已经存在的 `adapter` 配置，不建议通过模拟 DOM 点击或伪造全局快捷键接入。
