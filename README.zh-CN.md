# 速切（Speed Switch）

思源笔记插件：像 Windows 的 **Alt+Tab** 一样快速切换已打开的页签。点击顶部按钮或快捷键即可弹出「标签切换器」，以**缩略图**形式展示所有已打开的页签，点选即可瞬间切换，并完整支持**分栏（分屏）**布局。

<img src="preview.png" width="640" alt="速切预览"/>

## 功能特性

- 🌟 **缩略图预览** — 每个页签以卡片形式展示文档内容预览，而不只是一串名字。
- 🔀 **支持分栏** — 页签按窗口（分栏）分组展示，切换时自动激活所在分栏。
- ⌨️ **键盘操作** — 方向键 / `Tab` 移动，`Enter` 切换，`Esc` 关闭（与 Alt+Tab 一致）。
- 🧠 **MRU 排序** — 记住最近使用的页签，默认聚焦到最近使用的那一个。
- 🧩 **双入口** — 顶部按钮 + 全局快捷键。

## 入口

- **顶部按钮**：顶部工具栏的布局图标。
- **快捷键**：默认 `Shift+Alt+S`，可在 设置 → 快捷键 中修改。

## 使用方法

1. 打开多个页签（可以分布在多个分栏中）。
2. 按快捷键或点击顶部按钮。
3. 弹出切换器，页签以缩略图卡片形式按分栏分组展示。
4. 点击卡片，或使用方向键 / `Tab` 移动后按 `Enter`，即可瞬间切换。
5. 按 `Esc` 关闭，不做切换。

## 环境要求

- 思源 v3.1.20 及以上（使用 `getAllTabs` API）。
- 桌面 / 浏览器桌面端前端（页签与分栏）。
