## 一、 背景与现状诊断

小驴雷切已明确核心产品主语为**“思源的工作上下文入口层”**，围绕“找到、预览、打开、执行、恢复现场”构建闭环。

在设计资产上，本仓库积累了 R4 平台综合原型、R5 顶栏原型以及 2026-10-16 最新的第二面板微马赛克（Micro Mosaic）静态原型；在工程实现上，全量测试达到 8749 项通过、0 失败，包体严格控制在 578 KiB 门禁以内。

然而，在**原型设计前瞻性**以及**从原型到生产实现的还原度**上，目前仍存在以下四个关键层面的断层与优化空间：

1. **壳层层级过度嵌套（Shell Over-Mounting）**：
   - *现状*：生产实现中，每次打开第二面板都会挂载完整的平台 Chrome（包含品牌、三表面导航、连接状态、设置、帮助、关闭）、二级工具栏（编辑布局/刷新全部/小组件商店）以及底部健康回执。
   - *影响*：在 920×390px 的紧凑窗口下，壳层吃掉了超过 150px 的垂直空间，留给小组件的可视高度不足一半，使其像“微缩版后台管理系统”而非“轻盈桌面看板”。
2. **尺寸档位被扁平化抹平（Flattened Grid Rhythm）**：
   - *现状*：生产样式中针对紧凑模式设置了 `grid-auto-rows: 28px`，但由于卡片内部结构（头部、状态、配置切换、列表）仍较为厚重，导致 `small`、`medium`、`tall` 在真实界面中高度差异不明显，视觉上退化为近似等高的列表卡。
3. **首屏信息密度与视线流干扰（Visual Noise）**：
   - *现状*：第一面板原型包含较高的彩色渐变缩略图（67px）；第二面板小卡常驻显示来源状态（Live source/Cached）、配置按钮与完整更新时间。
   - *影响*：分散了用户聚焦核心信息（如文档名、核心数值、待办项）的视觉注意力。
4. **极端端侧退化较为生硬（Adaptive Gracefulness）**：
   - 在思源宿主 245px 真实窄 Dock 以及 960×600 便携短窗口下，卡片内部仍有发生文本截断和双滚动条的隐患。

## 二、 原型设计层面的突破与重构建议

针对三大核心表面，参考 Linear、Raycast、Obsidian 与 Craft 等现代顶级工具软件的视觉规范，提出以下设计演进方案：

### 1. 第二面板：自适应弹性瓦片系统（Adaptive Glance Tiles）
摒弃单一固定列数的生硬表格，建立三种标准**瓦片原型架构（Tile Archetypes）**：

- **A. Micro-Metric（单值微瓦片，1×1 单元，约 110×64px）**：
  - *适用场景*：本地时刻、天气温度、未完成待办数、写作打卡天数。
  - *结构布局*：极轻弱化小标签（9px）+ 20~22px 等宽数字（加粗）+ 状态点/单位。
  - *设计原则*：零多余边框、零副标题，纯粹的数据直给。
- **B. Compact-Row（微型信息条，2×1 单元，约 230×64px）**：
  - *适用场景*：近期编辑文档、今日日记、收藏快速访问。
  - *结构布局*：`[6px 类别指示点] + [单行省略标题 (12px)] + [右浮动次级时间/计数 (10px)]`。
  - *设计原则*：两行紧凑列表，悬停整行微亮，单次点击直接打开。
- **C. Dense-Card（密度卡，2×2 单元，约 230×136px）**：
  - *适用场景*：年度进度（带细轨道）、文档大纲目录、写作热力图。
  - *结构布局*：卡片内边距收敛至 6px~8px，图表/进度与指标紧凑咬合。
- **非对称微律动（Asymmetric Bento Layout）**：
  通过 `1 Dense-Card + 2 Compact-Row + 2 Micro-Metric` 组合，构成错落有致、空间饱满的微马赛克拼贴，消灭空白死角。

### 2. 第一面板（切换器）：三级视线流与轻量无缝卡片
- **缩略图降噪（Noise-Free Header）**：
  移除或弱化大块实色渐变缩略图，改为卡片内嵌浅色图标，或仅在顶部保留 2px 的微妙色相指示线。卡片高度从 124px 压缩至 52~60px。
- **视线三级流动通道（Three-Tier Visual Flow）**：
  1. *第 1 级（检索区）*：常驻高识别度输入框，右侧嵌入等宽键帽徽章 `⌘K` / `Tab`。
  2. *第 2 级（命中区）*：当前选中项具备左侧 3px 主题色微指示条 + 4% 柔和底色，键盘上下导航即时跟手。
  3. *第 3 级（预览区）*：右侧 34% 保持独立滚动，消除外围重复外框，背景直接融合在面板表面，呈现一体化现代阅览感。

### 3. 平台顶栏（Chrome）：动态单行极简收敛（36px Ultra-Compact）
- **紧凑模式完全隐藏上下文面包屑**（消除“工作上下文 › 工作台 › ...”对视高的挤压）。
- **左中右单行高集约排布**：
  - 左侧：极简“驴”Mark + 标题。
  - 中间：微型分段控制器（Segmented Control, 24px 高度，圆角胶囊滑块）。
  - 右侧：紧凑合并为 `[⚙ 设置] [Esc × 关闭]`。
- 整体高度从近 100px 彻底锁定至 **36px**，释放 60px 以上的可视工作区。

## 三、 工程实现维度的落地优化方案

为了将上述原型设计精准落地，同时不增加包体或破坏既有架构，建议在代码层采取以下针对性改造：

### 1. `view` 查看态与 `edit` 编排态彻底解耦
- **现状代码**：
  `src/second-panel-ui.ts` 中，查看模式依然渲染 `.sw-home__bar` 及其按钮组，并常驻渲染 `.sw-home__receipt`。
- **改造方案**：
  - **默认查看态（Glance Mode）**：
    - 完全不渲染 `.sw-home__bar` 工具条；
    - 刷新逻辑绑定至快捷键（`R` / `F5`）或收进右上角微型操作点；
    - 底部健康回执默认静默，**仅在组件产生 `error` 或 `stale` 时**以轻微动画从底部浮现可交互的“重试”条。
  - **编辑态（Editing Mode）**：
    - 用户显式通过更多菜单进入编辑时，才优雅滑入工具条，卡片呈现虚线把手与移除按钮。

### 2. 精确锁定 CSS Grid 计算行高与排版槽位
- 在 `src/styles/_12-r54-surface-adapter.scss` 中，针对 `.sw-home--compact`：
  - 维持 `grid-auto-rows: 28px`，但重构 `.sw-home__cell` 内部结构；
  - 废除紧凑模式下对通用 `.sw__home-module-header` 最小高度 24px + margin-bottom 的层层包裹；
  - 采用绝对紧凑的内部 Grid：
    ```scss
    .sw-home--compact .sw-home__cell {
        display: grid;
        grid-template-rows: auto 1fr;
        padding: var(--sw-space-xs, 4px) var(--sw-space-sm, 6px);
        overflow: hidden;
    }
    ```
  - 保证 `xs (h:2 = 56px)`、`small (h:3 = 84px)`、`medium (h:4 = 112px)`、`tall (h:6 = 168px)` 在视觉上形成清晰的高矮梯度。

### 3. 微质感（Visual Tactility）与微动效落地
- **1px 亚光微边缘（Subtle Rim Light）**：
  ```scss
  border: 1px solid var(--b3-border-color);
  box-shadow: inset 0 1px 0 0 rgba(255, 255, 255, 0.06), 0 1px 2px rgba(0, 0, 0, 0.03);
  ```
- **双层发光焦点环（Glow Focus Ring）**：
  彻底取代常规 2px 粗实线，解决浅色/深色主题下的视觉侵入性：
  ```scss
  :focus-visible {
      outline: none;
      box-shadow: 0 0 0 1px var(--b3-theme-background), 0 0 0 3px color-mix(in srgb, var(--b3-theme-primary) 35%, transparent);
  }
  ```
- **等宽键帽徽章规范**：
  统一使用 `font-variant-numeric: tabular-nums` 和 `ui-monospace`，保证数字和按键在切换时不产生微抖动（Zero Layout Shift）。

## 四、 极端环境自适应与无障碍规范

1. **真实窄 Dock（245px）的一维垂直流**：
   在容器宽度 `<= 280px` 时，全部卡片自动降为单列 100% 宽度，卡片内部自动收敛为微型信息条模式（Compact-Row），隐藏辅助文字，仅保留图标 + 核心指标。
2. **便携短屏（600px 高度）的弹性预算**：
   - 顶栏 padding 压缩为 2px 4px；
   - 卡片垂直 gap 调整为 4px；
   - 列表型小卡超过 2 项时自动截断并显示 `+N`，避免在小卡内生成第二滚动条。
3. **无障碍与 WCAG 2.2 兼容**：
   - 保持所有文字与背景对比度 `>= 4.5:1`（暗色模式下正文明度经过专项校准）；
   - 所有隐藏的可视标签均完整保留 `aria-label` 与原生 `title`，确保读屏与纯键盘用户无障碍操作。
