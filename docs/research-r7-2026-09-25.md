# R7 调研报告：启动器预览模式 × 思源上游增量（2026-09-25）

> 调研-吸收循环第七轮。前序：R5（机制层）、R6（导航上下文）。本轮背景：候补池清空（T-6834~T-6838 搜索体验批 + v0.35.0 发版），按 ROADMAP"剩余候补随反馈立项"口径，本轮以吸收外部情报、给候补立项补规格为主，不含代码变更。

## 1. 启动器预览窗格模式（Raycast/Spotlight 谱系）

**模式共识**（多来源交叉）：键盘优先启动器 = 可过滤列表 + **右侧常驻 detail/preview 窗格**（随 ↑/↓ 选中项实时更新）+ 动作面板；Raycast 官方 API 把它形式化为 `List.Item` 可选携带 `detail` 组件，选中即渲染。

**实现要点**（可直接转成规格）：
- **防抖与最小驻留**：昂贵预览工作必须 debounce（社区共识 300~350ms + 最小 2 字符查询）；快速连按方向键时不级联发请求。
- **骨架与显式空态**：窗格加载中显示骨架/既有内容降标，失败/空数据显示明确空态，不闪空白。
- **选中同步是唯一数据流**：列表键盘导航、点击选中、触摸三入口都走同一条"选中项 → 窗格渲染"管线（与我们 T-6838 行焦点 + T-6837 单一激活入口的架构天然对齐）。
- **重负载延后**：首帧显示轻量元数据（标题/路径/大纲），重内容按需加载。

**吸收结论 → P9 常驻预览窗格规格草案**（候补，随反馈立项）：
- 桌面 only；文档结果区右分栏（约 260px），窄宽自动隐藏。
- 数据源零新增端点：`/api/outline/getDocOutline`（已在白名单）取标题大纲 ≤12 条 + 有界 SQL 取首段文本 ≤600 字（轻量元数据先行）。
- 同步钩子=既有 `moveDocItemFocus`/focus 事件（T-6838），debounce 300ms + AbortController 竞态丢弃（复用 T-6814 关联行模式）。
- 骨架占位 + 空态文案；手机端不提供（工作台已承担类似角色）。

## 2. 思源上游增量（3.8.5 stable 2026-09-22 / 3.8.6-alpha / 内核 MCP）

- **内核原生 MCP 端点**：Go 内核自带 `POST /mcp`（Model Context Protocol），MCP 客户端可直连内核操作笔记。安全时间线：3.7.2 修复该端点鉴权缺失（CVE-2026-66012，CVSS 10.0）、3.7.4 修复 `database_clean` 工具路径穿越（CVE-2026-74798）。**对本项目**：T-6832（RPC 网关评估池）的外部消费面从"自建桥"升级为"内核 MCP + 插件 RPC 路由"——速切只读导航能力可经 `/api/plugin/rpc/:name` 被 MCP 侧 Agent 消费；评估池补充上游事实，等生态回应再立项。
- **3.8.6-alpha 反链按锚文本排序**：反链排序能力上游已做（alpha）——**候补**：关联内容行（T-6814）等 stable 后暴露排序或默认采用锚文本序。
- **3.8.6-alpha 插件发布资源目录声明**：发布管线变化——**观察项**：若集市同步路径变化需跟进发布 workflow。
- **3.8.5 数据库日历/列表视图、可编辑思维导图列表**：与 P8（数据库组件视图形态渲染，用户明示后置）相关，上游形态确认了"按视图类型渲染"方向正确；P8 维持后置。
- **3.8.6 修复两项与我们相关**：全局快捷键注册打断插件 onload（上游已修——我们 `safeRegisterPluginCommand` 防御保留，双保险）；只读模式插件编辑器命令快捷键不触发（已修——预览态命令行为需真机回归观察）。
- **集市分发协议提案**（社区，2026-09-10）：marketplace 从平台工程降级为"协议+索引"（静态 `latest.json` + minisign 签名，社区/企业可自托管）。**观察项**：若落地，我们的发布流程（tag → Release workflow → package.zip）可能需补一份签名 manifest；当前不动。
