# ADR 0134：本地片段商店与社区渠道

- 状态：已采纳
- 日期：2026-10-04
- 任务：T-7094 / T-6962 / T-6963 / AB-1801 / AB-1802

按用户“一律按推荐”授权，首批采用本地目录，复用实验室内部选择器、随包的 26 个 MIT CSS 示例、本机原生片段、分类/标签、分组、备份恢复与本地投稿包。新增商店入口仅改变选择方式：点击条目先只读沙箱预览，再明确新建禁用草稿，不改当前草稿或原生列表。启用仍须保存后通过原生开关；JS 预览保持禁执行。

来源与许可证未知时显示未声明，兼容性未验证时不宣称通过。内置示例受本仓 MIT 许可，端侧观感未验证；兼容端说明只表示 CSS 可适用的范围。配置包继续使用已有逐组差异确认（T-6961），原生片段备份继续使用已有事务预览（T-7073）；不复制成商店的第二真源。

社区推荐 GitHub 版本化人工审核目录加链滴投稿/讨论，先安全/质量审核，再禁用草稿导入；不采用先发后审，不自动上传。当前缺少已建立的目录仓库、维护者与实际目录 URL，获取链路属于外部前置，不能编造地址或自行发布。现有本地投稿包与用户指定 Gist 保持可用，T-6964 获取侧后置至真实渠道建立。
