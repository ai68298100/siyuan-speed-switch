# ADR 0207：可选效果组件收敛为紧凑摘要

- 日期：2026-10-16
- 状态：accepted
- 任务：T-7282

## 背景

第二面板的天气和倒数组件仍继承效果型卡片皮肤：天气带大渐变、超大温度和多行预报，倒数保留大字号和纵向里程碑。在 compact 工作台的小高度档中，这两项看起来像缩小的海报卡，并会把内容推到卡片边界之外。

## 决策

compact 桌面卡统一使用主题中性表面和轻边框。天气保留 20px 温度、右侧地点、四列单行预报和全宽来源行；标签与辅助文本使用省略，窄屏仍保持四列以避免第二行把小卡撑高。倒数保留 20px 主值、同行里程碑和单行目标摘要。配置、折叠、刷新和 stale 文案继续可达或可见。

样式放在 R54 最终适配层，并与默认七组件的 compact 规则分开。默认元数据继续使用可访问的视觉隐藏规则；可选卡只隐藏重复的 fresh 元数据，stale 元数据保留明文。天气地点清除原效果卡的深色胶囊背景，保证浅色主题可读。

## 边界

本任务只收敛可选卡的视觉和几何，不改变天气适配器的错误状态契约。当前天气网络失败仍可能沿用既有 emptyHint 路径，重试入口另立任务；本轮夹具覆盖 ready/stale，不把 empty/error 状态写成已验证。
