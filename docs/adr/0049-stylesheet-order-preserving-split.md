# ADR 0049：样式表顺序切片拆分（P1-2）

- 日期：2026-09-17
- 状态：已接受（T-6292）
- 范围：`src/index.scss`（6517 行）→ `src/styles/_00.._09-*.scss` + 12 行清单

## 背景

`index.scss` 是六轮 TS 重构之后**唯一未被治理的巨型文件**（6517 行）。但拆分样式与拆分
TS 有一个本质差别：**CSS 规则顺序即层叠顺序**，按域名聚类拆分会改变层叠结果，产生
难以察觉的视觉漂移。因此本批**不能**沿用 TS 那套「按语义聚类搬移」的做法。

勘察（`.tmp/scss-recon.py`）确认了可行性边界：无 `@mixin`、无 `@function`，
仅 6 个动效 SCSS 变量（编译期常量，不产出 CSS）与 2 个 `@keyframes`。

## 决定

1. **顺序切片，而非域名聚类。** 在「带注释小标题的顶层区块起点」处切成 10 个连续片段，
   按原顺序 `@use` 组装。层叠顺序逐字节保持。
2. **动效令牌抽出**到 `_00-tokens.scss`（只含注释与变量，**不产出任何 CSS**），
   各切片按需 `@use "00-tokens" as *;`——因 tokens 无 CSS 产出，不会重复发射。
3. **自证机制写进拆分脚本**：重组（剔除 `@use` 行）后必须**逐字节等于原文件**。
   实测 True。这是"零漂移"的第一道证明。
4. **组合视图（`tests/source-scan.cjs` 新增 `readStyleSource`）**：
   既有 35 处样式契约断言是按单文件写的，直接读清单会集体失效。改为按清单顺序
   重组后**再交给既有断言**——断言一行不改，锚点强度不降低。
   另修 1 处裸 `fs.readFileSync`（`css-block-scan.test.cjs`）改走组合视图。

## 验证：零视觉漂移的两道证据

1. 拆分脚本自证：重组后逐字节等于拆分前原文件 → True。
2. **产物指纹一致**：`dist/index.css` 拆分前后均为 145577 bytes、
   md5 `ff1c0a2e9b74ee428df9f05ccbad5ed3`（`cmp` 逐字节相同）。

配合全量 5872/5872 与 `verify:release` 全链绿。

## 负向验证

- 注入「清单只保留 tokens」→ 组合视图塌缩 → **128 项精确失败**，字节级还原后全绿。
  证明组合视图是**承重的**，没有把门禁改瞎。

## 附带发现（真实覆盖缺口）

注入「清单删掉 `03-chunk`」（**1940 行，约占样式 30%**）后，
**5872 项测试全部仍然通过**。即该切片的样式内容几乎没有任何契约断言覆盖。

这不构成对本批拆分的否定（产物 CSS 逐字节未变，行为零漂移），
但暴露了门禁覆盖的不均衡：store-* 家族覆盖密集，而另一大块样式处于「删了也没人拦」的状态。
已用 `.tmp/scss-coverage-audit.py` 做逐切片审计量化，结果作为下一节点（补契约）的输入。
