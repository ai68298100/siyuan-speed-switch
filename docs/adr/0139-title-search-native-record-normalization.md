# ADR 0139：标题搜索归一化思源原生路径记录

- 状态：已接受
- 日期：2026-10-05
- 任务：T-7111

## 背景

思源 3.8.x 的 `/api/filetree/searchDocs` 标题搜索返回的记录可能只有 `path`、`hPath`、`box`、`name` 和 `alias`，不保证提供插件旧流程依赖的 `id` 或 `rootId`。切换器此前把这些记录直接交给筛选和渲染，后续 ID 解析会丢弃有效结果，因此真实宿主中的标题搜索可能显示为空。

## 决策

标题搜索在筛选和渲染前统一调用 `normalizeTitleSearchDocuments`。归一化器从合法 `.sy` 路径推导根文档 ID，补齐标题/路径投影，并继续使用既有 ID 白名单和有界字段规则。无法推导合法根文档 ID 的记录仍被丢弃；缓存、分页和全文搜索语义不变。

真实原生响应形状进入行为测试夹具，避免用带 `id` 的旧假数据掩盖兼容性缺口。真实工作台 E2E 的人工释放适配器显式声明 10 秒上限，避免默认 800ms 超时把测试控制流误报为生产失败。

## 取舍

- 在 UI 入口归一化，兼容思源返回形状而不改写共享搜索模型的原生字段约定。
- 只接受 `.sy` 路径推导的合法 ID，不根据任意路径或标题猜测文档，保持安全边界。
- 保留 `normalizeSearchResult` 的有界投影，避免把宿主原始字段直接扩散到 DOM。

## 证据

- 标题搜索与搜索模型定向测试：`115/115`。
- 门禁负向注入：移除归一化调用后，标题搜索契约按名称失败；文件 SHA-256 恢复。
- `pnpm exec tsc --noEmit` 通过。
- `pnpm verify:release` 独占运行通过：全量 `8388/8388`、可复现构建 `3/3`、质量/集成审计各 `50/50`、全部 smoke 通过。
- 最新真实思源 3.8.6 全套 E2E：`35 passed / 2 skipped`；工作台恢复场景单独复测 `1/1`。
