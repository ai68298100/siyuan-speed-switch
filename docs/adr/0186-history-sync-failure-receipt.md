# ADR 0186：最近记录同步失败必须可见且可重试

日期：2026-10-14  
状态：已接受（T-7258）

## 背景

最近记录下拉打开时会先读取思源的官方最近文档接口。旧实现把请求失败、返回空数据和有效同步后的空列表都归一成同一条本地历史，用户无法判断是确实没有记录还是同步失败，也没有就地恢复入口。

## 决策

- 最近记录同步返回 `success`、`empty` 或 `failed` 三种结果；空结果保持本地列表语义，失败单独保留。
- 失败时在下拉面板顶部显示说明，明确当前仍展示本地记录，并提供“重试同步最近记录”按钮。
- 同步按钮在请求期间继续禁用并设置 `aria-busy`，重试复用同一触发器和已有请求保护。

## 验证

- `tests/history-sync-receipt-contract.test.cjs` 覆盖失败/空结果区分、错误提示、Retry 接线和负向删除探针。
- TypeScript、全量测试和构建通过；真实宿主网络边界仍遵循 `BLOCKERS.md`。
