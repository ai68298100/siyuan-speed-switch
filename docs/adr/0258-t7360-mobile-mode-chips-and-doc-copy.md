# ADR 0258：T-7360 移动端模式药丸、搜索结果 ⌘K 画板与 Alt+C 快捷引用、清空历史芯片与门限校准

日期：2026-10-22  
状态：accepted  
任务：T-7360  

## 背景

在第一面板（切换器 / 深入穿透检索 / 动作画板）的可用性闭环与 v0.48.1 发版建设中：
1. **移动端符号输入成本过高**：在触屏虚拟键盘上输入 `@`、`^`、`#`、`!`、`>` 等符号需要来回切换键盘分页，用户体验割裂；
2. **搜索模式反馈感知**：用户键入或点击不同前缀进入大纲/正文块/标签模式后，Placeholder 仍是静态文案，缺乏模式感；
3. **搜索结果行快捷引用与动作呼出**：用户检索出全库文档或命中块后，除点击打开外，高频需要直接复制该块超链接（`siyuan://blocks/...`）或呼出 Raycast 风格动作画板（`⌘K`）；
4. **近期搜索词管理**：用户希望能够主动一键清空搜索历史。

## 决策

1. **移动端切换器常驻多模态穿透药丸 Chips 栏（`.sw__mode-chips-bar`）与清空按钮（`.sw__search-clear`）**：
   - 手机端顶部工具栏下方常驻全套药丸 Chips，支持触控横向滑动与单点激活对应模式；
   - 补齐清空微按钮，移动端一键清空无需反复按退格键；
2. **搜索模式专属 Placeholder 动态联动**：
   - 当识别到 `@`（大纲）、`^`（正文）、`#`（标签）、`!`（书签）、`>`（命令）、`?`（速查）时，输入框 Placeholder 同步更新为专属引导文案；
3. **全库搜索结果项 ⌘K 呼出动作画板与 Alt+C 单键复制块超链接**：
   - 键盘上下键聚焦至任一全库搜索结果行时，按 `⌘K` / `Ctrl+K` 即可打开动作画板，按 `Alt+C` 立即将命中块或文档的 `siyuan://blocks/...` 写入剪贴板；
4. **近期搜索历史一键清除芯片（`.sw__recent-query-clear`）**：
   - 近期搜索词列表末尾提供清空历史微按钮，点击即刻清理会话历史；
5. **包体预算与观察线校准（ADR 0258）**：
   - raw bundle 观察线由 1194 KiB 校准至 1198 KiB（1,226,752 字节，实测 1,225,245 字节，余量 1,507 字节）；
   - 归档包门限由 602 KiB 校准至 604 KiB（618,496 字节，实测 616,535 字节，余量 1,961 字节）；
   - 单条目压缩门限维持 332 KiB（339,968 字节，实测 330,387 字节，余量 9,581 字节）。
