# ADR 0197：文档关系摘要真实宿主边界

- 日期：2026-10-15
- 状态：已接受
- 任务：T-7272（T-7144 候选复核的证据子任务）

## 背景

`document-relations-summary` 的生产定位是活动文档的直接子块和有限 markdown 块引用摘要，不是完整反链图。T-7144 需要确认真实思源 SQL 字段、引用语法和活动文档上下文没有偏离模型假设。

## 决策

- 继续使用当前受限 SQL：直接子块与引用活动文档的块各取有界集合，再由模型去重、筛选和投影。
- 将真实宿主返回的 `child`/`reference` 记录作为兼容证据；不因单个隔离样本扩展到完整反链解析或新的 API。
- 保留等待索引完成的测试前置，避免把宿主异步索引延迟误判为插件空态。

## 证据与边界

- 思源 3.8.7 隔离工作区返回 1 个子块和 1 个引用；插件快照显示 `Child`、`Reference` 两项，关系总数为 2，标题上下文正确。
- 证据文件：`.artifacts/T-7272-relations-host-probe.json`。
- 该结果证明当前轻量摘要协议在真实宿主可用，不证明完整反链、复杂嵌套引用或旧宿主字段兼容。
