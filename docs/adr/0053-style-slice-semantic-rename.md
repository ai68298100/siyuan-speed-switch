# ADR 0053：样式切片语义重命名（P1-4）

- 日期：2026-09-17
- 状态：已接受（T-6296）
- 范围：`src/styles/_01.._09-chunk.scss` → 语义文件名；清单 `src/index.scss` 注释扩充

## 背景

P1-2（ADR 0049）按顺序切片拆分时使用 `_01.._09-chunk` 占位名，P1-3（ADR 0050）的
独占锚点覆盖门禁上膛后，重命名已安全。dev-plan 原设想按"切换器/首页/商店/设置/移动端"
五个域名命名，但勘察推翻了这一设想：**切片是原文件的时间累积片段，单个切片横跨多个域**
（如 03-chunk 1941 行同时含桌面切换器弹窗内部、手机切换器、手机全局三个域），
按单域名命名会名不副实——而"名不副实"正是本仓断言方法论的处置对象。

## 决定

保留**序号前缀**（维持层叠顺序的可读性，顺序即层叠顺序、不可调整），
主体名取"起始/占比最大的内容"，精确的跨域映射写进清单注释，不做任何内容搬移：

| 旧名 | 新名 | 主体内容 |
|---|---|---|
| `_01-chunk` | `_01-base-controls` | 基础动画与控件、快速选择器 |
| `_02-chunk` | `_02-settings` | 设置页收藏与标签布局 |
| `_03-chunk` | `_03-switcher-mobile` | 切换器弹窗内部（桌面+手机）与手机全局 |
| `_04-chunk` | `_04-fab-fullscreen-soft` | 悬浮球、全屏模式、现代柔和视觉层 |
| `_05-chunk` | `_05-settings-widgets` | 设置页视觉、减动效、分组排序、第二面板起步 |
| `_06-chunk` | `_06-widgets-store` | 手机顶栏芯片、排序浮层、小组件画布、商店画廊 |
| `_07-chunk` | `_07-sidebar-panel-store` | 侧栏工具栏、组件面板、商店分区 |
| `_08-chunk` | `_08-home-store-cards` | 首页问候、快速记录、商店卡片 |
| `_09-chunk` | `_09-store-preview-polish` | 商店实时预览、面板交互打磨、周打卡、高对比 |

- 全部 `git mv`（保留历史）；清单 9 条 `@use` 路径逐一替换（每条断言命中恰 1 次）。
- **组合视图零改动**：`readStyleSource()` 完全数据驱动（解析清单 @use → `src/<dir>/_<base>.scss`），
  文件改名对它透明，契约断言一行未改。
- 活动引用面勘察：测试/脚本/CI 中对旧名的引用仅 `style-slice-coverage.test.cjs:4`
  的历史叙述注释（描述 P1-2 时代动机），按"叙述性引用保持原样"规则不改。

## 验证

- `pnpm build` EXIT=0；`dist/index.css` md5 `ff1c0a2e…` **与 P1-2 登记逐字节一致**
  （重命名不触碰编译产物，这是零漂移的最强证据）；`index.js` 631445 不变。
- `package.zip` 320546 → 320543（-3 B，zip 内部时间戳抖动），在 release-quality 门禁
  既有的 1 KiB 漂移护栏内，不触发文档同步。
- `verify:release` 全链绿；style-slice-coverage 门禁（数据驱动切片清单）天然兼容新名。

## 教训（本轮当场踩中并修正）

**对已 CRLF 的文本再做 `replace('\n', '\r\n')` 会产生 `\r\r\n` 双重损坏。**
首轮清单改写脚本对 CRLF 文本统一做了 `\n → \r\n` 替换，12 处行尾全部变成
`\r\r\n`（替换 `@use` 路径的 9 处断言照常命中，编辑器与 Read 工具均不显示差异）；
第二轮插入映射注释时锚点"命中 0"才暴露——**"命中 0"当可疑信号这条铁律再次成为
唯一防线**。修复后以三条断言收口：无 `\r\r\n`、无裸 `\n`、锚点命中恰 1。
→ CRLF 文件改写的正确姿势：**检测行尾 → 只在必要处替换 → 写回前断言行尾纯净**。
