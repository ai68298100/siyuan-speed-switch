# ADR 0174：移动悬浮球快滑在越过触摸斜坡后仍可识别

日期：2026-10-12  
状态：已接受（T-7142）

## 背景

移动悬浮球的四向快滑原本只在 `pointerup` 仍处于 `docked` 时分类。实际的首个有效移动通常会先超过 8px 触摸斜坡，指针生命周期随即进入 `dragging`，因此上下左右快滑不会进入分类器，而是被当作普通拖动保存一个新位置。该缺口可在 JSDOM 指针序列中稳定复现：`pointerdown(100,120) → pointermove(100,80) → pointerup(100,80)` 的状态先进入 `dragging`，回调没有方向且位置发生变化。

## 决策

- 在 `pointerup` 先计算释放点的动作目标；没有落在第一层动作按钮时，移动端允许 `dragging` 状态继续参加快滑分类。
- 如果分类成功，恢复按下前的停靠位置、抑制合成 `click`，再分发方向动作；因此快滑不会留下半应用的拖动位置。
- 若释放点命中动作按钮，动作拖放优先，保持原有目标执行语义；若速度/主轴位移不达阈值，继续按普通拖动处理。
- 桌面和侧栏仍只使用拖动目标路径，不改变已有位置保存规则。
