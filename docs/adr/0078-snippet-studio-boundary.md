# ADR 0078：实验代码片段工作室的宿主边界与分期

- 日期：2026-09-25
- 状态：已接受（实验功能，未进入发布承诺）
- 关联：T-6859～T-6862、`docs/snippet-studio-plan-2026-09-25.md`、ADR 0076、ADR 0077
- 上游基线：SiYuan v3.8.5，源码快照位于 `.research/siyuan-v3.8.5`，API 子集由 `tests/fixtures/siyuan-api-contract.json` 生成

## 背景

本插件需要一个用于研究 CSS/JS 代码片段的宽屏工作室。思源原生片段接口是整表替换，没有 compare-and-swap；AI 编辑接口通过 SSE 返回草稿。若把片段当成插件自己的配置，或者把 AI 输出直接写入宿主，会产生跨窗口覆盖、脚本副作用和权限边界不清的问题。

## 决策

1. **原生列表是唯一保存来源。** 工作室读写 `/api/snippet/getSnippet`、`/api/snippet/setSnippet`，写入前只投影 `SnippetInput` 允许的 `id/name/type/content/enabled/disabledInPublish` 字段；内存中保留的未来字段只用于冲突比较，不回传到 `additionalProperties:false` 的接口。保存后再调用 `/api/setting/setSnippet`，沿用思源原生 UI 的刷新通知，让其他窗口执行宿主的 `renderSnippet`。
2. **冲突策略承认宿主能力边界。** 每次变更都会重新读取并比较当前选中行，写入后再次读取确认宿主结果；这能拦住已发生的外部改动和宿主规范化，但整表接口无法阻止“读取后、写入前”发生的并发覆盖。该残余风险不伪装成原子保存，后续若上游提供版本戳再升级。
3. **入口只在桌面页签切换器工具栏。** 不注册快捷键、插件顶栏、侧栏或移动端入口。工作室关闭按钮由 `disableClose` 禁止，返回按钮先检查未保存草稿；插件卸载仍可程序化销毁并把草稿保存在会话内存中。
4. **预览与生产文档隔离。** CSS 预览使用 opaque-origin sandbox iframe；工作室不把预览 DOM 写入笔记。JS 代码保留管理和导出能力，但同步执行的脚本可能用死循环冻结 WebView，因此当前只展示禁用的执行 affordance。Worker 可以终止线程却没有 DOM，不能忠实执行任意 SiYuan 片段；后续若推进，只能先做明确标注为“受限模拟预览”的虚拟 DOM/操作日志子集并补超时、终止和迟到消息测试，完成后另立任务恢复受限执行。
5. **AI 只生成手动审核结果。** 请求只携带当前片段、用户指令和新生成的 `taskID`，使用原生 `/api/ai/editor/chat` SSE；生成、优化和迭代模式返回受限代码草稿，解释模式返回受限纯文本，不把解释误当代码。迭代只通过宿主已有的 `history` 字段携带最近的 user/assistant 对话，不传文档 ID、模型密钥或凭据，不自动启用或保存，取消、超时、过期回包和多余输出均降级为受控错误。官方能力清单是 Agent capability manifest，不能证明编辑器 AI 已配置，因此不增加会触发真实请求的能力预探测；是否可用由正常请求的受控错误反映。
6. **导入、投稿和字体范围受限。** CSS/JS 文件只进入禁用草稿；投稿仅生成本地未审核 JSON 包，没有伪造的社区上传/审核服务。字体只使用片段示例和系统栈，兼容性研究另行记录，不复制字体插件产品面。
7. **包体采用懒加载。** 工作室通过动态 import 进入 `dist/snippet-studio.js` 独立 chunk；发布包保留该子路径，入口在运行时从当前 `index.js` 脚本 URL 设置 Webpack chunk 基址，避免把构建目录和发布根路径混淆；主入口保持在 ADR 0077 的 1024 KiB 自律线内，构建产物和压缩包仍须按现有发布门禁复核。
