# ADR 0179：精选组件补齐入口与商店预览上下文

日期：2026-10-13  
状态：已接受（T-7252）

## 背景

工作台的“恢复默认”实现实际只会将目录中缺少的精选组件补到当前设备布局，不覆盖已有组件或位置；空态以外无法再次使用，入口范围与原型不一致。组件商店原型另以三个静态文本模拟设备分段，而生产只按当前宿主呈现预览，并在预览元信息中显示当前端侧。

## 决策

- 将按钮改称“补齐精选组件”，编辑态非空布局提供同一操作；空态继续保留引导入口。
- 只补当前可用且未布局的精选组件；操作前展示数量并确认，已有布局保留，成功记录入撤销历史。没有缺项时禁用入口并说明原因。
- 商店原型显示当前“桌面预览”，另以“支持主面板 · 侧栏 · 移动端”说明能力范围；不模拟未实现的跨设备切换。

## 验证

- 独立思源 3.8.7-beta.3 工作台与商店 E2E 6/6 通过，覆盖取消、补齐、保留位置、禁用和撤销，以及当前预览端提示。
- 移除工具栏恢复监听、恢复静态设备分段、移除生产预览上下文芯片三种负向注入均使指定测试失败；恢复后各源文件哈希一致。
- 类型检查、生产构建、工作台/商店定向契约、状态索引审计与 `git diff --check` 通过。
