# ADR 0224：按生产接线与环境证据校准完成状态

- 日期：2026-10-18
- 状态：accepted
- 任务：T-7303

## 决策

“代码存在、契约通过、原型可点击、生产可达、真实宿主可用”分别登记。T-7293 完成表示透明度纯模型完成，不表示新增多维筛选 UI；ADR 0218 的噪点、Spotlight/3D、呼吸光晕与语法高亮不视为已交付。本轮只修复可复现的错误，不为追求原型全覆盖直接引入装饰、完整编辑器或新数据源。

JSON 包导入在确认后直接操作原生片段列表，必须说明三模式的启用与覆盖语义；CSS/JS 单文件仍进入禁用草稿。沿用既有 snapshot/签名/原生保存 API，无新存储 key。

Agent 执行必须经过 normalizeWorkspaceStep/executor；计划输出 schema 与实际载荷一致。本地信号可合作取消，但 siyuan@1.2.8 的 handler 不提供执行期 AbortSignal，不声明开始后的宿主取消或撤销保证。生产图因正确接入 executor 从 76 实测变为 77；数量预算随实际接线校准，包体独立门禁不放宽。

依赖安全修复采用 terser-webpack-plugin 同主版本更新与三项定点覆盖，不进行全量依赖升级；以 pnpm audit、类型、全量测试及可复现构建验证。GitHub PR/保护/私密报告仅审计，不代用户合并或更改远端治理策略。
