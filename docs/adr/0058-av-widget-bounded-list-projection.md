# ADR 0058 数据库（属性视图）组件的有界列表投影

日期：2026-09-18　状态：已采纳　关联：T-6330、dev-plan-2026-09-18 §2（v0.23 解锁线调研）

## 背景

思源 v3.8.x 提供了 `/api/av/renderAttributeView` 只读端点（内核 av 契约：`AVTable{Columns, Rows}`，
行单元格为 `AVBaseValue{valueType, value}`）。思源用户大量用数据库管理习惯、书单、追踪器——
这正是小驴打卡桥接组件验证过的场景，但数据源可以是原生的。组件面板接入它是 v0.23 调研
清单的最大机会。

## 决策

1. **列表优先投影，不做表格渲染**。MVP 把当前视图的行投影为面板标准列表项：
   主列（第一个可见列）文本作 label，其余可见列文本取至多 2 个拼接作 value，
   行块 ID 作 value? 不——label/value 之外不再扩字段；点击跳转复用面板既有
   "value=块 ID 打开文档" 约定（绑定的块行即其文档内块；解绑行交给面板的
   BLOCK_ID_RE 兜底）。完整表格渲染（新 viewType、列宽、单元格类型渲染）留待
   真实需求出现再立项。
2. **只读**。不接 `addAttributeViewBlocks`/`updateBlock` 等任何写端点；编辑是宿主
   数据库编辑器的职责。
3. **视图语义交还内核**。请求不带 viewID/query/page——用户在思源里对当前视图做的
   筛选、排序、分组天然生效，插件不复制第二套口径（与打卡桥接"不复制 schedule/quota
   判定"同一原则）。
4. **有界**。行数按组件配置钳制（默认 8，1~12）；单元格文本经 boundedText（120）。
   除文本、块、数字、日期和选择项外，URL、邮箱、电话、复选框、资源名、模板、创建/更新
   时间、关联与汇总也只抽取有界展示文本；递归类型限制深度与条目数，绝不透传原始 JSON。
5. **容错即空态**。av 规格过新（ErrSpecTooNew）、视图缺失、形状不符一律归一为
   null → adapter 转 emptyHint 确定空态；不做部分渲染。
6. **真实宿主证据后置**。av JSON 的版本敏感性高于既有内核端点，本组件上线后必须在
   T-6305 真机会话中补一次真实数据库的读取验证，在此之前 README 不宣称已验证。

## 2026-09-18 增补（T-6348~T-6349）

- 配置页通过有界 SQL 清单提供数据库名称/路径搜索，不再要求用户手工复制块 ID；最终
  仍只保存通过块 ID 校验的值。
- 用户可勾选至多 3 个可见列；投影顺序以勾选顺序为准，第一列继续作为 label，后两列
  作为 secondary。未配置列时保持原有“全部可见列中取前三列”的兼容行为。
- 数据库切换会清空旧列选择，并用请求代际阻止旧数据库的异步列结果覆盖新选择。

## 2026-09-18 深度优化增补（T-6368~T-6371）

- 搜索输入与已绑定块 ID 分离：只有点击结果才更新配置；配置页持续展示已选数据库并提供清除
  操作，数据库名称与路径共同参与搜索。
- 同时兼容 v3.8.x 的 `view.table` 与新版公开 API 的 `view.columns/rows/rowCount`；分组视图读取
  `groups[]` 行源并按 item ID 去重。单元格按 `value.keyID` 关联列，兼容旧 `cell.id/keyID`。
- 点击目标优先使用主键值的 `value.block.id`（绑定块），没有绑定块时才回退 item ID；显示模板
  优先采用 `renderedContent`，数字/日期优先采用内核格式化文本。
- 用户可切换字段名与行号；卡片显示“已显示/总行”以明确截断，数据库详情允许换行；adapter
  使用 1 秒短缓存、1.5 秒超时，手动刷新仍可绕过缓存。

## 后果

- 组件面板获得原生数据库的只读触达，与打卡桥接互补（不依赖第三方插件）。
- 投影层集中在 `kernel-widget-model.js`，形状容错集中一处，后续契约变化只改一个文件。
- 放弃了表格视觉与编辑能力——这是有界 MVP 的明确代价，接受。
