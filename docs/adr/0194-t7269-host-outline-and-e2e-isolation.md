# ADR 0194：真实宿主大纲兼容与隔离 E2E 边界

- 日期：2026-10-15
- 状态：已接受
- 任务：T-7269（T-7144 候选复核的证据子任务）

## 背景

T-7144 的模型和接线测试无法证明真实思源返回形状。隔离思源 3.8.7 的 `/api/outline/getDocOutline` 实测为嵌套节点：根标题在 `name`，子标题在 `content`，文本含 `&nbsp;` 等 HTML 实体。旧的 `flattenOutline` 只读取 `name`，导致真实当前文档大纲只显示根标题。

现有 E2E 启动器只检查回环地址和工作区标记；默认端口被其他进程占用时，启动失败或探测可能落到错误服务，不能把回环地址本身当作隔离证明。

## 决策

- `flattenOutline` 同时读取 `name`/`content`，并在有界文本清洗后解码有限的命名与数值 HTML 实体；保持标题、ID、深度和数量上限。
- 新增 T-7144 隔离 E2E，使用显式临时工作区与专用端口创建测试笔记本，验证标签、同名书签聚合、今日日记待办、笔记统计、近期编辑、当前文档大纲和标签/书签点击路径。
- E2E 启动前拒绝占用端口；内核启动期间和就绪后都要求端口唯一归属于本轮子进程，清理时再次核对，避免向个人内核或其他服务发送退出/写入请求。
- 书签同名记录按宿主模型的 `bookmark` 属性聚合；本轮验证两个文档同名书签返回一个组且块数为 2，不把它当作独立分组缺陷。

## 证据与边界

- 隔离 E2E：`tests/e2e/t7144-widgets.spec.mjs`，思源 3.8.7、专用端口 6841，1/1 通过；测试创建和清理专用笔记本，未访问个人工作区。
- 大纲回归：`tests/agent-outline.test.cjs` 新增真实响应形状；定向套件 75/75 通过。将生产展平逻辑临时还原为只读 `name` 后，该命名测试按预期失败，恢复后源文件 SHA-256 保持一致。
- 端口保护：`tests/e2e-port-guard.test.cjs` 1/1；覆盖占用端口、错误 PID 和启动后唯一归属。临时移除占用检查后具名测试按预期失败，随后恢复源码。
- 配套验证：`pnpm exec tsc --noEmit`、`pnpm run build`、`pnpm run release:check`、`node scripts/current-status-audit.cjs`、`git diff --check` 均通过；工作树快照为 `dist/index.js` 1142825 B、`package.zip` 591540 B。
- 当前仍没有真人使用频率证据；T-7144 的“高价值”排序仍需 T-7168 或问题记录支持。近期编辑大库规模观测已由 [ADR 0195](0195-t7270-recent-edits-host-scale.md) 单独记录；旧宿主字段兼容和标签精确定位继续保持待证，不因隔离样本销号。
