# ADR 0192：复合间距刻度的精确迁移

日期：2026-10-14
状态：已接受（T-7266）

## 背景

样式审计在 17 个 SCSS 文件中统计了 1142 条 `gap`、`padding`、`margin` 家族声明。已有 4/6/8/12/16/24px 间距刻度，但复合简写中仍重复出现可等值迁移的正向分量。直接扩大迁移范围会碰到负偏移、函数参数、安全区计算和非刻度几何，可能改变布局或掩盖特殊语义。

## 决策

- 六档生产间距由 `_00-tokens.scss` 中的 `$sw-space-xs` 至 `$sw-space-2xl` 编译期变量作为单一来源，并生成既有 `--sw-space-*` 运行时接口。
- 只迁移顶层、正值且精确匹配六档的 `gap`、`padding`、`margin` 家族分量；复合简写只替换命中的分量，其他值和 fallback 原样保留。
- 负值、`calc()`/`env()` 函数内部数值、非刻度特化值、结构化安全区表达式不在本批范围内。
- 门禁同时检查生产样式、编译期来源和运行时来源；注入裸字面量必须使门禁失败。

## 验证

- `tests/spacing-token-migration.test.cjs`、`tests/space-scale-gate.test.cjs`、商店移动布局/外部契约与商店 UI 定向回归：768/768。
- 将 `_01-base-controls.scss` 的真实迁移声明临时改回 `padding: 4px`，迁移门禁按预期失败；恢复后源文件 SHA-256 与注入前一致。日志见 `.artifacts/t7266-negative-spacing-probe.log`。

## 边界

本批以维护一致性为目的，不改变设计密度和组件几何。审计的“完整声明值种类”按整条声明字符串统计，复合值可能包含多个长度，不应解读为减少了 80 种独立像素尺寸。现有 4/6/8/12/16/24px 六档均属于 2px 基准栅格；6px 是既有紧凑档，不强行改为 4px 的倍数。10/14/18px 等特化值和安全区函数需要单独的视觉与语义评估。
