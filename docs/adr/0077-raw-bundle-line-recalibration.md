# ADR 0077：raw 包体自律线三次校准（960→1024 KiB）

- 日期：2026-09-24
- 状态：已接受
- 关联：ADR 0074（896→960）、ADR 0067（832→896）、ADR 0062（768→832）、D-353（512 KiB zip 硬上限，不变）
- 关联任务：T-6814（关联内容只读适配）、T-6815（恢复回执+分层快照）、T-6816（Alt+点击预览）、T-6817（动态收藏组组合查询）、T-6818（多目标快速捕获）

## 背景

raw 自律线（`scripts/release-readiness-metrics.cjs` 的 `RAW_BUNDLE_BUDGET_BYTES`，960 KiB=983040 字节）仍是"评审信号"而非宿主硬限制；512 KiB zip 硬上限与压缩条目线不变。工作上下文批（T-6814 关联内容适配器/工作台区、T-6815 回执、T-6816 预览、T-6817 动态组组合条件、T-6818 多目标捕获对话框）落地后实测 raw 达 984939 字节，越过自律线 ~1.9KB。

## 增量的真实来源（ADR 0076 五阶段的既定任务，非碎片堆积）

- T-6814：`related-content-model.js` 有界投影 + 工作台关联行 + 端点白名单/契约夹具；
- T-6815：Essentials 回执、文档集 presetId 分层固化、统一恢复摘要；
- T-6816：Alt+点击预览打开（doc.mode 透传 + 可发现性提示）；
- T-6817：动态组笔记本范围与更新时间窗（模型、管理器双下拉、行内条件展示）；
- T-6818：快速捕获多目标切换（日记/当前文档）、目的地预览行、分步失败原因、回执。

## 决定

1. `RAW_BUNDLE_BUDGET_BYTES` 校准为 **1024 KiB**（1048576 字节），按 0062/0067/0074 先例 +64 KiB 步进；
2. 512 KiB zip 硬上限与压缩条目线不变（当前 zip 实测 ~438KB，余量充足）；
3. `tests/second-round-widgets.test.cjs` 的常量钉死断言更新为 1024 * 1024，ADR 校验指向 0077；
4. `tests/host/release-quality.test.cjs` 的校准日期备注同步 2026-09-24（ADR 0077）；
5. 依据用户 2026-09-23/24 指令：数量类门禁只作观测护栏，因合理增量触发时按实测校准，不阻挡功能；包体复合增长率继续由 readiness 快照逐版记录观测。
