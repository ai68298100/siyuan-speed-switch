# ADR 0137：元数据未提交输入与部分保存恢复

- 状态：已采纳
- 日期：2026-10-04
- 任务：T-7098 / AB-1306 / AB-1701

目录字段只监听 change 会漏掉未失焦输入；原生保存成功但侧车失败时重新选择条目会清空待保存元数据，并错误放行保存后离开。原生写后的只读核对成功分支原来也没有走元数据收尾。

input 立即保存目录字段到当前 session 并更新脏稿状态，保留输入中的分隔符和光标；其他字段同步优先读取待提交元数据。已有片段仍在 change 时独立提交目录字段；成功后清除待提交值，失败保持可编辑与离开守卫。比较只使用有界归一化后的别名、摘要、标签和置顶，不比较 ID 或观察时间。

直接写成功与写后核对成功共用收尾。原生保存成功后更新原生 baseline，侧车失败时保留相同 ID 及元数据草稿，返回未全部保存，停留并允许重试。两个存储没有跨通道原子事务，不回滚已经成功的原生写入，不把侧车通道接受写入等同于磁盘持久化完成。已有全局存储失败回执继续负责异步持久化错误。

真实挂载测试覆盖未失焦输入、跨字段重绘、原生目录字段失败、直接/晚确认保存失败和同 ID 重试。精确负向探针删除 input 更新、输入保护、待提交优先读取、失败保留、失败返回及晚确认收尾，分别须触发对应测试。隔离思源 E2E 的适配器拒绝和通知失败是受控故障证据，与真实设备/文件系统故障分开记录。
