# ADR 0170：精确分类 E2E 正常关停日志

日期：2026-10-12

状态：已接受，T-7245

## 背景

独立思源内核 E2E 通过后，正常退出 HTTP server 会留下 cmux 的 `mux: server closed` 错误级日志。旧分类器把它计入错误摘要，造成成功运行显示警告；但全局过滤该文案会掩盖真实监听错误或异常关闭。

## 决策

- 只在 `exited kernel`、HTTP server 关闭开始、精确 cmux 记录、HTTP server 关闭完成的顺序上下文中忽略该条摘要。
- 不修改原始内核日志，不屏蔽其他错误/警告，不把不完整、乱序、相似文案或跨关闭尝试复用的上下文当成正常结束。
- 测试调用生产 `kernelErrorLines()`，并覆盖真实关闭样本、缺标记、顺序错误、其他错误和重复关闭边界。

## 验证

`tests/e2e-kernel-log.test.cjs` 定向测试 7/7。两条真实源码负向探针分别禁用完整上下文过滤、绕过内核退出标记，均以预期测试名失败；探针完成后 `scripts/e2e/lib.mjs` SHA-256 还原为 `76102b9fa3cea62aef74cf353104e3516910b92abf56f97fc92005d5e5cf7435`。本逻辑只改 E2E 诊断摘要，不改变插件运行时行为。
