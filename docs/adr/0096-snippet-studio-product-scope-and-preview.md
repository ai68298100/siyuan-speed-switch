# ADR 0096：片段实验室产品范围与预览契约（提案）

- 日期：2026-09-28
- 状态：提案，等待用户确认后施工
- 关联：T-6985～T-6996、ADR 0078、ADR 0080、ADR 0083、ADR 0086

## 背景

片段实验室的原生管理、草稿保护、AI diff 和 CSS 沙箱已经存在，但历史文档同时保留 R1/R2 原型、早期“进行中”状态和后续已完成任务。用户当前需要看到第三面板到底完成到哪里，以及预览能否随着 CSS 内容合理变化。

## 提议决策

1. **R2 是现行原型**：预览主区 4fr，主区下排为属性 2fr 与编辑器 3fr，AI 为右栏，目录为浮层选择器；R1 常驻目录只作为未来布局实验，不作为当前缺陷判定依据。
2. **第三面板补齐尺寸模式**：增加 fullscreen/adaptive/custom，与另外两个面板共享 `resolvePanelSize` 语义；新装默认继续 fullscreen，旧用户显式设置不被迁移覆盖。
3. **预览是安全近似，不追求真实文档渲染**：场景由有界静态 fixture 构成，保留思源常用块语义和 `data-node-id/type/subtype`；CSS 根据有界 coverage analyzer 追加命中探针；不加载个人文档、整套宿主 CSS 或网络资源。
4. **预览回执必须说明近似范围**：展示场景、宽度、主题 profile、探针命中、脚本禁用、网络禁用和可能未命中 selector；baseline 对照不追加探针。
5. **JS 默认继续 blocked**：若未来开放受限模拟执行，必须另立 ADR 和可终止 runner 合同；在此之前移除“可执行”暗示比长期保留一个永久 disabled 的运行按钮更诚实。
6. **CSS 自适应按覆盖证据扩展**：先升级 selector/声明诊断和主题 token bridge，再增加任务、富文本、Callout、列、公式、媒体等静态场景，不按固定样例数量衡量完成度。

## 取舍

- 真实文档/主题渲染的忠实度更高，但会引入个人数据、宿主 DOM、网络和插件兼容风险；安全近似预览牺牲部分忠实度，换取可重复、可离线、可测试。
- 全屏默认保留现有 R2 密度和用户反馈；补齐 adaptive/custom 满足尺寸统一需求，但设置与 resize 接线会增加任务面，必须单独验收。
- 完整 CSS 解析器或 stylelint 依赖会增加包体和复杂度；先做有界诊断子集，必要时再以独立 ADR 评估解析器。

## 退出条件

- 用户确认本提案及 T-6986～T-6996 优先级。
- 尺寸模式、预览契约、主题 bridge 和 CSS coverage 负向测试通过。
- 真实桌面证据单列 B-005；没有宿主证据时只报告本地实现和限制。
