# ADR 0251：T-7359 符号导航速查指引与全量文档对账

日期：2026-10-21  
状态：accepted  
任务：T-7359  

## 背景

随着穿透检索前缀扩充（`@`大纲、`#`标签、`!`书签、`^`正文块、`>`命令模式）以及卡片免呼出直达快捷键（`Ctrl+Shift+T`、`⌘⇧S`、`Alt+R/V` 等）的连续落地，用户需要零学习成本的即时可发现性提示；同时，中英文 README、CHANGELOG 变更日志需完整对账。

## 决策

1. **`?` 符号导航速查指引（CheatSheet）**：
   - `SEARCH_MODES` 扩展 `HELP: "help"`；
   - 包含 `@`大纲、`#`标签、`!`书签、`^`正文块、`>`命令、`⌘K`画板、`Ctrl+Shift+T`撤销、`⌘⇧S`文档集快照与 `Alt+R/V` 思阅/思播生态联动等 8 条核心指引；
   - 输入 `?` 或 `？` 时在内存中纯本地瞬时聚合返回，零网络开销。
2. **中英文文档与快捷键对账完备**：
   - 同步更新 `README.md` 与 `README.en-US.md` 快捷键表格；
   - 更新 `docs/CHANGELOG.md` 与 `docs/CHANGELOG.en-US.md` 完整登记 v0.48.0 增量特性。
3. **包体预算与观察线校准**：
   - 依据 ADR 0251 将 raw bundle 观察线由 1182 KiB 微调至 1186 KiB（1,214,464 B，实测 1,211,534 B，余量约 2.9 KiB）；
   - 归档包上限相应由 594 KiB 微调至 596 KiB（610,304 B，实际 package.zip 为 608,361 B，余量约 1.9 KiB）；
   - 单条目压缩上限维持 320 KiB 不变。

## 证据与验证

1. **定向测试**：`tests/symbol-cheatsheet-and-docs-reconciliation.test.cjs` 5/5 通过；
2. **多语言与单测**：全量单测全部通过；四大批量审计全部 PASS。
