# ADR 0157：顶栏分段导航与稳定命中层

- **日期**：2026-10-09
- **状态**：accepted
- **关联任务**：T-7228
- **范围**：统一平台顶栏的切换器、工作台、片段实验室入口与关闭动作

## 背景

用户反馈鼠标停在顶栏入口时没有稳定的 hover 或点击反馈，必须反复移动指针才能触发。入口文字没有说明用途，当前表面与可切换表面也缺少统一的控件边界；宿主按钮皮肤、提示节点和透明内层进一步放大了命中不稳定。

## 决策

1. **采用分段控件原型**：三个表面入口放进同一连续导航容器，默认保留边界和底色；当前项以强调色和“当前”语义区分，可切换项保持真实 `button`。
2. **入口自带用途信息**：每项显示稳定图标，并通过 `title` 与 `aria-label` 给出用途提示；图标和文字设置 `pointer-events: none`，事件归属外层入口。
3. **命中层由控件自持**：入口和关闭钮声明 `pointer-events: auto`、`touch-action: manipulation`、原生按钮外观重置与独立层级，避免宿主皮肤或提示节点改变点击目标。
4. **状态反馈不延迟**：hover、focus-visible、active 采用即时样式；当前项也保留 hover/focus 反馈，关闭钮扩大桌面命中尺寸并在粗指针环境保持 44px。

## 验证要求

- 顶栏 DOM、用途提示、当前状态、命中层和负向删除注入必须有契约测试。
- 运行完整测试、TypeScript、构建、发布检查和 surface-switch/UI smoke；真实最窄侧栏、读屏和 Android 仍按 `BLOCKERS.md` 取证。
