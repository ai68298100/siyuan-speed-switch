# ADR 0195：近期编辑真实宿主规模证据边界

- 日期：2026-10-15
- 状态：已接受
- 任务：T-7270（T-7144 候选复核的证据子任务）

## 背景

`recent-edits` 已有 SQL 口径、排序和条数上限的模型/接线测试，但 T-7144 仍缺少真实思源宿主中较大文档集的读取耗时证据。单次空库或少量样本不能说明 1200 ms 适配器超时是否过紧，也不能证明真人使用频率。

## 决策

- 用专用、带标记的临时思源工作区创建 96 篇测试文档，连续 8 次强制刷新同一笔记本范围的 `recent-edits`，固定 30 天窗口、5 条返回上限和查询词。
- 将结果记录为宿主读取路径的观测，不把合成 96 篇规模外推为个人工作区性能，也不因一次绿色测量修改分页、缓存或超时策略。
- 测试结束删除临时笔记本；报告只保留笔记本 ID、样本耗时和返回条数，不包含个人笔记内容。

## 证据与边界

- 8/8 次读取成功且返回 5 条，p50 1.4 ms、p95 3 ms；低于当前 1200 ms 适配器超时。
- 证据文件：`.artifacts/T-7270-recent-edits-scale.json`。
- 该结果只关闭“当前隔离规模下存在明显读取超时”的疑问；真人使用频率、极端大库、旧宿主 SQL 字段差异仍待其他证据。
