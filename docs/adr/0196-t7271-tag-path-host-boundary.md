# ADR 0196：标签层级路径与原生入口边界

- 日期：2026-10-15
- 状态：已接受
- 任务：T-7271（T-7144 候选复核的证据子任务）

## 背景

标签组件将宿主返回的层级树投影为可点击叶节点和不可点击的虚拟父节点。旧审计记录曾把标签路径值和原生 dock 的精确选择能力列为待证，但当前思源版本没有公开的 dock 选择方法，只有显示/隐藏入口。

## 决策

- 保留 `tag:<完整层级路径>` 作为叶节点动作值；父节点在没有直接块计数时保持虚拟、无动作值，避免打开一个无法定位的目标。
- 点击标签只调用宿主公开的 `toggleModel("tag", true)`，不伪造或反射调用未公开的“选中某标签”接口。
- 如果未来思源提供稳定 tag ID 或显式筛选参数，再单独扩展精确定位协议并补宿主 E2E；当前不因缺少公开选择 API 修改生产代码。

## 证据与边界

- 隔离思源 3.8.7 中，`parent/child` 返回虚拟父项和完整路径的叶项；叶项点击实际调用 `toggleModel("tag", true)`。
- 证据文件：`.artifacts/T-7271-tag-path-probe.json`。
- 该结果证明当前宿主协议下路径不会被插件截断；不证明原生 tag dock 会自动选中某一标签，也不替代真人频率证据。
