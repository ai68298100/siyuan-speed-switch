# ADR 0252：T-7360 组件商店核心精选推荐（Featured）机制与微标头分层

日期：2026-10-21  
状态：accepted  
任务：T-7360  

## 背景

工作台目前已积累 58+ 个组件（涵盖思源原生、小驴打卡桥接、生活资讯及第三方扩展）。由于组件种类丰富，若在商店中无差别的全量平铺，将给用户带来巨大的认知与筛选负担（“给用户太多选择就是没有选择”）。

## 决策

1. **核心黄金精选推荐清单（`HOME_FEATURED_MODULE_IDS`）**：
   - 筛选出高频、高价值、零或低依赖的核心 12 项组件（近期文档、今日日记、今日待办、属性看板、闪卡复习、笔记统计、年度进度、时间日期、收藏、文档集、天气、今日打卡）；
2. **商店分类分层与推荐筛选页签**：
   - `STORE_TABS` 强化 `recommended`（⭐ 精选推荐）；
   - 卡片在全部与分类视图中，精选组件均自动渲染高质感金色微光徽标（`.sw-home-store__badge--featured`）与微高光边框；
3. **包体预算与观察线校准**：
   - 依据 ADR 0252 将 raw bundle 观察线由 1186 KiB 微调至 1188 KiB（1,216,512 B，实测 1,214,983 B，余量约 1.5 KiB）；
   - 归档包门限维持 596 KiB（610,304 B，实测 609,592 B，余量 712 B）不变；
   - 单条目压缩上限维持 320 KiB 不变。

## 证据与验证

1. **定向测试**：`tests/home-store-featured-and-curation.test.cjs` 5/5 通过；
2. **既有契约**：`tests/home-store-model.test.cjs` 427/427 全绿通过；
3. **全量单测与审计**：8982 项单测全绿，四大批量审计全部 PASS。
