# ADR 0074：raw 包体自律线二次校准（896→960 KiB）

- 日期：2026-09-23
- 状态：已接受
- 关联：ADR 0062（768→832）、ADR 0067（832→896）、D-353（512 KiB zip 硬上限，不变）
- 关联任务：T-6789~T-6802（悬浮球宿主命令桥、一键同步、插入模板、统一索引、工作区切换、搜索语法）

## 背景

raw 自律线（`scripts/release-readiness-metrics.cjs` 的 `RAW_BUNDLE_BUDGET_BYTES`，896 KiB=917504 字节）是"评审信号"而非宿主硬限制；512 KiB zip 硬上限与 256 KiB 压缩条目线不变。R1-A 吸收批落地后实测 raw 达 915415 字节，距自律线仅 ~2KB——后续任何功能（搜索语法、场景预设、动态收藏组、皮肤层）都会触线。

## 增量的真实来源（不是失控，是用户指令的功能面）

- T-6789/T-6790：宿主命令桥（能力检测 + globalCommand 分发）与 9 条命令目录；
- T-6791/T-6792：一键同步（内核写端点接入）与插入模板（清单/渲染/光标写入）；
- T-6799~T-6801：切换器统一索引、文档集工作区切换、重开滚动现场；
- 后续已排期：搜索语法、场景预设、动态收藏组、皮肤层（CSS 为主）。

以上均为 R1 调研吸收批与用户指令功能，不是碎片堆积；继续增长须复核 512 KiB 包体门禁（D-353）。

## 决策

1. `RAW_BUNDLE_BUDGET_BYTES` 校准为 **960 KiB**（983040 字节），按 0062/0067 先例 +64 KiB 步进；
2. 512 KiB zip 硬上限、256 KiB 压缩条目线、漂移诊断全部不变；
3. `second-round-widgets` 中钉死常量值的断言同步更新，并改为校验 ADR 0074 的存在与数值；
4. 下一次校准前必须先消耗完本档余量并附新一轮审计说明。

## 验证

- `tests/host/release-quality.test.cjs` 的 `bytes <= budget` 断言继续有效（换常量值）；
- `tests/second-round-widgets.test.cjs` 的常量钉死断言更新为 960 * 1024，ADR 校验指向 0074；
- 本 ADR 与 release-readiness 快照的 Current build 行保持实测一致。
