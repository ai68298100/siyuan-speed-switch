# ADR 0262：T-7363 中文全角穿透符号自适应与 v0.48.5 发版

日期：2026-10-23  
状态：accepted  
任务：T-7363  

## 背景

中文用户在使用思源笔记时，键盘输入法通常处于中文状态。在此状态下键入常用前缀符号会产生全角字符（例如 Shift+1 产出 `！`、Shift+. 产出 `》`、直接键入冒号产出 `：`），之前系统仅对半角 ASCII 符号触发模式切换，导致中文用户必须频繁切换输入法英汉状态，存在操作摩擦。

## 决策

1. **中文全角穿透符号智能自适应（Punctuation Adaptive Routing）**：
   - 在 `src/penetration-search-model.js` 与 `src/index.ts` 中全面支持中文全角标点：
     - `！` 自动映射为书签搜索模式（`!`）；
     - `》` 自动映射为命令面板模式（`>`）；
     - `：` 自动识别为文档大纲穿透分隔符（`:`）；
     - `？` 自动映射为符号速查指引（`?`）；
   - 切换器模式药丸栏（`.sw__mode-chips-bar`）与输入框 Placeholder 在输入全角标点时同步联动高亮与切换提示；
2. **移动端切换器 Dialog 统一品牌标题栏**：
   - 在 `createMobileSwitcherDialog` 中同步装配 `mountPlatformDialogTitleWrap`，使移动端弹窗具备标准 22×22 星际深紫底白标与版本胶囊；
3. **版本晋级与集市发布闭环**：
   - 严格执行小版本递增：`0.48.4` -> `0.48.5`，并在 GitHub 发布 Release `v0.48.5`，确保集市爬虫准时索引。

## 证据与验证

1. **定向测试**：`tests/dialog-title-wrap-and-midnight-tile-contract.test.cjs` 5/5 通过（包含中文全角符号映射断言）；
2. **全量单测与审计**：9058+ 项测试全绿，四大批量审计全部 PASS。
