# ADR 0123：片段分组的插件侧元数据与原生列表对账

- 状态：已采纳
- 日期：2026-10-04
- 任务：T-6972

## 背景

片段实验室管理的是思源原生片段。分组属于插件的组织偏好，不能写入原生片段正文、启用状态或宿主未承诺的配置字段；同时，片段可能在思源设置或其他窗口中被删除，插件必须避免保留不可见的幽灵归属。

## 决策

1. 使用独立持久化 key `sw_snippet_groups`，结构版本为 `1`，只保存分组 `id/name/collapsed`、片段 ID 归属、`tree/flat` 视图和未分组显示偏好。
2. 读写统一经过 `normalizeSnippetGroupStore`，最多 64 个分组、256 条归属；名称与 ID 清洗、去重，未知版本整体回退为空 store。
3. 使用 `reconcileSnippetGroups(store, nativeSnippets)` 作为纯函数对账入口。原生片段 ID 是唯一事实源；原生列表消失的归属在下次读取时清除，仍存在但没有归属的片段进入“未分组”。
4. 删除分组只删除插件侧归属，片段回到“未分组”，绝不调用原生删除接口。拖放只调用插件侧归属更新；内置示例片段可浏览但不参与分组拖放。
5. 树形视图展示可折叠分组头和平铺视图展示组名标签；视图偏好与折叠状态持久化。触控尺寸、焦点轮廓和 reduced-motion 沿用片段实验室现有规则。

## 取舍与边界

- 归属按单片段单分组处理，重复归属以首个合法记录为准，避免多组同时渲染同一原生片段。
- 当前片段实验室仍由桌面宿主开放，真实 Android 触控和最窄侧栏观感继续归入 B-004/B-005；jsdom 交互测试只证明 DOM 事件和插件存储接线。
- 不引入 Gist、文件夹监视或 CodeMirror；这些能力有独立的安全、体积和宿主边界，不因分组任务顺带扩大范围。

## 验证

- `tests/snippet-groups.test.cjs` 覆盖清洗、容量上限、CRUD、外部删除对账和 256 个组合场景。
- `tests/snippet-groups-ui.test.cjs` 执行真实挂载、建组、拖放归组、折叠和平铺偏好持久化。
- 存储兼容矩阵、迁移、Agent 健康 schema 和双语存储用量登记同步到 18 个 key。
