# ADR 0067 B4 后 raw bundle 自律线校准

状态：已接受（2026-09-21）

悬浮球 B4 增加了闲置态、边缘半隐藏、全屏/页面可见性让位、原因聚合、无障碍禁用语义和生命周期清理。这些代码属于用户明确要求的核心功能；继续为了守住 832 KiB 的内部预警数字而拆散或削弱功能，会把自律线误当成产品限制。

本次将 raw `dist/index.js` 的自律线从 832 KiB 调整为 **896 KiB**（917504 bytes）。该数字是带日期和增量来源的评审线，用于识别异常膨胀，不是思源宿主限制，也不是删减功能的理由。

不变的约束：

1. `package.zip` 512 KiB 归档硬上限不变；
2. `index.js` 压缩后 256 KiB 单条目评审线不变；
3. 生产图、可复现构建、发布/质量/集成审计继续运行；
4. 下一次跨越 896 KiB 仍须记录真实增量来源并做同条件负向验证。

验证：将 896 KiB 临时改为低于当前产物的值时，raw bundle 目标门禁必须按名称失败；恢复原字节后，门禁通过且文件 SHA-256 与注入前一致。历史的 832 KiB 校准记录保留在 ADR 0062，不改写历史事实。
