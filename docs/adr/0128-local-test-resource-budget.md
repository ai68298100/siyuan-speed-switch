# ADR 0128：多插件开发时限制本仓单元测试并发

- 状态：已采纳
- 日期：2026-10-04
- 任务：T-7088
- 关联：T-7085、T-6973

## 背景

独立工作区、端口和产物目录隔离了 E2E 的数据与进程所有权，但多个插件仍共享 CPU 和内存。T-6973 首轮全量测试按 Node 默认 CPU 数量并发，耗时 258 秒；出现一项悬浮球 DOM 重绘时序失败，同期隔离内核启动超时。悬浮球单独复验 21/21 通过，内核在资源释放后原工作区重试成功；不改功能或放宽断言来消除这类时序失败。

## 决策

测试入口仍完整发现顶层与 host 的所有测试文件，默认限制为 4 个文件并发。SWSS_TEST_CONCURRENCY 可按共享机器资源指定 1～8；非法值直接退出，避免意外退回无限并发。E2E 继续每内核一个 worker，同一轮先让高负载全量测试收尾再补宿主验收，不抢占其他插件的实例或终止其进程。

这是资源预算，不能保证多个实例完全互不影响。数据隔离与机器资源竞争分别记录；失败仍保留具体测试名、日志和重试结果。
