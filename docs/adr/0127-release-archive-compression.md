# ADR 0127：发布 ZIP 使用兼容压缩器与最高压缩级别

- 状态：已采纳
- 日期：2026-10-04
- 任务：T-7087（T-6973 收口时发现）

## 背景与决策

Gist 功能的初次构建归档为 590,930 B，比现行 576 KiB 上限超出 1,106 B。归档器 zip-webpack-plugin 4.0.3 所带 yazl 2.5.1 不支持 compressionLevel；添加未生效的配置不能解决压缩问题。

只为 zip-webpack-plugin 覆盖 yazl 到 API 兼容的 3.3.1，并显式设置 compressionLevel 9。保持文件内容、路径、权限、提交时间戳和解压格式，继续执行连续双构建哈希核对。原预算均不放宽，主入口 raw 上限仍为 1160 KiB、归档仍为 576 KiB、主入口压缩条目仍为 320 KiB。

同时修正 readiness-snapshot 的事实同步：旧正则不能匹配 1160 KiB/ADR 0125，ZIP 行还写死 512 KiB，导致刷新后不同表格行不一致。尺寸与预算数值均从现行共享常量生成。

## 验证

负向探针核对指定失败项与源码字节恢复。包体校验、连续双构建和全量门禁共同验证归档可用性与可复现性；提高压缩级别只影响构建耗时，不改变运行时行为。
