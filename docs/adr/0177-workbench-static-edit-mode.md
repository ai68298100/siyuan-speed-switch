# ADR 0177：工作台采用静态编辑态反馈

日期：2026-10-13  
状态：已接受（T-7250）

## 背景

第二面板编辑态沿用早期原型的 iOS 摇摆效果，为每张组件卡持续运行 320ms 无限旋转动画。独立思源内核浏览器测量确认：查看态 1.6 秒内没有动画或根节点变更；进入编辑态后每张卡均启动该动画，且卡片边界持续变化。工作台经表面导航返回时会恢复编辑态，因此持续摇摆会被感知为频闪或面板抖动。

分钟/秒级时钟及联网组件心跳走单卡 controller 刷新，不会周期性重建整个面板；本轮未发现其造成查看态持续闪烁的证据。

## 决策

- 移除编辑态卡片的无限摇摆动画和专属 keyframes。
- 保留静态虚线轮廓、拖动把手、尺寸选择、删除操作和落点提示，继续清楚表达编辑状态。
- 同步更新工作台原型与编辑态接线契约，避免原型或测试重新要求无限动效。
- 编辑状态仍可按既有行为经工作台表面导航恢复；恢复后也不得启动循环动画。

## 验证

- 独立思源内核 Playwright 检查进入编辑态和离开后返回：卡片 computed `animation-name` 为 `none`、无运行中动画，虚线框/拖动把手存在。
- 静态编辑态契约测试；负向注入重新添加摇摆动画后，指定契约测试按预期失败，源码恢复后通过。
- 工作台与片段实验室定向 E2E、类型检查、构建和 `git diff --check`。
