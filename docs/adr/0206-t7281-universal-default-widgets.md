# ADR 0206：通用默认七组件与独立紧凑排版

- 日期：2026-10-16
- 状态：已完成
- 任务：T-7281
- 相关：ADR 0202～0205

## 背景

用户要求第二面板默认显示更多通用组件，并分别优化 UI。已有四卡偏重导航/任务，首次打开缺少无需已有笔记内容也能显示的信息。

## 决策

1. 默认组合增加时间与日期、年度进度、笔记统计，共七项。前两项本地计算，统计只读思源本地汇总；无需账号、定位或公网请求。月历需要完整日期网格，天气需要城市配置，倒数需要目标日期，留在商店按需添加。
2. 时间使用紧凑时刻、日期与细日进度；年度进度使用百分数、细进度条和并排天数，均为 small 4×3；统计使用 wide 8×3，将主数值与两列明细并排。仅桌面 compact 收敛样式，统一中性材质；三项均为 96px 卡片。
3. 新装播种七项，旧完整原样四卡仅补三项空位，保留旧坐标和尺寸。缺卡、禁用、配置或布局已调整的状态不自动补卡；引入默认初始化版本，避免删空后自动复活。空态恢复入口同步使用通用组合。
4. 保持现有紧凑窗口，新增内容由画布滚动承载；不为了组件数量放大窗口。各卡保留配置/折叠、异常明文和完整可读信息。

## 实现与验证

默认声明与初始化模型复用 `src/home-model.js`，保持生产依赖图 76 模块门禁。保存初始化版本单调递增，撤销或删空不再触发首次播种；移动端先打开原样旧桌面四卡不提前消耗升级标记。显式恢复默认保留已有实例的配置与尺寸，取消时不写入；商店全局默认尺寸不变。时钟心跳同步日进度、标题提示与健康信息，fresh/stale 切换重建视图，连续 stale 保留失败明文。统计错误态保留全宽重试，宿主图标改用实际存在的 `iconGraph`。
