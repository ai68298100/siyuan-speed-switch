# ADR 0176：片段实验室窄屏滚动与触控命中区

日期：2026-10-13  
状态：已接受（T-7249）

## 背景

R54 适配层在不超过 560px 的容器中把片段实验室主布局设为 `overflow: hidden`，同时编辑区和 AI 辅助区保留较大的最小高度。片段实验室根节点本身也锁定溢出，因此短窗口中编辑器或 AI 区尾部可能没有可滚动的祖先。目录筛选按钮仍沿用 32px 高度，未纳入粗指针的 44px 命中区规则。

## 决策

- 保留 560px 容器断点和现有纵向排列；将唯一主滚动责任交给 `.sw-studio__layout`，设置 `min-height: 0`、纵向自动滚动和横向裁切，保留片段实验室的固定顶栏与底部主操作区。
- 不缩短编辑器、预览或 AI 内容以迁就短窗口；用户应能通过主布局滚动访问完整区域。
- 粗指针下将片段类型筛选按钮纳入 44px 最小高度规则。
- 同步 R4 原型的窄屏状态：目录、编辑器和辅助建议纵向排列，主工作区独立滚动，原有桌面专属提示不再显示。

## 验证

- 独立思源内核 Playwright 覆盖 520×600 的片段实验室滚动区、目录/编辑器/AI 可达性、AI 尾部动作和横向溢出；粗指针 context 等待面板入场动画完成后确认筛选按钮实测高度不少于 44px、计算最小高度为 44px 且无 transform。
- TypeScript、样式适配定向测试、生产构建和 `git diff --check`。
- 自动化容器不能替代 Android 真机或思源最窄原生侧栏验收；继续按 `BLOCKERS.md` 后置。
