# ADR 0153：三面板紧急布局与宿主标题栏边界

- 状态：已接受
- 日期：2026-10-09
- 关联任务：T-7221、T-7222、T-7223、T-7224

## 背景

v0.46.1 在宿主实际显示中暴露出三类回归：片段实验室的三个同级区域仍使用双列网格；平台弹窗同时显示宿主原生标题和平台自有标题；第一面板预览请求把第三参数的取消选项误判为超时值。组件商店在部分主题中也失去原生标题栏关闭钮。

## 决策

1. 片段实验室桌面布局固定为库列表、编辑区、AI 预览三列，窄容器降级为纵向流式布局。网格列宽使用有界值，库列表和预览各自滚动，避免任一侧挤压编辑区。
2. 带有 `sw-platform-dialog` 的弹窗由平台自有顶栏负责标题和关闭动作，隐藏直属原生 Dialog 标题行并清除其顶部内边距，避免重复标题和双重留白。
3. `fetchKernelJson` 在边界统一兼容旧的数字超时参数和 UI 模块传入的第三参数 AbortSignal 选项，保持旧调用方兼容。
4. 组件商店在内容区保留独立关闭按钮，使用现有 Dialog 销毁和焦点恢复链路，不依赖宿主主题对原生标题栏的呈现。

## 取舍与验证

- 预览栏采用 34%（280～480px）有界宽度，优先保证可读性；小容器继续走既有单列降级。
- 关闭按钮在触屏设备扩大到 44px，桌面保持 32px，满足触摸目标而不改变商店主体密度。
- T-7221～T-7223 契约均执行过负向注入：旧双列布局、错误超时归一化、缺失关闭销毁动作会精确失败，并在验证后恢复源码字节。
