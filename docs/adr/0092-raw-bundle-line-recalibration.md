# ADR 0092：raw 包体自律线校准 1088 → 1120 KiB

- 日期：2026-09-28
- 状态：已采纳（T-6979 开工前）
- 关联：ADR 0059、0081、0089、0090；`docs/handoff-2026-09-28.md`

## 背景与减量审计

v0.41.0 基线 `dist/index.js` 为 1,113,051 B，距 1088 KiB 自律线仅 1,061 B。T-6979 要修复切换器中已确认的片段入口错位、收藏分组遮挡和任务速览失真；后续商店 S2 与组件规格施工也均属用户可见功能，不能假设剩余空间足够。

- raw 线只度量入口 JS，CSS 修正和独立的片段实验室动态 chunk 不在此线内；增量仍应放在原有责任模块。
- 删除无查询态的冗余片段 chips 行会回收少量入口代码，但任务速览的任务语义与必要的 UI 接线仍可能使净增量越线。
- 既有产物由 tree-shaking 构建，集市必需资产与已经拆出的低频 chunk 不提供可安全移除的入口死重量；不为凑数字删用户已用功能。

## 决策

1. `RAW_BUNDLE_BUDGET_BYTES` 从 1088 KiB 上调至 **1120 KiB**（+32 KiB，本轮仅为自律观测线）。
2. 归档上限 544 KiB、压缩入口线 320 KiB、漂移容差 1 KiB 不变；每批仍须构建、复核实际尺寸与异常增长。
3. 本轮不发布、不 push、不触碰个人安装。新增或修改门禁按 `docs/gate-audit-checklist.md` 注入违规验证，真实宿主与 Android 结论继续单独后置。

## 后果

`scripts/release-readiness-metrics.cjs`、快照文案及预算相关测试同步校准；若后续再次逼近本线，须重新做减量审计并另记 ADR，不能静默抬线。
