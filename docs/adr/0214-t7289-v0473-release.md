# ADR 0214：v0.47.3 发布范围与授权

- 日期：2026-10-16
- 状态：accepted
- 任务：T-7289

## 决策

1. 用户本轮明确要求“发版”，授权把已验证开发分支快进到 main，推送 main/tag 并发布 GitHub Release。旧 BRANCH-PROTOCOL.md 中 0.44.1 冻结记录是历史状态，不阻止本次明确授权；不修改历史文件，也不把本次授权泛化为后续自动合并。
2. 发布 v0.47.3，沿用近期 UI 与兼容修复的补丁版本惯例。范围为 v0.47.2 后紧凑工作台、七组件默认组合、天气重试、书签/大纲兼容和诊断预览。
3. 七卡是新工作台的默认组合。已发布 0.47.2 的已存双卡布局不会统一自动补成七卡；保存布局、删除、禁用与配置继续保留。只有匹配未发布中间态的原样四卡会安全补齐。
4. 版本、双语 README/changelog、路线与 readiness 同步后重新跑发布门禁。保持 578 KiB ZIP 门禁和最低声明 3.8.0，未完成环境验证不升级为兼容承诺。
5. 推送后以远端 main/tag、Release/CI 结论、实际资产大小和 SHA-256 回读为完成证据。GitHub Release 完成与集市同步分开记录，不覆盖个人安装。

## 证据

当期账本 T-7289 与 `.artifacts/T-7289-*` 保存本地验证、远端构建及资产回执。
