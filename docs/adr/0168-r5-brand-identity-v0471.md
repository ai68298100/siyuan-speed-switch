# ADR 0168：R5 生产界面层级与恢复路径收口

日期：2026-10-12

状态：已接受，本地候选 v0.47.1；GitHub 最新正式版仍为 v0.47.0

## 背景

R5 原型的顶栏左侧由品牌标记、产品名和“工作上下文平台”副标题组成。生产界面此前只有产品名，导致顶栏左侧缺少稳定的身份锚点，桌面、窄容器和移动端的视觉层级也与原型不一致。全路径复核还发现，工作台保存的组件全部不可用时没有就近恢复路径；组件商店目录卡在未选中状态收到键盘激活时会查找旧详情动作，首次 Enter/Space 静默无效。

## 决策

- 在共享 `mountPlatformChrome` 装配路径增加无业务含义的品牌标记、产品名和本地化副标题。
- 品牌标记使用主题主色和轻量双色混合背景，文字由 `aria-hidden` 标记，不重复播报产品名。
- 副标题复用双语 i18n，560px 容器内隐藏副标题并缩小标记，保留导航、设置和关闭的现有命中区。
- 不复制原型演示数据，不改变表面路由、关闭语义、焦点恢复、状态徽标或宿主 API。
- 工作台只有在保留的布局存在且其中没有可用组件时显示恢复面板；以可用工作区高度呈现标题、布局保留说明、商店主动作和编辑清理次动作。失效占位仍保留并移动到主体滚动网格，不把失效布局伪装为空配置；编辑态隐藏重复的进入编辑按钮。
- 空态不使用 `role=status` 包含交互按钮；用具名 group 与标题保持可访问语义。
- 组件商店目录卡遵循两阶段键盘动作：未选中时首次 Enter/Space 选择并展示详情；已选中时再次激活执行详情主动作。鼠标行点击仍只负责选择，行内按钮继续各自执行。

## 验证

- 顶栏品牌契约通过真实源码删除式负向验证：移除品牌标记装配后定向契约失败，精确恢复后文件哈希一致并恢复通过。
- 思源 3.8.7-alpha.7 隔离内核：面板头部/关闭 E2E 4/4，商店/工作台 E2E 4/4；TypeScript 与生产构建通过。
- 真实宿主的 245px 侧栏、Android 真机和读屏证据继续按 `BLOCKERS.md` 后置。
