# ADR 0089：压缩条目预算线校准 288 → 320 KiB

日期：2026-09-28。状态：已采纳。

## 背景

T-6949（固定与解除固定当前预览，[2026-09-27 账本](../dev-plan-2026-09-27.md) 阶段 A 首项）在切换器预览头部新增会话级固定开关：状态 WeakMap、头部按钮与标签同步、`previewTabOrDoc` 跟随守卫、会话销毁释放，附 8 项行为测试（含负向注入）。功能落地后 `dist/index.js` 压缩体积达 295,198 字节，越过 288 KiB（294,912 字节）条目预算线 286 字节；账本（dev-plan-2026-09-27 §7）此前已两次预告「压缩入口余量 66 字节，新增功能不能假设主入口还有充足空间」。

## 决策

沿用 ADR 0059/0062/0065/0075/0081 的校准程序：

1. 压缩条目预算线（`COMPRESSED_ENTRY_BUDGET_BYTES`）从 288 KiB 上调至 **320 KiB**（+32 KiB，与 0065→0075 的 32 KiB 步进一致）。
2. 减量审计：本轮增量为真实用户可见功能（预览固定），无死重量可删；以删功能挤线违背既定纪律（ROADMAP §8.0.19「既不无意义删功能挤线，也不无记录抬线」）。
3. 预览固定属切换器核心交互，不适合拆分动态 chunk（会破坏首屏跟随体验与懒加载路径语义）。
4. 硬上限不变：归档总上限仍为 512 KiB；raw 自律线仍为 1088 KiB（ADR 0081，当前 1,076,038 字节，余 ~37 KiB）。

## 后果与边界

- `tests/host/package-resource-audit.test.cjs` 的单条目断言随 `COMPRESSED_ENTRY_BUDGET_BYTES` 放宽，演进注释同步补记。
- `tests/host/package-resource-baseline.json` 的 index.js 条目刷新至当前压缩体积（本轮 +352 字节，远低于 8 KiB 增长告警线）。
- **下一约束预警**：归档总上限 512 KiB 当前仅余 ~13 KiB（package.zip 510,742 字节）。阶段 A 剩余任务（T-6950 预览内查找、T-6951 设置搜索、T-6952 保存搜索编辑）每次成批后必须复核整包线；越线时按本 ADR 同一程序另行审计，优先评估动态 chunk 分流。
- 本 ADR 只调整自查预算线，不改变任何外部契约（思源集市无此限制）。
