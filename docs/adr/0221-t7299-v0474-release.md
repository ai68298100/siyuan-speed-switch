# ADR 0221：v0.47.4 发布范围、授权与资产回执

- 日期：2026-10-17
- 状态：accepted
- 任务：T-7299
- 关联：T-7290～T-7298、ADR 0215～0220、Issue #15

## 决策

1. **用户明确授权发版**：根据用户指令“发版落地”，授权将 main 分支已验证的全部 12+ 提交、现代科技感重构成果与安全契约打包发布为 **`v0.47.4`** 正式版，推送 main 与带注释的 Git Tag `v0.47.4` 并触发 GitHub Release 工作流。
2. **发布范围（v0.47.3 后的重大闭环）**：
   - **第二面板与商店最现代化科技感重构**：时钟去壳直出、等宽科技排版、待办复选框 0ms 乐观打勾与划线衰减微动效、年度时间进程 2.8s 流光脉冲、商店卡片画廊化与图标微底衬；
   - **多端双拼 Bento 架构与 GPU 性能护栏**：手机端（<=560px）时钟与天气 50% 优雅并排，长列表 100% 舒展；iPad 4列 Bento；触控隔离与硬件加速零重排；
   - **全表面渐进式质感升级**：第一面板 8 页签卡片消费 1px 晶体纯白微倒角切光（`--sw-rim-light`）、机械键帽微立体阴影、双层发光微环；强化白天陶瓷霜白质感，物理微噪点重构为全局自主可选开关；
   - **闭环 Issue #15**：搜索页面右侧独立 34% 预览窗格优化，正文独立滚动不遮挡全库文档；
   - **Phase C 受控智能与动作安全回执契约完备交付**（Provider 7阶段契约、8大组件密度、AI 沙箱、文档集 6 态回执）；
   - **全套标准化支持与治理手册交付**（FAQ 排障指南、隐私政策与漏洞披露、工业级维护者手册、五条主路径可用性评测执行手册）。
3. **发布门禁与包体预算**：
   - 保持 578 KiB（591,872 字节）发布门禁与最低声明思源 3.8.0；
   - 实际构建产物 `package.zip` 约 575 KiB，健康留存 2.7 KiB 以上余量；
   - 全量自动化测试 8770+ 项全部通过。
4. **外部发布与协同**：
   - 推送后以 GitHub Actions Release 构建结论、远端资产 SHA-256 回读为完成证据；
   - 在 GitHub Issue #15 中回复说明解决情况并由维护者关闭；集市同步与个人安装继续单独待用户操作。

## 证据

当期账本 T-7299 记录本地验证、远端构建及资产回执。全量契约测试与 4 套冒烟全绿，TypeScript 0 错误。
