# ADR 0136：工程阻塞状态与环境后置分开记账

- 状态：已采纳
- 日期：2026-10-04
- 任务：T-7097 / AB-1704

T-7096 后单元测试 8380/8380，但质量审计仍寻找“当前无阻塞”字串而失败。当前无工程阻塞与 Android、账号、社区渠道等环境前置可以同时成立，不能为了让旧检查通过而改写事实。

BLOCKERS 使用唯一的 `Current engineering blockers` 标记声明当前工程状态。质量门禁要求恰好一条 `none`；缺失、重复、未知值或 `active` 均失败。历史描述和 B-004～B-011 不替代这个当前状态。标记属于人工维护的文档契约，不能证明外部验收已完成，也不能检测所有未发现的代码缺陷。

负向验证扩展既有 contract-probe；仅额外允许精确的根目录 BLOCKERS.md，不放开根目录任意文件。active、删标记、重复标记分别须击中具名失败，并按原始字节和 SHA-256 恢复。
