# ADR 0141：当前状态索引治理

- 状态：已接受，已实施
- 日期：2026-10-05
- 任务：T-7113

## 决策

`docs/current-status-index.json` 是当前开发队列的唯一状态源。它记录当前任务、状态、优先级、证据入口、阻塞或后置原因以及下一任务；`docs/dev-plan-2026-09-27.md` 保留历史执行记录，当前队列表只提供索引链接，不重复维护状态字段。

`scripts/current-status-audit.cjs` 只读校验索引结构、任务唯一性、证据路径、阻塞/后置原因和“不自动合并主线”约束。审计接入发布门禁；历史归档保持只读，不回写历史状态。

## 原因

路线图、当期账本、专项计划和 ADR 的职责不同。把历史过程记录强行改成当前状态会破坏审计时间线，而在多个位置手工维护同一状态会产生“已完成/待实施”漂移。单一 JSON 状态源能让机器检查唯一性，同时保留人类可读的历史证据链。

## 边界

索引不伪造 Android、真实账号、社区目录、在线 AI 或兄弟插件工作区证据；这类任务继续引用 `BLOCKERS.md` 和对应 ADR。完成任务后，先更新索引，再在账本追加历史记录；不通过修改旧归档来消除漂移。

## 验收

- 当前队列任务 ID 在索引中恰好出现一次，索引内无重复状态记录。
- `completed`、`blocked`、`deferred` 项分别有证据、阻塞原因或后置依据。
- 删除当前任务证据、阻塞原因或主线保护约束时，审计必须精确失败。
