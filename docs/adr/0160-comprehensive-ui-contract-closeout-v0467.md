# ADR 0160：全量 UI 复核与交互契约收口（v0.46.7）

- **日期**：2026-10-10
- **状态**：accepted
- **关联任务**：T-7233

## 决策

1. 顶栏布局同时按视口和 `.sw-platform` 容器宽度降级；自定义窄面板不能因为浏览器视口很宽而把导航与关闭动作挤出可达区域。
2. 第三面板片段选择器关闭后恢复实际触发入口的焦点；从组件商店入口打开时不再错误跳回左侧选择按钮。
3. 笔记本配置字段统一通过详细加载结果渲染，失败、空列表、重试和销毁竞态保持可区分；对应源码合同同步到共享加载助手。
4. 侧栏导航继续使用密度 token，短窗只压缩细指针关闭按钮，粗指针保持触控命中尺寸。

## 验证

- 顶栏合同、反馈合同与 245px 侧栏 smoke 通过。
- 片段选择器焦点回归测试通过。
- 笔记本加载失败/重试/销毁行为测试通过；旧数组加载和旧占位渲染合同的负向注入会失败。
- 完整构建与类型检查通过；发布快照在构建后重新生成。
