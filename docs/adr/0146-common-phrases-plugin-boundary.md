# ADR 0146：小驴常用采用独立插件，雷切提供可选入口

- 日期：2026-10-05
- 状态：已采纳
- 任务：T-7123（2026-10-06 编号勘误：原误登记 T-7122；该号保留给先登记的配置弹窗生命周期修复，研究结论不变）
- 关联：`docs/research-common-phrases-2026-10-05.md`、ADR 0010、ADR 0038、ADR 0078

## 背景

Quicker 的“常用语”动作证明了文本、网址、图片、链接、代码和附件混合调用的需求。小驴雷切已经拥有切换器、快速捕获、模板插入、剪贴板入口和第三方快捷动作注册能力，但第一面板仍以导航为首要职责；片段实验室也只负责 CSS/JS 片段，不是通用内容库。

## 选项

1. **全部并入小驴雷切**：入口集中，但会把内容库管理、媒体资源、编辑器插入和移动端适配继续堆进切换器。
2. **完全独立且不互通**：职责清晰，但用户需要记住两个入口，无法利用雷切的统一动作目录。
3. **独立常用内容插件 + 雷切可选 provider 入口**：内容域独立，雷切继续承担发现、快捷动作和跨表面入口。

## 提案决策

选择第 3 项，独立插件正式命名为“**小驴常用**”。

- 思源文档/块是正文、资源和结构的唯一来源；插件侧车只保留范围、收藏、最近使用和偏好。
- 常用内容插件提供搜索、复制、插入、打开来源和媒体能力；雷切只通过已有 provider registry 注册 `open` 等可选动作。
- 小驴常用对外保留版本化的内容项、能力声明和 provider/action 接口，供小驴雷切、小驴打卡及其他小驴系列插件按能力接入；完整联动协议不阻塞首期文本/网址 MVP。
- provider 的持久化部分只使用可序列化的 ID/value，回调保存在运行时；插件卸载后入口安全降级，重载后可以恢复。
- 首期先交付文本与网址，再取证块结构、图片和附件；没有真实宿主合同时不宣称移动端插入可用。

## 后果

正面：常用内容可单独安装和演进，避免污染切换器首屏；内容天然进入思源文档树、标签、同步和回链体系；雷切不需要复制正文或建立第二个真源。

代价：需要维护一个新插件和跨插件 provider 协议；最近/收藏等侧车元数据可能是设备本地的，必须在界面上说明；媒体插入和 Android 行为需要额外宿主验收。

## 退出条件

- 完成桌面与 Android 活动编辑器、剪贴板、资源引用和宿主搜索合同取证；
- 文本/网址 MVP 的复制、插入、来源回链、失效处理和 provider 卸载恢复通过专项测试；
- 真实移动端证据确认后，才决定开放图片、附件和块结构插入。
