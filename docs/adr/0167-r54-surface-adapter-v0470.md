# ADR 0167：R54 三面板视觉适配与工作面层级

## 状态

已接受（2026-10-11）。随 v0.47.0 发布。

## 背景

小驴闪卡 R54 原型已经形成稳定的“画布 / 工作面 / 主动作”层级：普通对象使用白面和细描边，主工作区使用克制阴影，移动端按容器宽度降级为单一主滚动区，并保证触控目标可达。雷切已有统一 `sw-platform-*` 外壳，但第一面板、第二面板和第三面板仍由多批历史样式叠加，材质、间距和窄容器行为不完全一致。

## 决策

1. 新增作用域样式适配层 `src/styles/_12-r54-surface-adapter.scss`，只消费思源主题变量和既有 `sw-*` token，不复制 R54 原型的合成数据、业务导航或状态模型。
2. 第一面板保留切换器语义，强化连续阅读工作面、预览边界和稳定的搜索/侧栏层级。
3. 第二面板保留网格编排和组件商店目录—详情结构，普通组件使用平静白面，详情预览保留单一实时预览与动作区。
4. 第三面板保留片段库、编辑器、预览和 AI 辅助的真实流程，编辑器是主工作面，预览/AI 是辅助面；宽度小于 760px/560px 时按真实 `sw-platform` 容器降级。
5. 不新增全局 `:root` 颜色、不改 API、存储、异步状态或关闭/焦点语义；所有交互继续由现有生产 DOM 和控制器负责。

## 取舍

- 不把雷切强行改成闪卡的五项业务导航。雷切三个面板是不同工作表面，统一的是平台外壳、状态和材质合同。
- 不使用厚重渐变或装饰性玻璃。R54 的质感来自对象正确、层级可读、边界稳定和动作可接续。
- 容器查询只作用于面板内部后代；根节点仍由既有 Dialog/侧栏尺寸控制，避免覆盖宿主的窗口管理。

## 验证

- `tests/r54-surface-adapter-contract.test.cjs` 通过，并对工作台卡片边界执行删除式负向验证。
- `pnpm exec tsc --noEmit`、`pnpm build`、`pnpm test:smoke:surface-switch`、`pnpm test:smoke:layout`、`pnpm test:smoke:browser` 通过。
- 后续发布门禁继续覆盖明暗主题、窄面板、触控命中、reduced-motion 和真实宿主边界；Android 真机、最窄原生侧栏仍按 `BLOCKERS.md` 后置。
