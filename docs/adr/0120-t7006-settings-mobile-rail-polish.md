# ADR 0120：设置控件与窄屏 rail 抛光

- 状态：已采纳
- 日期：2026-10-04
- 任务：T-7006

## 背景

T-7000 和 T-7001 已补齐移动设置字段与生产语义，但设置页在窄屏仍有三个可见风险：标签栏命中区不足、长文案与右侧控件争用宽度、range 控件的触控和焦点反馈不稳定。搜索结果、恢复/重试等局部操作也需要保持可触达，且不能用负边距制造横向溢出。

## 决策

1. 设置标签在窄屏使用至少 44px 高度、横向滚动和 `touch-action: manipulation`；桌面保留 36px 基线。
2. 设置行的文案区域和右侧控件允许收缩，长文本使用 `overflow-wrap: anywhere`；右侧控件保留 42px 最小承载宽度。
3. 搜索清空、搜索筛选、搜索结果、重置、重试和撤销入口补充触控尺寸与 `:focus-visible` 轮廓。
4. range 控件在窄屏拥有 44px 真实控件高度，桌面拥有明确轨道、thumb、焦点环和触控行为；数值输入保留独立可操作区域。
5. 窄屏搜索条的布局使用与面板内边距一致的补偿值，避免 390px 视口下出现横向溢出。

## 不变边界

- 不改变设置字段、存储 key、输入事件和提交时机。
- 不把浏览器视口测试当作 Android 真机证据；Android 触控/旋转/输入法继续归 B-004，最窄真实侧栏归 B-005。
- 不新增运行时依赖或第二套主题变量体系。

## 证据

- `tests/settings-mobile-rail-contract.test.cjs`：定向契约 10/10。
- `tests/e2e/t7006-settings-polish.spec.mjs`：真实思源 3.8.6 E2E 1/1，覆盖 390×844 rail、焦点、range 触控高度和横向溢出。
- 负向验证：将移动 range 高度注入为 43px 后目标契约精确失败；源码 SHA-256 恢复为 `d1c062566a22c7c9896e5596af29e96e701767fe626859dbfce106b8a551beb2`。
- 全量验证：`pnpm exec tsc --noEmit` 通过；`pnpm test` 首轮 8313/8314，唯一失败为既有浮球 host-redraw 时序断言；单独重跑该文件 21/21，通过，未修改无关测试或生产代码。
