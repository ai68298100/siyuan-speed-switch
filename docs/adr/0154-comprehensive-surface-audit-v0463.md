# ADR 0154：三面板全路径审计与 v0.46.3 回归修复

- 状态：已接受
- 日期：2026-10-09
- 关联任务：T-7225

## 背景

v0.46.2 发布后的历史复核发现，部分合并回归没有表现为功能完全消失，而是表现为 DOM 仍存在、对应样式或失败边界消失。典型问题包括平台顶栏按钮与 Esc 提示、第一面板搜索来源标记、工作台 stale 状态、片段商店/Gist 预览布局，以及宿主主题改写 Dialog 内容后留下空壳。

## 决策

1. 平台顶栏设置/关闭提示、移动 sheet 关闭按钮与 Esc 提示必须有独立的基础样式、焦点反馈、触控 44px 命中区和窄屏降级。
2. 第一面板来源/范围辅助信息、工作台 stale 缓存状态、片段商店与 Gist 预览节点按生产 DOM 保留对应视觉和滚动边界；不依赖通用样式的偶然继承。
3. 商店 Dialog 在容器、根节点或目录/详情窗格缺失时立即销毁空壳并恢复打开控件焦点，避免主题兼容失败变成不可关闭界面。
4. 新增样式/生命周期契约必须使用块级断言，并对删除关键声明做负向注入；普通测试全绿不足以证明门禁有效。

## 取舍与验证

- 控件高度继续使用共享 token；Esc 键帽和 Gist 行圆角采用既有刻度，避免恢复历史奇数/孤立尺寸。
- 未把真实 Android、读屏和外部账号结果冒充本地浏览器证据，继续按 B-004/B-005/B-008 后置。
- v0.46.3 通过完整测试 8596/8596、TypeScript、样式回归契约、商店生命周期契约、Chromium smoke、可复现构建和发布门禁后再上传 GitHub。
