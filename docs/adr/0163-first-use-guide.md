# ADR 0163：三面板共享快速开始入口

- 日期：2026-10-10
- 状态：accepted
- 关联任务：T-7236

## 背景

新用户首次打开插件时，第一面板空态只有一段说明，第二面板常因自动播种组件而跳过空态，第三面板也需要先理解“选择、编辑、预览、保存、启用”的顺序。把教程做成强制首次弹窗会遮挡搜索和编辑现场，也无法覆盖用户稍后再次需要帮助的时刻。

## 决策

1. 三面板顶栏提供同一个本地“快速开始”按钮；帮助内容使用现有 i18n 和 DOM 构建，不请求网络、不读取用户正文、不改变当前面板布局。
2. 帮助对话框同时说明切换器、工作台、片段实验室的三步主路径，并显示当前生效的切换器/工作台快捷键；当前表面以边框强调。
3. 第一面板无页签空态提供“开始搜索、打开工作台、打开片段实验室、快速开始”四个明确 CTA。跨面板 CTA 先关闭当前弹窗，侧栏模式保持原有 dock 语义；搜索 CTA 只恢复搜索框焦点。
4. 帮助对话框支持显式关闭、Escape 和关闭后焦点恢复；同一会话重复点击不会叠出多个帮助窗。
5. 第二面板空态文案使用真实存在的“打开组件商店”入口；不增加强制欢迎横幅或首次持久化状态。

## 取舍

- 共享入口比只依赖空态更可靠，因为工作台首次打开通常已经有默认组件，第三面板也不一定从空库进入。
- 不做强制首次教程，避免遮挡高频搜索、编辑和关闭动作；始终可见的帮助按钮让用户可回看。
- 不在本轮增加外链说明、联网探测或 OCR 等前置配置；引导必须离线可用。

- `tests/first-use-guide.test.cjs` 覆盖共享按钮属性、三面板接线、四个空态 CTA 及负向注入。
