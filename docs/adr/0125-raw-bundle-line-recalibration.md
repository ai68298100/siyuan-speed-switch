# ADR 0125：本地功能批次后的 raw 包体自律线校准

- 状态：已采纳
- 日期：2026-10-04
- 任务：T-7086

## 背景

ADR 0098 将 `dist/index.js` 的 raw 自律线校准到 1152 KiB。随后完成的片段分组、片段备份、搜索组合复验、工作台生命周期、provider 协议、商店预览和多项面板/设置收口均属于已验收的生产功能。当前构建为 1,181,710 B，较 1152 KiB 线超出 2,062 B；`package.zip` 为 584,659 B，仍低于 576 KiB 归档上限。

## 复核

- 片段实验室继续放在动态 `snippet-studio` chunk，分组管理没有把编辑器正文搬回主入口。
- 生产源码无新增调试输出或机器路径；生产图当前为 73 个模块，增长来自已登记的功能模块。
- raw 线是异常膨胀观测线，归档上限 576 KiB 和 `index.js` 压缩条目 320 KiB 保持不变。

## 决策

1. `RAW_BUNDLE_BUDGET_BYTES` 从 1152 KiB 校准到 **1160 KiB**，保留 6,130 B 当前余量，并要求下一批功能再次做包体复核。
2. `ARCHIVE_BUDGET_BYTES` 继续为 576 KiB；不得用 raw 线校准掩盖归档硬上限或压缩条目超线。
3. 生产图数量护栏同步到当前实测 73；新增生产模块仍需在对应任务和 ADR 中登记，不能只改数字。

## 验证

`pnpm build` 后由 `scripts/readiness-snapshot.cjs` 更新产物快照；`release-quality`、生产图隔离和全量测试必须重新通过。
