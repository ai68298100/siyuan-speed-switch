# ADR 0119：T-7001 设置字段与原型语义清洗

- 状态：已接受
- 日期：2026-10-04
- 任务：T-7001

## 背景

设置页原型与生产字段存在语义漂移：日记开关混合了自动创建和只读查找，工作台状态记忆、默认视图和单项重试没有完整暴露，滚动现场开关没有明确门控，快捷键展示可能与真实注册值不一致，悬浮球说明仍沿用旧侧栏术语，部分中英文文案也没有同步表达当前端侧语义。

## 决策

1. 日记行为拆成 `journalAutoCreate`。关闭时只通过有界 SQL 查找今日日记并给出创建指引，禁止刷新或查找路径隐式创建文档。
2. 工作台分别持久化 `homeStore.rememberState`、`homeStore.defaultViewMode` 和 `homeStore.retryFailed`。状态记忆关闭时不恢复、不写入现场；默认视图只接受受支持值；单项失败重试关闭时不渲染重试动作。
3. `rememberScrollPosition` 只控制滚动位置的恢复与写入，非法旧值按默认值清洗，并保留既有存储兼容性。
4. 快捷键设置展示真实注册快捷键 `⌥⇧S` 与 `⌥⇧P`；悬浮球文案明确桌面/手机端范围，并保留旧侧栏字段迁移提示。
5. 所有新增设置字段进入统一模型归一化、双语资源、设置 UI 和生产接线；不为原型字段增加第二套存储或旁路行为。
