# ADR 0223：v0.47.5 发布范围、授权与资产回执

- 日期：2026-10-17
- 状态：accepted
- 任务：T-7301
- 关联：T-7300、T-7144、ADR 0222、ADR 0221

## 决策

1. **用户明确授权发版**：根据用户指令“发版”，授权将 main 分支已验证的零依赖代码格式化器、三模式导入规划引擎、全表面 1px 晶体微倒角高光对齐成果与原型系统集成打包发布为 **`v0.47.5`** 正式版，推送 main 与带注释的 Git Tag `v0.47.5` 并触发 GitHub Release 工作流。
2. **发布范围（v0.47.4 后的重磅深化）**：
   - **零依赖极速 CSS 格式化器 (`src/snippet-formatter.js`)**：纯原生状态机解析，支持 CSS 选择器、大括号、多声明分行、冒号空格规范化与分号补齐，彻底消灭 200KB+ Prettier 外部依赖；吸收 `formatWithCursor` 机制，在格式化时将原始光标平滑映射至对应位置，光标绝不乱跳。
   - **三模式代码片段导入规划引擎 (`src/snippet-import-plan.js`)**：
     - `merge`（默认增量合并）：匹配同 ID 片段更新代码与名称，严格保留本地用户的 `enabled` 启用偏好和列表原排序位置；
     - `fork`（分叉克隆）：全部重新生成全局唯一 ID，强制置为 `enabled: false` 作为独立全新副本导入，绝不覆盖已有版本，适合社区代码二次魔改；
     - `overwrite`（镜像覆盖）：以导入集合作为唯一事实源进行全量替换。
   - **全表面晶体微倒角切光与物理质感深度对齐**：
     - 第二面板生产工作台单元格（`.sw-home .sw-home__cell`）常态与 hover 全面注入 `box-shadow: var(--sw-rim-light, none), var(--sw-polish-shadow-card)`，浮现 1px 晶体纯白微内切光高光与环境光遮蔽微阴影；
     - 第一面板切换器右侧大预览窗格（`.speed-switch .sw__doc-preview`）注入同款微倒角高光切光；
     - 第三面板代码实验室编辑区（`.sw-studio__editor-section`）与片段卡片全面对齐微倒角切光与发光微环。
   - **第三面板编辑区操作深化**：
     - 工具栏新增 `[ 🧹 格式化 ]`（`snippetFormat`）单键操作按钮，支持中英文双语并自动记入草稿撤销历史栈。
   - **典藏版高保真原型全面集成多设备视口模拟器**：
     - 包含桌面（100% 弹性响应式）、iPad（834px 4列同心 Bento）、手机端（393px 2列双拼 Bento）、原生窄 Dock（245px 单列流），并具备 40+ 交互全闭环。
3. **发布门禁与包体预算**：
   - 保持 578 KiB（591,872 字节）发布门禁与最低声明思源 3.8.0；
   - 实际构建产物 `package.zip` 为 **577 KiB（591,166 bytes）**，健康处于发布门禁之内（余量 **706 bytes**）；
   - 全量自动化测试 8777+ 项全部通过，静态类型检查 0 错误。
4. **外部发布与协同**：
   - 推送后以 GitHub Actions Release 构建结论、远端资产 SHA-256 回读为完成证据；
   - 远端 Release 设为 Latest，双语更新日志与资产下载端点同步就绪。

## 证据

当期账本 T-7301 记录本地验证、远端构建及资产回执。全量契约测试与 4 套冒烟全绿，TypeScript 0 错误。
