# ADR 0105：大库搜索聚合采用受限平面记录快路径

- 日期：2026-10-02
- 状态：已接受（T-7074）
- 关联：T-6835、T-7046、ADR 0098

## 背景

全文检索回退会对每条命中记录执行多轮嵌套容器与字段别名扫描。1200 条命中、300 个根文档的基线 CPU 均值为 25.65ms；复杂度门禁在 600→1200 命中时测得 3.17x，超过 3x 上限。40ms 是真实病态输入告警线，不能通过放宽阈值掩盖热路径问题。

## 决策

1. 当记录没有 `block`、`root`、`document`、`data` 嵌套容器，且直接根文档 ID 别名有效时，使用直接属性读取与同一套文本/数字归一化，避免为每条平面记录创建嵌套候选数组。
2. 快路径覆盖 canonical 与 legacy 直接字段别名；没有直接根 ID、存在嵌套容器、需要路径推导或文档记录判别时，继续走原有防御性解析，不改变输入契约。
3. 不引入无界索引或跨请求缓存，不跳过文本清洗、长度上限、片段去重和截断标记；40ms 病态线与复杂度门禁保持不变。

## 后果

- 大库常见的平面全文命中减少规范化分配，聚合输出字段、来源优先级、片段/块 ID 限制和文档顺序保持不变。
- 嵌套或形状不确定的宿主返回值仍由旧解析器兜底，快路径不承担宿主兼容性猜测。
- 直接字段读取与旧解析器必须持续由平面/嵌套、canonical/legacy、重复片段和限制组合矩阵共同覆盖。

## 验证

- `tests/search-aggregation-matrix.test.cjs`：216 个组合 + 4 个边界用例，共 220/220。
- 搜索模型与编排定向套件：99/99；搜索编排性能：5/5；复杂度门禁：7/7。
- 负向验证：临时移除快路径 `hPath` 别名后矩阵按预期失败（实际路径为空），恢复后 220/220 通过。
