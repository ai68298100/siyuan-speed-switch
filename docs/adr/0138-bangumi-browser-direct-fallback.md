# ADR 0138：Bangumi 固定日历直连优先与代理回退

- 状态：已采纳
- 日期：2026-10-04
- 任务：T-7100

真实思源 3.8.6 诊断显示，浏览器从 `https://api.bgm.tv/calendar` 直连返回 200，思源 `/api/network/forwardProxy` 在同一环境中因出口连接超时返回 `code: 8`。继续只走代理会把可用的公开日历错误显示为空态。

仅对精确的 Bangumi 固定日历端点使用浏览器直连，并把调用方取消信号传入；直连失败后回退既有白名单代理。端点仍由生产方法做字面量校验，其他公开服务、用户端点、本机服务和带凭据请求继续走原有内核代理，不扩大出网范围。

模型层仍负责响应大小、超时、JSON 解析、缓存和失败抑制；直连与代理共享这些约束。直连成功证据为真实 WebView 返回 HTTP 200，代理失败证据为真实内核 `forward request failed`；在线 E2E 用真实页面确认日历条目和官方 HTTPS 封面能够渲染。
