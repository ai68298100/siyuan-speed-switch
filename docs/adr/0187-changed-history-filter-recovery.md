# ADR 0187：最近记录改动筛选失败与空态恢复

日期：2026-10-14  
状态：已接受（T-7259）

## 背景

最近记录的“只看有改动”通过 SQL 批量读取根文档更新时间。旧实现把请求失败或非数组响应当成空结果，点击监听器可能产生未处理拒绝；确实没有符合条件的文档时，也没有退出过滤的直接动作。

## 决策

- SQL 结果必须存在且 `data` 为数组；每一行都必须包含合法根文档 ID 和字符串更新时间。请求失败或响应结构异常按失败处理，不提交部分更新时间映射。
- 失败时取消筛选并保留完整本地历史，显示可读错误及重试入口；请求期间禁用开关并设置 `aria-busy`，最终必定释放。
- 有效结果为零条时明确说明窗口期内无改动，并提供“显示全部最近记录”动作。

## 验证

- `tests/history-sync-receipt-contract.test.cjs` 验证失败回执、锁和空结果恢复入口。
- 完整测试、类型检查、生产构建和发布 smoke 通过；门禁改动按 T-7258 方法完成负向注入验证。
