# ADR 0166：v0.46.9 E2E 收口与表面细节修复

- 日期：2026-10-11
- 状态：accepted
- 关联任务：T-7240、T-7241
- 关联： [ADR 0161](0161-tab-preview-available-height.md)、[ADR 0164](0164-performance-first-paint.md)、[ADR 0165](0165-floating-ball-first-use-and-action-boundary.md)

## 背景

v0.46.8 发布后，独立真实思源后台回归发现三类可复现的细节问题：第三面板短窗口下预览区内容可能越过自身边界覆盖详情；手机设置页标签的触控高度被桌面规则压低，搜索条的负外边距在窄面板产生横向溢出；移动布局 E2E 在创建文档后立即搜索，可能早于思源索引完成而产生时序失败。工作台保留旧快照时的实际语义是 stale，但旧合同仍把它断言成 failed。

## 决策

1. 第三面板预览 section 自身拥有 `overflow: auto` 边界，继续由预览画布承载内容滚动，不改变预览数据或布局列数。
2. 手机设置页标签保持至少 44px 触控高度；搜索条的外扩与面板内边距成对抵消，窄屏不产生横向溢出。
3. 移动布局 E2E 在打开文档前等待真实内核的文档索引可检索；测试等待只改善证据稳定性，不增加生产端延迟。
4. 工作台保留快照且刷新失败时显示 stale，保留内容和 Retry；只有没有可用快照的失败才显示 failed。
5. 发布前以独立后台成功轮次、完整本地发布门禁和构建产物为证据；单项超时导致编排器关闭内核后的连接拒绝只记录为环境级级联，不视为额外代码缺陷。

## 验证

- 独立真实思源后台：run `20261010172658-63372-e9c870`，内核 `3.8.7-alpha.6`，编排器退出码 0。
- 真实宿主定向回归：第三面板布局、工作台信息、移动布局和设置页 E2E 均通过；生产构建通过。
- 本 ADR 所属发布批次继续执行 `pnpm verify:release`、`git diff --check` 和远端 Release 资产回读。

## 后果

预览和手机设置在短窗口/触控环境下有明确几何边界，E2E 不再把索引异步时序误报为产品故障；工作台状态文案与保留快照的真实语义一致。真实 Android、读屏和最窄原生侧栏仍受 `BLOCKERS.md` 的环境条件约束。
