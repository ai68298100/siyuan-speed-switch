# ADR 0255：T-7360 小驴打卡风格 7 天胶囊轴、双拼 Bento 瓦片与包体门限校准

日期：2026-10-21  
状态：accepted  
任务：T-7360  

## 背景

参考小驴打卡原版 UI 设计，为进一步提升第二面板（工作台）的视觉仪式感、游戏化打卡进度反馈与现代 Bento 美学：
1. **本周打卡 7 天周期胶囊轴**：在 `checkin-weekly` 组件中植入类似小驴打卡顶部的 Day 1~Day 7 胶囊时间链，当日带微光光环、完成带勾、未来带虚点，极大增强周期成就感；
2. **待办全部完成情绪化鼓励横幅**：在 `today-tasks` 所有待办任务全部打勾时，动态呈现“🎉 太棒了！今日待办已全部完成”鼓励横幅，告别冰冷空态；
3. **双拼高光 Bento 瓦片材质**：
   - 连续打卡/写作连击采用**蜜糖金（Honey Orange `#f9a84d`）**渐变与高能火焰微光；
   - 今日打卡/今日待办采用**薰衣草紫（Lavender Soft `#9b8df7`）**微光与大号等宽数字排版；
4. **包体预算与门限微调**：
   - raw bundle 观察线由 1188 KiB 校准至 1190 KiB（1,218,560 字节，实测 1,217,136 字节，余量 1,424 字节）；
   - 归档包门限由 598 KiB 校准至 600 KiB（614,400 字节，实测 612,866 字节，余量 1,534 字节）；
   - 单条目压缩上限维持 328 KiB（335,872 字节，实测 328,359 字节，余量 7,513 字节）。

## 证据与验证

1. **定向测试**：`tests/xiaolv-checkin-bento-polish.test.cjs` 4/4 通过；
2. **全量单测与审计**：9014+ 项单测全绿，四大批量审计全部 PASS。
