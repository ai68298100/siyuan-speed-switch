# ADR 0178：工作台编辑快捷键与输入保护

日期：2026-10-13  
状态：已接受（T-7251）

## 背景

工作台原型提示 Ctrl+B 进入布局编辑，完成按钮也提示 Esc，但生产实现此前只响应点击。快捷键必须同时尊重 IME 组合输入、表单输入和 CodeMirror 等编辑器已有的键位。

## 决策

- 工作台打开时在所属文档监听 Ctrl/Cmd+B 进入布局编辑、Esc 完成编辑；事件必须来自工作台或仍聚焦的打开入口，且工作台是最上层可见弹窗。不把快捷键扩展到组件商店或其他面板。
- 事件已取消、IME 组合输入或焦点位于输入/可编辑区域时不接管。
- 编辑按钮用 `aria-keyshortcuts` 和双语提示说明当前动作，包含 Ctrl 与 Command 提示；面板销毁时移除文档监听。

## 验证

- 独立思源内核覆盖从打开入口触发快捷键、商店置顶保护、IME 与输入框保护；本轮 3.8.7-beta.3 工作台回归 4/4 通过，联合工作台/商店回归 6/6 见 `.artifacts/T-7252-final-e2e/results.json`。
- 反向移除键盘监听后，快捷键 E2E 在 `aria-pressed` 断言处失败；原始失败输出见 `.artifacts/T-7251-negative.log`，恢复后源文件哈希一致。
- 类型检查、生产构建及工作台静态 chrome 契约通过。
