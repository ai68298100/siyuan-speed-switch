# ADR 0209：T-7144 候选矩阵与证据准入边界

- 日期：2026-10-16
- 状态：accepted
- 任务：T-7284
- 相关：T-7144、ADR 0194～0197、ADR 0201

## 背景

T-7144 要求从真人反馈或问题记录中选出 5～8 个高频组件，再针对可复现卡点做二轮精修。T-7269～T-7272、T-7276 已补齐多项隔离思源和模型证据，但这些证据只能证明当前宿主协议或工程边界，不能替代使用频率，也不能证明旧宿主字段仍在支持范围内。

## 决策

1. 用 E0（模型/接线）、E1（隔离宿主）、E2（隔离宿主加规模或负向）、E3（真人问题/频率）标记候选证据等级。
2. 只有 E3 或可独立复现的生产缺口才能进入 T-7144 的体验精修；E1/E2 只用于关闭宿主兼容、性能或动作边界疑问。
3. 在没有 E3 的当前条件下，允许做旧字段 fixture 兼容审计，但不得据此修改生产协议或宣称 T-7144 完成。
4. 标签只打开宿主公开的 tag dock；没有稳定 ID 或筛选参数时，不把“dock 打开”描述为“精确选中”。

## 结果

候选矩阵见 [`docs/t7144-candidate-matrix-2026-10-16.md`](../t7144-candidate-matrix-2026-10-16.md)。矩阵确认书签、标签、大纲、待办、统计、近期编辑、关系摘要和默认组件均已有不同等级的工程证据；真人频率、旧字段兼容和标签精确选中仍是独立边界。

本任务不改生产代码、不改变组件协议、不发布、不 push，也不把隔离工作区数据写入个人安装。
