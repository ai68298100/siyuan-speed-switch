# ADR 0224：v0.47.6 发布范围、授权与资产回执

- **状态**：accepted
- **日期**：2026-10-19
- **相关任务**：T-7333（紧接 T-7305～T-7332 连续 28 项核心加固与契约闭环）

## 背景与决策

1. **用户明确授权发版**：根据用户指令“当你感觉开发的内容已经值得发送到GitHub时，就加版号，经过检查后打包发版，可以通过gh发版”，授权将 main 分支已验证的真实隔离宿主 E2E 闭环、高对比度与无障碍增强、悬浮球自由停放网格、片段 AI 单片段授权与回收站三限淘汰、统一请求调度重试钳制以及 Agent 只读 Schema 约束成果打包发布为 **`v0.47.6`** 正式版，推送 main 与带注释的 Git Tag `v0.47.6` 并触发 GitHub Release 发布。

2. **版本范围（从 v0.47.5 到 v0.47.6 的 41 个本地提交增量）**：
   - **真实宿主 E2E 闭环**：
     - 文档集恢复与收集箱元数据无缝对齐思源原生云端收集箱（`tests/e2e/document-sets.spec.mjs`）。
     - 代码片段实验室 3 模式（Merge / Fork / Overwrite）导入与安全保存 E2E 闭环（`tests/e2e/snippet-import-save.spec.mjs`）。
     - 收藏分组添加、多端点击与工作现场返回真实宿主 E2E 闭环（`tests/e2e/favorites-flow.spec.mjs`）。
     - 最近打开与误关闭记录差集感知、双分区去重及重开对齐 E2E 闭环（`tests/e2e/recent-closed-flow.spec.mjs`）。
   - **全表面无障碍与高对比度强化**：
     - 系统级高对比度（`forced-colors: active`）与 `prefers-contrast: more` 边框强化与高对比度系统颜色映射。
     - 键盘焦点环 `focus-visible` 统一收敛为高对比度清晰边界，符合无障碍操作标准。
   - **核心调度与安全契约**：
     - 统一请求服务（`request-service.js`）：序列化深度溢出防御（>16 层阻断）、统一异常状态码分类与最大重试次数严格钳制（`MAX_RETRIES = 2`）。
     - Agent 执行器原生 ID 直读与同名 SQLite 过滤锁定，消除异步索引覆盖风险；只读能力输入输出 Schema 严格有界（查询词截断 200 字符、配置 8 字段上限）。
     - 代码片段回收站数量 50 / 年龄 30 天 / 字节 256KB 三限淘汰与禁用草稿恢复。
     - Gist 凭据四点掩码脱敏（••••cdef）、强制声明未列出 `public: false` 与配置包敏感字段隔离。
     - 代码片段 AI 辅助单片段授权、64KB 有界载荷与 SSE 流式中断取消机制。
     - 全局悬浮球自由停放、视口几何越界收敛与动作网格调度。
     - 设置中心跨十标签全局搜索（多词 AND 匹配、真实 DOM 控件引用高亮跳转）。

3. **包体预算防护**：严格遵守 578 KiB（591,872 B）归档包硬门禁，对称归档早期日志维持健康余量。
