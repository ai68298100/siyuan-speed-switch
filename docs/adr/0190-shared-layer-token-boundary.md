# ADR 0190：共享层级 token 的边界与渐进收敛

日期：2026-10-14  
状态：已接受（T-7264）

## 背景

样式 token 审计显示，颜色、字号、字重和动效已经有较高覆盖率，但层级仍主要使用字面量。一次性把所有 `z-index` 改成变量会触发平台弹窗、宿主浮层和契约测试之间的边界变化，也会把不属于插件外壳的系统层级错误地抽进共享刻度。

## 决策

- 在 `_00-tokens.scss` 增加编译期 `$sw-z-base: 0` 与 `$sw-z-raised: 1`，只表达插件平台外壳内部的基础层和焦点提升层。
- 平台顶栏入口及其 `:focus-visible` 状态消费这两个 token。层级是固定结构常量，不需要运行时主题覆盖；Sass 展开后仍输出原来的 `0/1`，避免增加包体字节。
- 宿主弹窗、系统级遮罩、FAB portal 和第三方组件的特殊层级继续由各自边界维护；不为覆盖率新建没有明确语义的 token。
- 后续迁移必须先证明语义边界和计算样式无变化，再单独补契约与负向验证。

## 验证

- `tests/platform-topbar-layout-contract.test.cjs`：6/6，通过 token 正向断言及删除 token 的负向验证。
- 样式门禁（radius/font/space/motion/overlay）：22/22，通过并包含负向自检。
- Sass 输出对照：改动前后 expanded CSS **433356 B / SHA-256 相同**，说明编译后的层叠输出未变。
- `git diff --check`：通过。

## 边界

T-7264 当批不迁移 10px/14px 间距、1.35/1.55 行高或 6px/8px/10px 圆角：它们在组件中承担不同几何语义，现有契约还直接断言部分字面值；没有输出等价与契约证据时不按覆盖率推动迁移。后续 T-7265 已通过编译期等值映射收敛 6px/8px 圆角，具体决策与证据见 [ADR 0191](0191-shared-radius-compile-time-tiers.md)；10px 几何与非匹配刻度仍保留待逐项审计。
