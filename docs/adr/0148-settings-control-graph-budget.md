# ADR 0148：设置控件语义模块进入生产图后的闭包预算校准

- 日期：2026-10-06
- 状态：已采纳
- 任务：T-7128

## 背景

T-7128 为设置行中的原生 input、select、checkbox、range 和复合控件补充可访问名称与说明关联。为了让多处设置构建器复用同一套绑定逻辑，语义绑定被放入 `src/settings-control-dom.js`。它进入 `src/index.ts` 的生产导入图后，闭包从 73 个模块增至 74 个模块。

## 决策

把生产图观测上限从 73 校准为 74，并在 `tests/production-graph-isolation.test.cjs` 记录模块来源和本 ADR。该上限只用于发现意外的依赖涌入，不放宽 raw bundle、压缩条目或 ZIP 硬上限；包体仍由 `release-readiness` 与发布检查独立约束。

## 后果

设置语义逻辑有独立边界和可单测入口，新增一项受审计的生产模块。后续再增加生产模块时，必须先说明模块价值、运行时体积和可移除性，再校准观测线；不能把数量线当作无条件的包体预算。
