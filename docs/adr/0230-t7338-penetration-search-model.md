# ADR 0230：T-7338 Obsidian 风格深入穿透检索模型（大纲穿透与块级搜索语法）

日期：2026-10-19  
状态：accepted

## 背景

在 2026-10-19 ROADMAP 行业竞品调研中，第二项核心演进规划明确指出：引入类似 Obsidian Quick Switcher++ 的大纲穿透（`:` 语法）与块级深入检索（`^` 语法）。

小驴雷切现有搜索管线主要负责文档标题匹配（`title`）、路径首字母加速（`acronym`）以及受限全文搜索（`content`），所有结果均为文档级。用户若想检索并直达文档内部的特定小节（如 `产品方案:架构设计`）或正文段落（如 `^重构规划`），必须先打开文档，再通过大纲树或正文查找手动二次跳转，键盘流断裂。

## 决策

1. **新建纯领域模型 `src/penetration-search-model.js`**：
   - 语法解析（`parsePenetrationQuery`）：
     - 块级深入检索：以 `^` 开头（如 `^重构架构`），解析为 `mode: "block"`，提取 `blockNeedle` 并提供纯净内核查询；
     - 大纲穿透：包含 `:` 且位于引号外部（如 `周报:下周计划`），解析为 `mode: "outline"`，分别提取 `docNeedle` 与 `headingNeedle`；以 `:` 开头（如 `:今日总结`）自动标记 `isCurrentDoc: true`；
     - 普通搜索：默认 `mode: "doc"`。
   - 语法转义与安全边界：
     - 双引号内部的冒号（如 `"key:value"`）被安全转义，保持普通文档搜索模式；
     - 标准 URL 协议头（`http:` / `https:` / `file:` / `siyuan:`）绝不触发大纲穿透；
     - 非首字符的 `^`（如 `x^2`）保持文档模式。
   - 内核安全查询（`cleanKernelQuery`）：自动剔除语法前缀与冒号，杜绝把自定义语法原样塞入思源内核端点导致语法报错或空结果。
   - 大纲标题打分（`filterOutlineHeadings`）：支持子串匹配，叠加标题层级加权（H1 > H2 > H3...），有界截断上限 24 项。
   - 块结果归一化（`normalizePenetrationBlockResult`）：`BLOCK_ID_RE` 格式强校验，清洗 Markdown/HTML 标记，正文长度限制在 120 字节内。
2. **由 `src/search-model.js` 统一再导出**：保持现有搜索架构的单点入口约定。
3. **生产图闭包上限 81 -> 82**：实测 82，按同口径校准（先例 T-6814/T-6950/T-7260/T-7334/T-7335/T-7336/T-7337）。
4. **包体预算完全保持在 582 KiB 内**：构建产物 `package.zip` 为 595,077 B，低于 582 KiB（595,968 B）仓库门禁 **891 B**，无需再次调整预算。

## 证据与边界

- **类型与全量测试**：`pnpm exec tsc --noEmit` 0 错误；全量测试从 8885 项扩充至 **8892 通过 / 1 跳过 / 0 失败**（新增 7 项 penetration-search 契约）。
- **五组负向注入验证**（按 `docs/gate-audit-checklist.md`）：
  1. 非法 blockId 被拒 ✅
  2. 非首字符 caret 不误判为块模式（经注入代码实测定向失败并复绿） ✅
  3. 引号内冒号不触发大纲穿透 ✅
  4. URL 协议头不误判为大纲穿透 ✅
  5. 大纲结果受最大上限钳制 ✅
- **构建与包体**：生产构建 `package.zip` 为 **595,077 B**，稳定处于 582 KiB（595,968 B）仓库门禁之内（健康余量 **891 B**）；`dist/index.js` 为 1,178,560 B（低于 1,187,840 B 预算线 9,280 B）；压缩条目 316,921 B（低于 327,680 B 门禁 10,759 B）。
- **批量门禁全绿**：可复现构建 3/3 一致；四大批量门禁 49/49、50/50、50/50、174 tasks 全部通过；六套浏览器 Smoke 全部复绿；`git diff --check` 通过。
- **边界声明**：本决策交付**语法解析器、大纲打分与块结果归一化纯模型**，不改动远端 Release、Git Tag 或包版本号。切换器搜索框的 UI 渲染分流与键盘回车穿透跳转归后续生产接线任务。
