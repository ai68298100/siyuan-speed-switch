# ADR 0198：第二面板首屏信息架构与自由画布边界

- 日期：2026-10-15
- 状态：已被 ADR 0199 取代（2026-10-16）
- 任务：T-7273

## 背景

本 ADR 记录的 Context Workbench 首屏层级提案已被用户后续反馈校正：主要问题是第二面板和组件整体过大、视觉不像轻巧小组件。该提案保留为历史研究，不再作为 T-7274 的当前方向。

## 决策

1. 首个改造方向采用 **Context Workbench**：保留当前网格和组件协议，增加当前工作上下文、首屏语义分区和明确的继续动作。
2. 默认首屏优先回答“我可以继续什么/今天要处理什么”，外部资讯和低频统计退到次级区域。
3. 自由画布、小地图和归档恢复保留为独立 P1 实验；若实现，必须与现有 `layouts` 并存、可只读预览、可放弃、可键盘聚焦并在窄屏降级。
4. 不根据无法核验的 Archive 插件细节复制数据格式、拖拽规则或第三方代码。

## 影响

- T-7274 可以在不迁移现有布局、不新增网络请求的条件下验证首屏层级。
- 现有组件健康、缓存/陈旧和失败回执继续复用；本 ADR 不改变它们的真实性语义。
- 未来若做自由画布，需要额外的场景数据模型、焦点/缩放交互和迁移门禁，不能作为普通视觉优化混入。
