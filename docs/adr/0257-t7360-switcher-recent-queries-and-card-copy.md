# ADR 0257：T-7360 切换器近期搜索词历史重放、卡片悬停复制块链接与门限校准

日期：2026-10-21  
状态：accepted  
任务：T-7360  

## 背景

在第一面板（切换器与深入穿透检索）的持续深化中：
1. **高频重复查询记忆诉求**：用户反复检索相同关键词或符号语句（如 `^并发限制`、`@系统架构`）时，需要重新敲入；
2. **卡片微交互直达**：用户在浏览已打开页签时，高频需要快速获取该文档/块的 `siyuan://blocks/...` 引用链接，此前需呼出动作画板或右键菜单，鼠标操作路径长。

## 决策

1. **近期搜索词历史记录与一键重放（Recent Query Replay）**：
   - 自动在会话中记忆最近 5 次非空搜索词（长度 >= 2）；
   - 在切换器空态区域（无已打开页签或零词态）装配 `.sw__recent-queries` 胶囊行：
     - 点击任一词条即可秒级重放该搜索并自动触发检索；
2. **卡片悬停快速复制块链接把手（`.sw__copy-btn`）**：
   - 在桌面端切换器卡片右上角（紧邻关闭按钮，x: 34px, y: 6px）装配轻量微链接图标；
   - 默认透明，悬浮（Hover）或键盘聚焦（Focus-within）时平滑淡入；
   - 点击直接将块超链复制到剪贴板并冒泡成功提示；
3. **包体预算与门限微调（ADR 0257）**：
   - raw bundle 观察线由 1192 KiB 校准至 1194 KiB（1,222,656 字节，实测 1,220,915 字节，余量 1,741 字节）；
   - 归档包门限由 600 KiB 校准至 602 KiB（616,448 字节，实测 614,563 字节，余量 1,885 字节）；
   - 单条目压缩上限维持 332 KiB（339,968 字节，实测 329,440 字节，余量 10,528 字节）。

## 证据与验证

1. **定向测试**：`tests/switcher-recent-queries-and-card-copy.test.cjs` 4/4 通过；
2. **全量单测与审计**：9025+ 项单测全绿，四大批量审计全部 PASS。
