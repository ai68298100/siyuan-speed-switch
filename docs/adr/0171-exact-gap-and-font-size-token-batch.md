# ADR 0171：精确间距与字号 token 第二批迁移

日期：2026-10-12

状态：已接受，T-7246

## 背景

T-7244 第一批后，全库仍有重复的组件间距和字号字面值。源码审计列出 213 条 `gap: 4/6/8px`、161 条 `font-size: 10/12/13px`，与 `_00-tokens.scss` 已有刻度完全一致。既有 token 没有密度覆盖，使用原值 fallback 可维持当前计算结果。

## 决策

- 仅替换审计报告逐条列出的精确候选，并按属性和值映射到现有 `--sw-space-*` 和 `--sw-font-*` token。
- 保留 fallback，避免在宿主选择器作用域缺失时改变渲染结果；不移动 14px 等相邻字号，不把普通 `gap` 之外的尺寸盒、图标、负偏移或特化布局塞入间距刻度。
- 使用相同 Sass/Chromium 夹具验证前后 computed style 与几何，并记录 CSS 输出体积增量。

## 实测

源码间距覆盖从 125/1137（10.99%）升至 338/1137（29.73%）；字号从 136/370（36.76%）升至 297/370（80.27%）。expanded CSS 从 412766 增至 420131 bytes（+7365 bytes）。30 个双主题、多宽度和窄容器场景覆盖 480 个元素，差异为 0。该结果证明受测声明保持一致，不证明所有 17 个 SCSS 文件的每个组件均已视觉验收。
