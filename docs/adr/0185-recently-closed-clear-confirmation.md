# ADR 0185：清空最近关闭记录需要二次确认

日期：2026-10-13  
状态：已接受，T-7257

## 背景

历史下拉菜单已经为“最近打开”提供二次确认，但“最近关闭”仍会直接清空。两者都属于不可撤销的批量删除，行为不一致会让用户误触后失去恢复入口。

## 决策

- 清空“最近关闭”前统一使用本地化确认对话框。
- 中文提示明确说明清空后无法从此处恢复；英文提供等价后果说明。
- 用户取消时不修改数据、不保存、不刷新列表；确认后沿用现有清空、持久化和刷新流程。

## 验证

- `tests/history-clear-confirm-contract.test.cjs` 正向断言确认、清空和负向删除探针均通过。
- `pnpm exec tsc --noEmit` 通过。

## 边界

单条历史移除仍由条目菜单直接执行；本 ADR 只约束分区级批量清空，不改变历史数据结构或恢复策略。
