# ADR 0172：精确既有刻度的跨样式模块迁移

日期：2026-10-12

状态：已接受，T-7247

## 背景

T-7244/T-7246 完成共享外壳和主要样式模块中的两批精确迁移后，复扫 17 个 SCSS 文件仍发现可以直接复用已定义刻度的声明。逐项核对后，候选为 298 条间距（含每个分量都属于既有刻度的 shorthand）、17 条字号、34 条行高和 134 条字重。候选不包含零值单项、auto、负值、特殊字号或未定义的行高/字重。

## 决策

- 仅将逐条审计到的精确字面值迁移为对应 CSS token，并在每个 token 中保留原值 fallback；组合间距只替换其命中的非零分量，零值保持不变。
- 继续使用既有六档间距、七档字号、四档行高和五档字重；不因凑覆盖率新建刻度，也不把邻近值归入刻度。
- 使用同一 30 场景/480 元素 Chromium 夹具在迁移前后比较计算样式和几何；另记录 expanded CSS、生产包体和覆盖率。源码收敛不被视为性能收益。
- 负向探针直接破坏被测样式中的 fallback，必须由指定契约测试精确拦截，并在测试后逐字节恢复文件。

## 实测

- 精确候选：间距 298、字号 17、行高 34、字重 134，共 483 条。
- 迁移前后 Chromium 计算样式与几何差异为 0；expanded CSS 从 420131 增至 432369 bytes（+12238 bytes）。
- 迁移后源码覆盖：间距 636/1137（55.94%）、字号 314/370（84.86%）、行高 41/117（35.04%）、字重 147/163（90.18%）。

## 边界

Chromium fixture 不替代思源宿主、Android 或读屏器验收。CSS 输出增加是可见成本，不将本次迁移宣传为加载或包体优化；后续只在有明确测量与维护收益时继续迁移。
