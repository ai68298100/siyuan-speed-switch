# ADR 0091：工作台材质 × 尺寸档位系统（T-6968 原型实现决策）

日期：2026-09-28。状态：已采纳（原型 T-6968 经用户评审通过）。

## 决策

按已批准原型（`docs/design/workbench-redesign-2026-09-27.html`）将工作台从「统一白卡网格」升级为**材质 × 尺寸双轴系统**：

1. **材质四类**（组件目录按 moduleId 显式声明，白名单外回退 `plain`）：
   - `plain`：surface 底 + hairline 边框（日历/热力图/列表等信息型组件）；
   - `accent`：主色 135° 渐变 + on-primary 文字（打卡/倒数日/目标类）；
   - `dark`：固定深色渐变 StandBy 风（时钟/引言），明暗主题恒定；
   - `vibrant`：内容驱动语义渐变（天气=天空），**仅限组件显式声明的预设，不做自动取色**。
2. **尺寸档位**：S=3×2 / M=6×2 / L=6×4 / X=12×3（英雄位，每面板至多 1 个置首行）——映射既有 12 列网格的跨度组合，不新增布局引擎；X 档默认授予世界时钟类，用户可在编辑态改档。
3. **声明契约**：`home-model.js` 的 `HOME_TILE_MATERIALS` 显式登记 + `resolveHomeTileMaterial` 纯函数解析（白名单外一律 plain）；第三方组件未声明即安全回退，不阻塞接入；后续逐组件规格（T-6971）扩写档位明细。
4. **与既有机制正交**：面板尺寸模式（follow/adaptive/custom/fullscreen）描述**弹窗**大小，材质/档位描述**格内**呈现，二者并存互不替代；刷新管线、健康回执、缓存回退语义不变。

## 边界

- 不动组件协议、第三方 provider 契约、数据端点；`vibrant` 仅限显式声明预设渐变，不自动取色；不建第二套视觉系统——材质经皮肤层（ADR 0073）作用域派生，明暗主题与对比度采样继续覆盖。
- 历史快照（T-6953）包含材质渲染结果所在状态，但材质本身是展示层属性，不进入撤销语义。

## 分期落地

- **Slice 1（本批）**：材质目录 + 渲染接线 + 四材质样式（含彩色材质前景继承、失败描边延伸）+ 单测/接线契约/负向验证。
- **Slice 2**：尺寸档位落格（S/M/L/X 跨度映射 + 编辑态改档 UI + 尺寸角标）。
- **Slice 3**：查看态微标头与编辑态抖动模式全量 chrome。
- **Slice 4**：58 组件逐个规格卡（T-6971）+ widget-protocol 材质/档位声明字段。
