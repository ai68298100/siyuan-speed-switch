# ADR 0068：悬浮球完整交付的交互与配置边界

- 日期：2026-09-22
- 状态：已接受；本地实现与完整验证已完成，真实宿主/设备验收后置
- 关联任务：T-6764（B7）
- 修订：ADR 0066 §3、§4、§6；保留原 ADR 作为决策历史，不回写历史文档
- 关联：`docs/floating-ball-ui-spec.md`、ROADMAP §8.0.7、`docs/gate-audit-checklist.md`

## 背景

B0~B6 已建立动作模型、三端控制器、动作面板、设置页和生命周期。按完整 UI 方案核对，仍有外观/行为参数未充分接入、拖动目标和球体的几何耦合、更多面板键盘等效入口、组件面板动作以及真实可视区边界需要收口。用户要求一次性完成悬浮球开发，并明确自律线、归档上限和压缩条目线可随合理功能增量调整。

本轮保留共享动作注册表和执行链，完成这些交互边界，不新增第二套动作定义或执行系统。

## 决策

### 1. 外观与行为共享，位置、开关和动作列表分端

配置仍使用 schema v1。`enabled`、`position`、`actions` 按 desktop/sidebar/mobile 分别保存；`appearance` 与 `behavior` 为三端共享。此处明确修订 ADR 0066 §6 中尺寸、透明度、滚动行为也全部分端保存的设想，避免 UI 选择端侧后实际编辑共享值却让用户误认为独立。

桌面和手机尺寸允许 44~64 px、默认 48 px，侧栏固定 44 px。边距 `marginPx` 为 0~32 px、默认 8 px。设置页明确共享范围，并禁用侧栏尺寸调节。滑杆 input 仅更新模拟预览，change 才持久化并刷新已打开的入口。

`snap=false` 时持久化可选 `position[surface].xRatio`，与 `yRatio` 一起表达自由停放；重新开启吸附使用边缘位置。缺少增量字段的旧 schema v1 配置按默认值读取，无需覆盖原动作数组。位置和展开/执行状态仍不进入导出，导入保留当前设备位置。

### 2. 动作目标稳定，选择动作不迁移停靠位置

一次拖动开始时测量宿主边界并计算首层目标，目标保持固定；球体通过 transform 跟随指针。pointermove 使用缓存的几何命中，不反复读取 DOM 布局。

命中动作或“更多动作”后球体恢复原停靠位置，随后执行目标；只有空白松手才保存新位置。取消、捕获丢失、窗口失焦等退出恢复原位置，不写盘。这修订了原方案“选择动作也吸附到最终松手点”的规则，避免日常执行动作逐步改变用户停靠位置。

纯几何模块 `floating-ball-layout.js` 输出 viewport 坐标。桌面/手机优先内收半环，侧栏优先竖列；顶部/底部平移和避开球体后仍放不下，则回退紧凑网格。目标至少 44 px，首层最多 6 项。极小空间缩减可见目标时保留最后的“更多动作”，不把目标缩成难以触控的尺寸。命中半径增加 8 px，重叠容错区选最近目标，同距按稳定索引确定唯一目标。

### 3. 更多面板承担完整键盘入口

更多面板打开时隐藏首层并移出 Tab 顺序，合并首层和其他已配置可展示动作，并在列表内去重。这修订 ADR 0066 §4 的溢出分工：首层仍负责拖动效率，更多同时提供其键盘等效入口。

更多提供名称/ID/来源搜索、分组、来源与能力说明、启用开关、无结果空态及“管理快捷动作”。管理入口直达悬浮球设置标签；排序留在设置页的上移/下移或拖动控件中。明确不支持当前端的动作留在设置页解释；能力未知、提供方未加载或用户禁用的动作可展示原因，但不能执行。

组件面板使用共享 builtin `home`，经既有共享执行器打开第二面板。新配置/恢复默认包含日记、搜索、组件面板、设置；已有用户动作列表不被默认预设更新覆盖。

### 4. 执行、滚动和弹层按生命周期隔离

执行态有 1500 ms watchdog，防止未完成的 provider Promise 永久锁住入口。每次执行使用版本标记，旧 completion 不能解除较新的执行态；destroy 清理定时器并使迟到回调失效。

滚动按端侧宿主识别，桌面不消费侧栏滚动。仅滚动导致隐藏时提供可聚焦的边缘恢复按钮；其他隐藏/让位原因仍具有优先级。

弹窗深度在尚无球体时也计数。弹窗期间启用/关闭端侧或修改 `yieldToModals`，按当前配置和当前 controller 重新应用状态；最后一个释放回调恢复当前实例，不能只恢复打开弹窗时捕获的旧实例。释放幂等，用户关闭让位时轻触入口也可正常使用。

### 5. 尊重实际可视区及宿主层级

位置和拖动目标以 `visualViewport` 可见矩形为基础，侧栏再与宿主矩形取交集。手机加入 CSS safe-area inset 与底部 48 px 导航预留；viewport resize/scroll 事件重算边界。主入口和恢复按钮保持低于宿主 `siyuan.zIndex` 的受限层级，无轮询或不断抬高固定 z-index。

### 6. 容量线用于审计，不替代功能取舍

新增几何模块后生产依赖闭包为 63 个模块，审计上限由 62 调至 64；它是有边界的异常增量检查，不是删除必要几何模块的理由。该门禁调整仍需同条件负向验证。

本轮最终 raw bundle 885369 bytes（约 864.6 KiB），仍低于 ADR 0067 的 896 KiB 自律线，无需扩大包体线。归档 405921 bytes、压缩后的 index.js 240657 bytes，低于保持原值的 512 KiB 归档上限和 256 KiB 压缩条目线；以后如确有合理功能增量，可按用户授权重新校准并保留增长来源、验证证据。

## 验证与验收边界

- 纯几何动态测试 8/8：左右镜像、上下边界、侧栏、低高度网格、缩减保留更多、100 组拖动数据、唯一命中和畸形输入。三轮负向验证分别注入第 7 个目标、遗漏目标半径的边界、遗漏 8 px 命中容错，精确失败后恢复原字节。
- 宿主动态测试 9/9：AST 提取并执行真实 `index.ts` 方法，动作执行器、registry 和集成场景的面板使用生产实现；覆盖参数创建/更新、弹层偏好、嵌套释放、替换 controller、端侧销毁和组件/设置/搜索路由，以及提供方注销/恢复、命令/dock 缺失、拖动/更多打开前刷新和环境关闭面板。十一轮内存变异分别破坏尺寸、让位、组件、当前实例释放、管理页签、adapter/command/dock 可用性、拖动前刷新、更多打开前刷新和面板关闭接线；目标测试精确失败，生产文件哈希保持不变。
- 更多面板 22/22、设置 UI 17/17、控制器 21/21 通过；完整 `pnpm verify:release` 通过：5990/5990 测试（222 文件）、TypeScript、生产构建、可复现构建 3/3、release:check、quality/integration 各 50/50 及四套 UI smoke；独立 `release:audit` 50/50。
- 悬浮球 Chromium 夹具 22 个场景通过，覆盖亮暗主题、184 px 侧栏、横屏、真实 visualViewport 缩小、三端面板搜索/焦点，以及连续 100 次真实指针拖动（每次恰好一次执行、无意外点击和位置保存、单例 portal）。20 px 热区和越界样式注入均被准确识别，恢复后 CSS 字节一致且正向再次通过。
- 生产图上限临时降至 62，真实 63 模块闭包精确失败；触控阈值、执行超时、默认动作、设置持久化/恢复、面板幂等/首层合并及发布计数等新增或修改契约均完成负向验证，恢复原字节后完整门禁通过。
- 本地实现范围已收口。真实 SiYuan 最窄侧栏/主题/宿主交互和 Android 真机触控、旋转、键盘与安装升级仍按 B-005 / B-004 后置；浏览器夹具不冒充真实宿主或设备证据。

## 未采用的方案

- 让动作目标跟着拖动球体一起移动：指针追逐目标，热区会逃离用户手指。
- 选择动作同时保存松手位置：常用动作选择会意外迁移停靠点。
- 通过缩小热区保留全部目标：小视口下容易误触；保留更多入口更可恢复。
- 首层与更多同时可聚焦：隐藏的拖动布局会泄漏到键盘路径。
- 为守住内部模块数量而合并无关职责或删减核心功能：模块边界和性能由实际成本与测试证据决定。
