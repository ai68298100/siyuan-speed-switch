# ADR 0086: 片段编辑状态与常驻保存

- 日期：2026-09-27
- 状态：已采纳（T-6943/T-6944）
- 关联：ADR 0078、ADR 0080、ADR 0083

## 背景

编辑内容后，工作室仍显示原生片段的启用/禁用状态或草稿，缺少明确的未保存提示。属性区的描述和五条安全边界排在字段前，保存按钮在长滚动区末尾。低于 900px 时整个工作室滚动，单纯搬到 footer 仍不能保证保存可见。

## 决策

1. 复用既有 dirty 判定，不另建编辑状态。顶部及属性区徽标在有改动时显示“未保存”；保存成功或精确还原 baseline 后恢复原生状态。空白新建仍显示草稿，保存失败不得假装已保存。顶部徽标以 polite live region 提供可访问状态反馈。
2. 保存按钮仅保留一个，移入常驻 footer，沿用同一 mutate/save、busy/loading/error 禁用条件及原生保存语义。新片段仍保存为禁用草稿，不自动启用。
3. 属性区按身份、名称/类型、原生状态与操作、描述和安全边界排序。五条边界全部保留，不折叠、不移入工具提示；保存位置与安全承诺分离，不新增设置。
4. 窄窗口只让中间 layout 滚动，工作室保持视口内 flex 布局，顶部和 footer 不随正文滚走；footer 允许换行以容纳本地化标签。

## 验证边界

真实隔离思源桌面验证编辑、禁用保存、精确还原和多尺寸可达性；不覆盖个人安装，不宣称 Android 支持或真实 AI 请求通过。测试创建的原生片段仅在隔离工作区内按唯一名称清理，保留其他片段。
