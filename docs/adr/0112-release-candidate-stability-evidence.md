# ADR 0112：发布候选必须通过连续全链验证

- 状态：已接受并完成（T-7082）
- 日期：2026-10-03
- 关联：T-7079、T-7080、T-7081、B-004、B-005

## 背景

T-7079～T-7081 已完成依赖安全、搜索编排和工作台生命周期收口，但此前的全量测试曾出现一次宿主重绘时序抖动和一次性能基准抖动。单次绿色运行不能证明发布候选稳定，因此需要在不放宽阈值、不修改无关测试的前提下重新执行完整发布链，并把浏览器 E2E 与真实宿主验收边界写清楚。

## 决策

1. 发布候选使用仓库既有 `pnpm verify:release` 作为单一连续入口，顺序执行类型检查、双构建复现、全量测试、发布检查、质量审计、集成审计和全部 smoke。
2. 可复现性以 `dist/index.js`、`dist/index.css` 和 `package.zip` 的字节级结果为准；本轮构建结果分别为 **1163406**、**293457** 和 **574716** bytes，`repro:audit` 为 **3/3**。
3. 本轮全量测试为 **8071/8071**；`quality:audit` **50/50**、`integration:audit` **50/50**、发布检查和 TypeScript 检查均通过。移动卡片、移动布局、Chromium 明暗主题、浮球浏览器 **24** 场景和 surface-switch 三 case E2E 全部通过。
4. 连续发布链退出码为 **0** 才能把 T-7082 标记完成；不因单次性能抖动调高阈值，也不把浏览器夹具结果写成真实 Android 或真实窄侧栏结论。

## 未采用

- 不以 `pnpm test` 单独通过代替产物复现、审计和端侧 smoke。
- 不把 Chromium/JSDOM E2E 当作 Android 真机或思源真实窄侧栏验收。
- 不在发布候选收口阶段顺手修改产品行为、性能阈值或无关失败测试。

## 验证

- `pnpm verify:release`：退出码 **0**。
- 类型检查：`pnpm exec tsc --noEmit` 通过。
- 可复现构建：**3/3** artifacts match。
- 全量测试：**8071/8071**。
- 发布检查：产物尺寸与 readiness 快照一致。
- 质量审计：**50/50**；集成边界审计：**50/50**。
- E2E/smoke：移动卡片、移动布局、Chromium 明暗主题、浮球 **24/24** 场景、surface-switch 三 case 全部通过。
- 工作树检查：`git diff --check` 通过；本轮未提交、未 push。

## 边界与后续

本 ADR 只证明当前未发布工作树的本地构建、自动测试、浏览器 E2E 和受控 smoke 链稳定。Android 真机触控/旋转/安装升级以及真实思源桌面最窄侧栏宽度和最新 UI 生命周期仍由 B-004/B-005 管理；取得设备或已认证宿主后，按既有矩阵补充真实证据。
