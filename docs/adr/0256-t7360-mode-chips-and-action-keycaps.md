# ADR 0256：T-7360 切换器常驻多模态穿透药丸 Chips、画板立体机械键帽与门限校准

日期：2026-10-21  
状态：accepted  
任务：T-7360  

## 背景

在第一面板（切换器 / 深入穿透检索 / 次级动作画板）的用户体验对标与可用性调研中，发现：
1. **多模态前缀发现性断层**：虽然系统支持 `@`（大纲）、`^`（正文块）、`#`（标签）、`!`（书签）、`>`（命令）、`?`（速查），但用户需要记忆语法；
2. **动作画板快捷键视觉平淡**：画板右侧的快捷键此前为普通文本框，缺少类似 Raycast 的物理键帽质感。

## 决策

1. **搜索顶栏常驻多模态穿透药丸 Chips（`.sw__mode-chips-bar`）**：
   - 切换器与侧栏顶部常驻一排圆润饱满的药丸 Chips：`[全部页签]`、`[@ 大纲]`、`[^ 正文]`、`[# 标签]`、`[! 书签]`、`[> 命令]`、`[? 速查]`；
   - 点击任一 Chip 即可带前缀检索并自动获焦；输入框输入前缀时光标与激活状态联动高亮；
2. **动作画板立体机械键帽（`.sw__palette-item-shortcut`）**：
   - 键帽采用物理下沉阴影、线性微渐变背景、等宽代码字体与 2px 实体微凸底边框，选中时高亮匹配主题色；
3. **包体预算与观察线校准（ADR 0256）**：
   - raw bundle 观察线由 1190 KiB 校准至 1192 KiB（1,220,608 字节，实测 1,219,436 字节，余量 1,172 字节）；
   - 归档包门限维持 600 KiB（614,400 字节，实测 613,957 字节，余量 443 字节）；
   - 单条目压缩门限由 328 KiB 校准至 332 KiB（339,968 字节，实测 329,065 字节，余量 10,903 字节）。

## 证据与验证

1. **定向测试**：`tests/action-palette-keycaps-and-mode-chips.test.cjs` 3/3 通过；
2. **全量单测与审计**：9018+ 项单测全绿，四大批量审计全部 PASS。
