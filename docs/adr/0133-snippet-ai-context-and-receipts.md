# ADR 0133：片段 AI 上下文选择与诚实回执

- 状态：已采纳
- 日期：2026-10-04
- 任务：T-7093 / T-6994 / AB-1307 / AB-1601

现有生成、优化、解释、迭代只调用思源编辑 AI，没有文档、选区、块、搜索结果或外部数据读取通道。因此选择器仅呈现可用的片段代码及最近迭代对话，默认都不勾选；其他范围在说明中明确不读取，不增加假入口。指令必发，优化/解释/迭代须选择代码；代码与对话合计有 64 KiB UTF-8 上限。

提供方、模型、账单和额度由宿主控制。插件只说明使用思源配置且无法确认费用，不预探测能力、不虚构供应商或报价。401/403 显示授权拒绝；失败提供手动重试；取消恢复发送入口并保持草稿。

复制/导出候选使用候选文本，与复制/导出草稿独立。草稿改变后显示过期提醒，接受仍经既有替换确认、行级差异和撤销事务。浏览器受控 SSE 验证交互与请求边界，真实提供方在线生成仍另记环境证据。
