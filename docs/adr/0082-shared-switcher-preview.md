# ADR 0082：第一面板共享预览窗格

- 日期：2026-09-26
- 状态：已采纳（T-6900/T-6901）
- 关联：ADR 0079、T-6895、`docs/unified-platform-gap-matrix-2026-09-26.md`

## 背景

全库搜索结果已有大纲与摘要预览，但空查询的已开页签没有。默认全屏后，这使右侧预览只在搜索结果出现时可用。已有预览管线具备根文档 ID 校验、两路内核取数、300ms 防抖与代际丢弃，另建一条页签预览链会造成状态和请求语义分叉。

## 决策

1. 桌面宽容器的页签组与搜索结果共用同一个预览 DOM 节点及同一取数管线。焦点或悬停落在哪个区域，窗格就挂在哪个区域；空查询时恢复到页签区域。初始选中页签也触发预览。
2. 预览对象只取经过块 ID 校验的文档根 ID。非文档页签保留卡片和切换能力，在预览区显示“仅文档支持大纲预览”的 blocked 回执。
3. 两路内核结果逐项判断成功、失败或畸形；一路失败不清除另一路有效摘要，整体状态为 error。新目标进入防抖、列表重建、结果区重建和会话销毁都作废旧请求。
4. 移动端和侧栏继续使用原单列列表；桌面容器不足 680px 时不挂预览，避免卡片列被压得难以使用。预览仍只读，使用现有白名单端点，不持久化正文。
5. T-6937 扩展正文速览：块表的 `sort` 在同一文档的多个段落上可能相同，块 ID 不代表阅读顺序，因此正文改从已有 `/api/filetree/getDoc` 的首段块流提取。宿主 HTML 只在脱离页面的 `template` 中解析，白名单读取前 12 个标题、段落、列表项、引用与代码块的纯文本，再由插件自行创建 DOM；正文总量限 900 字。大纲仍走原接口并解码常见实体。不得将宿主 HTML 原样挂载进预览窗格。

## 取舍

共享节点需要在页签区和搜索结果区之间移动；这比复制两套窗格多一处 DOM 协调，却保证只存在一个当前预览和一套请求代际。真实桌面主题、最窄侧栏与小屏宽度仍按 B-005 补验。
