# ADR 0225：T-7144 大纲宿主回退与待办连续点击回执保护

日期：2026-10-18  
状态：accepted

## 背景

真实隔离思源 3.8.8-alpha.3 的未聚焦窗口中，当前文档大纲错误地进入“请先打开文档”空态。宿主的 `getActiveTab()` 默认只返回获得窗口焦点的页签；同时 `getDocOutline` 在 `preview:false` 下不返回标题树。另一个高频路径中，待办复选框允许连续点击，较早写入请求的失败回执可能覆盖较新的乐观状态。

## 决策

1. 大纲读取先使用聚焦页签，失败或为空时回退到 `getActiveTab(false)`，让后台 dock、无头回归和从其他窗口打开的只读组件仍能跟随当前文档。
2. 所有大纲消费者统一请求 `preview:true`，由宿主返回标题树；响应仍必须通过数组形状守卫和有界 `flattenOutline`。
3. 待办复选框为每一行维护单调递增的 toggle revision。只有最新点击的 Promise 失败或返回 `false` 时才允许回滚，旧回执只被忽略；成功写入后的读回刷新失败继续保持乐观状态并交给控制器展示重试。

## 证据与边界

- 真实宿主 Playwright：`tests/e2e/t7144-widgets.spec.mjs` 1/1，通过并读到 `Section Alpha`、`Detail Beta`。
- 定向契约：大纲、文档上下文、洞察组件与 Agent 大纲测试 141/141；待办连续点击延迟 Promise 测试覆盖旧失败回执与当前失败回滚。
- 全量门禁：8801 通过、1 跳过、0 失败；可复现构建 3/3；Chromium、悬浮球、surface switch、第三方生命周期 smoke 全部通过。
- 该决策只覆盖只读大纲和待办写入回执排序，不宣称 Android、真实 provider 或最新未发布修改已完成全量真实宿主验收。
