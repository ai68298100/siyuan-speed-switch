# ADR 0085：第二面板时钟心跳采用稳定行局部补丁

- 状态：Accepted
- 日期：2026-09-27
- 关联：T-6935、ROADMAP §8.0.7 F1、ADR 0052

## 背景

第二面板的本地时钟、世界时钟和每日引言由分钟或秒级心跳刷新。原实现每次刷新都重新渲染并替换整张模块卡，导致滚动位置和焦点需要补偿，已有行上的监听器也随节点销毁。

## 决策

1. 通用列表行输出稳定的 `data-sw-row` 标记；时钟行的可变 `item.value` 单独输出为 `data-sw-row-value` 节点，并把焦点身份绑定到稳定标签。
2. `home-controller` 只对三个本地时钟模块尝试补丁快路径。快路径要求模块 ID、状态、折叠状态、行数、标签和行结构字段一致，并检查 DOM 行标记仍完整；满足时只更新统计值、行值、可访问名称和头部元数据。
3. 标签、行数、链接/完成状态、值节点存在性或其他结构发生变化时，快路径返回失败，沿用原有整卡重建和焦点恢复逻辑。快路径不引入观察器、虚拟滚动或运行时依赖。

## 结果

- 分钟/秒级数值变化保留模块、行和按钮节点，焦点与外部监听器不丢失。
- 世界时钟的每行时间值进入可见文本和无障碍名称；旧的 `data-value` 语义继续保留。
- 只有统计值的本地时钟（关闭日期行时）也归一化为 `ready`，因此仍可复用同一补丁路径。
- 结构变化仍通过完整渲染处理，避免用局部补丁猜测 DOM 形态。
- 快路径范围被限制在明确的本地只读时钟模块，联网组件和其他列表不改变刷新语义。
