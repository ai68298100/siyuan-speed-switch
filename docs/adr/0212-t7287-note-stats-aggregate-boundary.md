# ADR 0212：笔记统计零值与缺失聚合边界

- 日期：2026-10-16
- 状态：accepted
- 任务：T-7287
- 相关：T-7144、ADR 0209、ADR 0211

## 背景

笔记统计使用一次 SQL 聚合读取文档数、`length` 字符估算和相邻时间窗活动。空库的合法聚合行应包含一组 0；内核响应缺失或没有聚合行则不能被当作 0。候选矩阵还缺少旧宿主 `length` 语义证据，因此本轮只冻结输入边界。

## 决策

1. 模型接受显式零值聚合并显示合法的 0 统计，保持空库可解释。
2. `null`、数组或缺失聚合行返回 `null`；adapter 继续抛出 `invalid_note_stats`，交给统一失败状态处理。
3. 不把缺失字段、旧宿主包装或 `length` 语义猜测成别名，不改变 SQL 查询与统计口径。

## 验证

- 模型 fixture 覆盖全 0 聚合、`null` 和数组输入。
- 接线契约冻结 `row = (json?.data || [])[0]`、条件 payload 和失败检查。
- 两路负向注入（移除 `row ?` 保护、移除失败检查）均使目标测试精确失败，并恢复 `src/index.ts` 原始 SHA-256。

## 边界

本任务只确认空库和缺失聚合的处理，不证明任何旧宿主 `length` 字段语义，也不把一次隔离宿主结果升级为跨版本兼容承诺。取得真实旧宿主 fixture 后，才可另立字段归一化任务。
