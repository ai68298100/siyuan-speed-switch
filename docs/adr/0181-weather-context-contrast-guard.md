# ADR 0181：天气组件上下文对比度门禁

日期：2026-10-13  
状态：已接受（T-7253）

## 背景

天气组件使用蓝紫渐变和白色上下文文字。原有 Chromium smoke 只从祖先 `backgroundColor` 取背景，既无法覆盖渐变，也没有把上下文采样纳入通过条件；实测辅助文字在渐变端点约为 2.83:1～3.82:1，低于普通文本 4.5:1。

## 决策

- 在天气上下文文字下增加深色半透明衬底，保持原有渐变卡片和白色品牌层级。
- smoke 计算径向高光与两个渐变端点的保守最低对比度，并把 `weatherContext` 纳入普通文本、`weatherStatValue` 纳入大字聚合门禁。
- 该检查是浏览器夹具的可读性证据；真实思源主题和宿主字体仍按 `BLOCKERS.md` 的环境边界验收。

## 验证

- 温度高光回退到 32% 的负向运行得到 2.23:1，移除上下文衬底的负向运行得到 3.07:1，两者均使 smoke 失败；温度高光从 32% 降至 8% 后，深浅主题温度大字均为 3.07:1、上下文均为 10.4:1，完整浏览器 smoke 通过。
