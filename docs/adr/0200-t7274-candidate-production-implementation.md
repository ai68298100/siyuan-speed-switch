# ADR 0200：紧凑小组件候选实现的验证门槛

- 日期：2026-10-16
- 状态：已接受为候选实现，尚未完成验收
- 任务：T-7274 / T-7275
- 相关：ADR 0199

## 背景

T-7274 的静态稿已经证明小窗口、混合尺寸和轻材质在受控 Chromium 视口下没有横向溢出；工作树同时出现了对应的生产候选改动。原 ADR 0199 只允许先做原型，因此需要明确这批改动目前的工程状态，避免把候选实现误称为已发布行为。

## 决策

1. 保留工作树中的候选实现：新装工作台使用 `custom / 920×390 / soft`，首次播种使用目录声明的混合尺寸，非全屏工作台使用最终层叠层的轻材质覆盖。
2. 已保存布局和用户显式的 `homeSizeMode`、尺寸与配色继续由现有归一化路径保留；候选实现不迁移或重写这些值。
3. T-7274 在真实宿主视觉回归完成前保持 `in_progress`，不改版本、不发布、不更新个人安装。
4. T-7275 必须补齐真实宿主截图/计算样式、40px 网格行高、soft 对彩色材质的覆盖、旧设置缺字段和显式偏好回归；全部通过后才可将候选实现提升为完成。

## 取舍

此决策允许继续收口已经开始的工作树改动，同时保留视觉不合格时回退或调整的空间。它不引入 Context Workbench、自由画布、新请求或新的组件数据源。
