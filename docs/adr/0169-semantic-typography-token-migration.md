# ADR 0169：语义排版与共享间距渐进收敛

日期：2026-10-12

状态：已接受，T-7244/T-7246 两批

## 背景

T-7243 后的 17 个 SCSS 文件，按去注释、排除变量定义、每条声明记一次的口径统计：间距变量消费 37/1137，字号 109/370，行高 0/117，字重 0/163。计数认可任意 CSS `var()` 与 `$sw-*`；零值、auto、继承和特化值仍在分母中，因此这是源码覆盖率，不能代替语义一致性或视觉验收。

## 决策

- 基础值继续由 `_00-tokens.scss` 的插件根选择器持有；平台和 R54 的间距名称只是兼容别名。
- 第一批迁移共享外壳、视觉适配层中用途明确且与现有刻度精确相等的声明。保留计算值，避免把所有 14px、品牌字重、1px 对齐、负偏移和图标盒子强塞进普通正文刻度。
- 第二批只迁移审计确认与既有刻度完全相等的 `gap: 4/6/8px` 与 `font-size: 10/12/13px`；共 213 条间距与 161 条字号声明。CSS 变量带原数值 fallback，不将临近值或特化值强行归档。
- 文本行高建立紧凑说明 1.2、界面说明 1.4、正文 1.5、阅读摘要 1.6 四档；字重建立正文 400、元信息 500、小标题 600、强调标题 650、导航标题 700 五档。品牌专用 720/800 以及图标居中的 `line-height: 1` 本批保留。
- 不新增字体文件、界面组件变体或主题切换器。浅色/暗色继续使用同一套思源主题变量。
- 迁移前后使用同一审计脚本计数，并用 Chromium 对相同夹具在多宽度、双主题下比较计算样式和几何尺寸。包体单独复测，不将 token 收敛声称为性能收益。
- 新增/修改契约遵循门禁审查清单，并对实际源文件负向注入、核对失败项、逐字节恢复。

## 实测结果

同一审计脚本、17 个 SCSS 文件、去注释并排除变量定义后的源码覆盖率：

| 类别 | 迁移前 | 第一批后 | 第二批后 |
| --- | ---: | ---: | ---: |
| 间距 | 37/1137（3.25%） | 125/1137（10.99%） | 338/1137（29.73%） |
| 字号 | 109/370（29.46%） | 136/370（36.76%） | 297/370（80.27%） |
| 行高 | 0/117（0%） | 7/117（5.98%） | 7/117（5.98%） |
| 字重 | 0/163（0%） | 13/163（7.98%） | 13/163（7.98%） |

圆角、阴影、层级、颜色和动效覆盖率本轮没有变化。Sass expanded CSS 从 409445 bytes 增至 420131 bytes（+10686 bytes，约 +2.61%）；这是 token 可维护性的体积成本，不作为性能收益。Chromium 在明暗主题、1200/560/245px 视口与窄容器的 30 个场景采样 480 个元素，迁移前后计算样式与几何差异为 0。比较边界不含真实思源桌面、Android 真机或读屏器。

全库覆盖率仍不等同于语义统一；源码计数中的变量消费不证明所有 token 都受同一语义控制。剩余间距、行高、字重及特化颜色继续按可测、可验证的组件批次推进。
