# ADR 0213：组件诊断预览与导出字段边界

- 日期：2026-10-16
- 状态：accepted
- 任务：T-7288、T-7149

## 背景

健康详情已有逐项复制，但点击会立即写入剪贴板；旧内容状态会误写为正常，预先填入的 reasonClass 能绕过分类。标题和实例 ID 可自定义，直接输出不满足默认脱敏要求。

## 决策

1. 在现有健康详情中切换到只读预览，保留取消与显式复制；不增加嵌套弹窗。取消回焦行入口，关闭详情回焦回执入口。
2. 复制只使用预览时生成的同一份摘要；在途禁用确认按钮。失败保留并选中摘要，允许手动复制；异步结果仅更新仍连接的预览。
3. 标题、实例 ID、配置和原始异常不进入摘要。模块标识只接受编译内置 DEFAULT_MODULES 的 ID，其他非空标识统一 external-widget，缺失为 unknown；不为诊断引入外部目录。
4. failed/stale/loading/ok 分别表达；失败与旧内容原因均重新过白名单，正常和加载中不补造失败原因。日期、版本与端侧也独立校验。
5. 版本来自构建期 manifest 常量与只读宿主 config；端侧和 workbench 表面来自当前面板。摘要附复现步骤、预期效果与截图遮敏指引。
6. 通过压缩 README 历史城市枚举和纠正过期预算说明容纳增量，维持既有包体门禁。
7. 健康行同时挂载组件名称、时间与操作区；回归中发现原先构造的信息节点未进入 DOM，必须在同批修复，使用户能识别诊断对象。

## 验证边界

模型测试和负向注入覆盖导出字段、状态及异常日期；隔离思源 + Chrome 覆盖预览、取消、异步复制、权限拒绝、回焦和窄屏主题几何。剪贴板在测试中受控，不代表真实系统权限或 Android 验收；没有自动上传、遥测或下载路径。
