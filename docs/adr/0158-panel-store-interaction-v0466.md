# ADR 0158：面板与组件商店交互修复（v0.46.6）

- **日期**：2026-10-09
- **状态**：accepted
- **关联任务**：T-7229、T-7230

## 背景

第二面板工作台的材质被后加载样式清零，组件商店详情区又重复挂载完整目录卡；第三面板片段选择器需要频繁切换条目后才能启停。用户还要求参考代码片段管理器和 Obsidian 无限画布类产品，但不应在一个紧急小版本中引入未经验证的自由画布持久化格式。

## 决策

1. 恢复工作台单元格的 token 化圆角、阴影和景深，保持组件自身渐变和高对比主题规则。
2. 商店详情采用“标题/事实元信息 → 唯一实时预览 → 尺寸与动作”的主从层级；复用卡片构建器只抽取必要节点，避免第二份目录卡。
3. 片段目录的原生条目提供并列启用/停用按钮。写入沿用 `store.mutate` 的整表替换、读回确认和错误回执；按钮不嵌套在选择按钮内，存在脏稿时先要求保存。
4. Obsidian Canvas/Visual Notes 的自由编排、归档恢复和小地图不在本版本直接伪装实现，先作为后续可独立回滚的场景能力。

## 验证

- 组件商店结构、工作台材质和负向注入：`tests/panel2-premium-store-contract.test.cjs`。
- 片段目录按钮的兄弟节点、可访问名称、样式和嵌套违规负向注入：`tests/snippet-catalog-quick-toggle.test.cjs`。
- 真实挂载启停、脏稿守卫和既有目录/分组回归：`tests/snippet-studio-mount.test.cjs`、`tests/snippet-groups-ui.test.cjs`。
- 发布前仍需运行完整测试、TypeScript、构建、发布/质量/集成审计和全部 UI smoke；真实 Android、最窄侧栏、读屏与外部服务继续按 `BLOCKERS.md` 后置。
