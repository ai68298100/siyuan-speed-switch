# ADR 0073：可选独立皮肤层（融合模式之外的第二视觉模式）

- 日期：2026-09-23
- 状态：已接受（方向立项）；原型已产出，实施分批
- 关联决策：修订 §2.1/ROADMAP"不建立第二套视觉系统"约束的含义——**默认仍与思源主题融合；皮肤为用户显式选择的可选模式**，非默认替换
- 关联：`docs/design/skin-prototypes.html`（设计原型）、小驴打卡 `src/ui/tokens.scss`（已验证先例）

## 背景

速切全部样式走思源主题变量（`--b3-*`），保证与任何主题融合。用户提出第二方向：像小驴打卡那样完全脱离思源主题、独立设计 UI 效果（如苹果风格），让各面板有更多展示形态。这是对早期约束的有意放宽，需记录边界。

## 已验证的先例（小驴打卡）

打卡插件的做法（`src/ui/tokens.scss`）：
1. 自持双色板（明亮/暗黑定死）+ 语义 token（accent/success/warning/danger、表面层级、圆角、阴影、动效、密度）；
2. **在插件根类作用域内同时重定义 `--b3-*` 别名**（如 `--b3-theme-primary: var(--lc-checkin-accent)`），使 legacy 底层样式自然继承本设计，且不影响宿主思源；
3. `data-appearance` + `data-palette` 属性切换多套命名色板（ocean/forest/sunset）。

该机制已在真实集市插件上验证：**皮肤=变量作用域覆盖，组件选择器零改写**。

## 决策

1. **双模式**：默认"融合模式"维持现状（所有 `--b3-*` 直通宿主主题）；新增"皮肤模式"，用户在设置中显式选择（跟随思源明暗/强制明亮/强制暗黑三档外观语义，具体以实施为准）。
2. **机制**：皮肤实现为根作用域类/属性（如 `.sw-root[data-skin="apple"]`）内的 `--b3-*` 重定义 + 自持 token 层（`--sw-skin-*`：模糊、圆角族、阴影族、壁纸）。既有组件选择器**零改写**；质感层（backdrop-filter、渐变壁纸、圆角升级）作为少量附加规则放在独立样式文件（`src/styles/_10-skins.scss`），可整文件卸载。
3. **作用域隔离**：皮肤变量只定义在速切自己的根容器内（切换器弹窗/侧栏/第二面板/悬浮球 portal/设置页），绝不写到 `body`/`:root`，宿主思源与其他插件零影响。
4. **无障碍与门禁不降级**：每个皮肤必须过 T-6697 同款 WCAG AA 对比度采样（复用夹具令牌集思路）；`prefers-reduced-motion`、44px 触控、focus-visible 语义在皮肤下保持。
5. **不做**：不做主题编辑器/用户自定义取色（Material You 式动态取色维持暂缓）；皮肤不做"半融合"混合态（避免变量来源不可审计）；不为皮肤引入运行时依赖或第二套组件 DOM。

## 原型（本轮交付）

`docs/design/skin-prototypes.html`：同一套真实生产 DOM（页签卡、组件日历、设置开关、悬浮球动作面板）在四种变量环境下的渲染对照——融合基线、苹果风格（液态玻璃 Light）、暗夜玻璃（Dark Glass）、暖纸墨水（Paper）。截图见同目录 PNG。机制演示重点：**三套皮肤均只换变量 + 少量质感规则，未动任何组件选择器**。
