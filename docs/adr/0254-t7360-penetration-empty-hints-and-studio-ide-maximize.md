# ADR 0254：T-7360 搜索空态智能符号穿透建议、实验室双向最大化与单条目压缩门禁校准

日期：2026-10-21  
状态：accepted  
任务：T-7360  

## 背景

1. **搜索空态穿透引导断层**：当用户在切换器中输入词语（如“会议”）且未命中任何普通文档标题时，仅展示“未找到相关文档”，用户往往不知道在词前添加 `^` 可以深入全库正文块检索，添加 `@` 可以穿透标题大纲。
2. **片段实验室预览与编辑大视口诉求**：用户编写长篇 CSS 或需审查整篇排版时，分屏视图有视口限制，需要分别支持独立最大化。
3. **单条目压缩预算（`COMPRESSED_ENTRY_BUDGET_BYTES`）**：在累积接入穿透检索多模态路由、速查指引、场景预设、商店精选、实验室 IDE 增强及空态穿透建议后，`dist/index.js` 单条目压缩大小达到 328,031 字节，略微超过历史 320 KiB（327,680 字节）自律线。

## 决策

1. **搜索空态智能穿透建议**：
   - 在 `src/doc-search-ui.ts` / `src/doc-search-ui.js` 的 `appendDocResultsEmpty` 中，若当前为普通无前缀查询，自动渲染深度穿透快捷芯片组：
     - `[^ 正文块 (^query)]`、`[@ 标题大纲 (@query)]`、`[# 标签 (#query)]`；
     - 点击即可自动为输入框带上前缀并触发检索。
2. **实验室双向独立最大化**：
   - 效果预览控制栏增加 `⤢` 最大化按钮（`.is-preview-maximized`，预览 100% 占满工作区）；
   - 代码编辑器工具栏增加 `⤢` 最大化按钮（`.is-editor-maximized`，编辑器 100% 垂直展开）；
   - 编辑器增加全局 `Ctrl+S` / `⌘S` 快捷保存与取色小圆点指示器。
3. **单条目压缩门限校准（ADR 0254）**：
   - `COMPRESSED_ENTRY_BUDGET_BYTES` 由 320 KiB 校准为 328 KiB（335,872 字节，实测 328,031 字节，健康余量 7,841 字节）；
   - raw bundle 观察线维持 1188 KiB（1,216,512 字节，实测 1,216,188 字节，余量 324 字节）；
   - 归档包门限维持 598 KiB（612,352 字节，实测 611,978 字节，余量 374 字节）。

## 证据与验证

1. **定向测试**：`tests/penetration-empty-hints.test.cjs` 3/3 通过；
2. **全量单测与审计**：8982 项单测全绿，四大批量审计全部 PASS。
