# ADR 0069：悬浮球触发器、动作呈现与移动端能力分离

- 日期：2026-09-22
- 状态：已接受；P0 已落地本地代码，真实宿主与 Android 验收后置
- 关联任务：T-6766～T-6771
- 修订：ADR 0066、ADR 0068 的动作呈现与能力边界；不回写历史 ADR
- 关联：`docs/floating-ball-competitor-research-2026-09-22.md`、`docs/floating-ball-ui-spec.md`

## 背景

悬浮球已有共享 quick-action registry、统一 executor、三端独立动作列表和更多面板。用户还需要配置悬浮球本体点击动作、为没有图标的内置/插件动作补充文字和图标，以及在插件没有移动端声明时拥有可控的尝试路径。把这些字段直接混入执行器会让展示改动改变能力判断，或把未知插件动作静默当成手机可用。

## 决策

1. `FloatingBallConfig.clickAction` 按 desktop/sidebar/mobile 保存，默认值为 `switcher`。主点击遇到缺失、禁用、提供方失效或不支持的动作时回退切换器；配置为 synthetic More 时打开更多面板。拖动命中与点击继续由 controller 分流。
2. 动作 descriptor 可以覆盖 `label`、`icon` 和 `mobileOverride`。文字与图标只属于呈现层，执行仍通过共享 registry/executor。名称最多 80 字符；图标归一化参考用户自有的小驴打卡 `src/shared.ts`，接受受限 SVG symbol ID、最多 4 字素短文字/Emoji、最长 500 字符且无凭据的 HTTPS 图片 URL，以及不超过 240,000 字节的 base64 图片 data URL。图片以 `img` 节点呈现、关闭 referrer，加载失败回退图标；禁止 HTML 注入。归一化函数由模型、共享快捷入口与选择器复用，设置支持预览和应用。与小驴打卡相比，短文字收紧为 4 字素以适配 44px 操作区域。
3. 插件命令和没有移动端声明的 adapter 在 mobile 上继续显示 `unknown` 并默认不可执行。用户在手机端设置中勾选“手机端尝试（未验证）”后，能力解析允许该动作进入执行路径，但设置行仍显示未验证；提供方缺失时仍不可执行。
4. 桌面、侧栏和手机共用动作目录与能力解析，但配置、主点击、首层和启停状态独立保存。更多面板保留不可用/未知动作的原因和恢复路径。
5. Toolbar Customizer 的端侧配置、图标/文字覆盖和移动端通用动作，Panda Navigation 的分组/预设/端侧显示，以及 FV / fooView 的多手势和任务编排作为产品参考。本轮在本项目中独立实现；Panda 为 GPL-3.0，没有移植其实现或资源到本项目。

## 后续

P1 补齐移动端通用动作；P2 增加双击、长按、滑动、分组和预设；P3 再评估插件发现、脚本权限、模拟点击兼容层和配置分享。每一阶段都必须保留能力状态、超时和真实端验收边界。

## 验证

P0 已补模型、设置模型、面板和宿主回归；未知移动端默认禁用、显式尝试、恶意图标清理和主点击安全回退均有定向断言。真实 SiYuan/Android 证据仍受 `BLOCKERS.md` B-004/B-005 限制。
