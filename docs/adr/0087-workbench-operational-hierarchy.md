# ADR 0087: 工作台操作与状态层级

- 日期：2026-09-27
- 状态：已采纳（T-6945/T-6946）
- 关联：ADR 0079、ADR 0080、ADR 0084

## 决策

1. 工作台移除独立问候行和开发者邀请/协议横幅，内容区只承载组件及必要空态。协议指南继续由项目文档提供，不在日常工作面板常驻。保留顶部编辑、刷新、商店三个入口，工具栏允许换行；编辑开关增加 aria-pressed。
2. 底部汇总复用单元健康数据，区分 ready/loading/error，并在未完成组件存在时追加加载数量。刷新开始即将对应单元标为 loading，结束后按既有结果恢复正常或失败；失败优先于加载。汇总保留 role=status，颜色仅作补充，失败和加载文字始终存在。
3. 只对全屏工作台容器以 100vw/100vh !important 覆盖宿主的打开时 inline 像素尺寸，不影响固定、自适应或移动工作台尺寸。

## 边界与验证

不新增组件、配置或网络请求，不改变刷新并发、失败重试和旧快照保留策略。缓存回退继续按既有控制器语义呈现缓存，不在本任务重定义“正常”。隔离桌面 E2E 通过临时只读适配器和内存布局驱动加载、失败、重试与恢复，不写持久化工作台布局；空快照用于测试无缓存回退的真实失败路径。个人安装及 Android 验收后置。
