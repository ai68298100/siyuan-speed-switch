# ADR 0132：片段目录元数据侧车

- 状态：已采纳
- 日期：2026-10-04
- 任务：T-7092 / T-6993 / AB-1306

复用 sw_snippet_groups 的版本 1 存储通道，新增可选 metadata（独立版本 1）。旧分组数据无需迁移；未知元数据版本丢弃，不影响已有分组。元数据最多 256 条，别名 64、摘要 256、标签最多 8 个且每个 32 字符；不保存正文、原生名称或启用状态。

原生条目通过稳定 ID 关联，加载及确认写入后清理失效 ID。草稿元数据随原生片段保存后落盘，已有片段修改目录字段时独立保存。持久化错误保留原生保存结果但显示警告，不宣称整笔成功。

置顶优先；目录支持原生顺序、名称和本插件最近修改排序。时间戳只表示本插件观察到的修改，不伪装成宿主全量修改时间。分组保留自身结构，组内使用同一筛选顺序；平铺使用全目录顺序。
