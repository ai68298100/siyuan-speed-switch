# ADR 0250：T-7358 全平台 E2E 矩阵验收与动作画板 MRU 排序

日期：2026-10-21  
状态：accepted  
任务：T-7358  

## 背景

在 Wave 4 终验里程碑中，需要系统性串联并验证 T-7349～T-7357 交付的全部特性，覆盖桌面主窗、极限窄侧栏 Dock 与移动端抽屉三大表面。同时，用户在频繁唤起动作画板时，最希望高频执行过的次级动作（如“在思播中打开”、“复制块链接”等）能自动置顶获焦，免去反复滚动查找的成本。

## 决策

1. **同分区 MRU 动作排序（`sortPaletteActionsByMru`）**：
   - 保持 `PANEL_SECTION_ORDER`（`open`, `copy`, `manage`）整体全局分组不变，避免破坏 a11y 语义与已有测试断言；
   - 在每个 section 内部，根据 `recentActionIds` 历史记录逆序（最近使用的优先）进行前置提升；
   - 运行时 `index.ts` 维护 `recentPaletteActions` 历史栈（容量上限 5 项），执行动作即刻入栈。
2. **全平台验收矩阵固化**：
   - 桌面端：卡片网格导航、快捷键免呼出直达、`Ctrl+Shift+T` 撤销恢复、文档集保存；
   - 极限窄侧栏 Dock（245px～340px）：弹性收缩、无横向溢出；
   - 移动端（<= 600px）：底部抽屉形态、`aria-modal="false"` 适配与 44px 触控可达性；
   - 工作台：属性看板（`database-board`）、闪卡复习（`flashcard-review`）与多媒体进度/徽标卡片。

## 证据与验证

1. **定向测试**：`tests/full-platform-e2e-matrix.test.cjs` 5/5 通过（包含跨分区字典序保护负向断言）；
2. **全量回归**：8982 项单测全部通过；四大批量审计全部 PASS；
3. **类型与打包**：`tsc --noEmit` 0 错误，可复现构建 3/3 一致。
