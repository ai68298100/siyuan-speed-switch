## 1. 产品目标与定位

**小驴雷切是思源笔记的统一切换与工作上下文平台。** 一个入口，切换内容；一个工作台，切换现场；一个实验室，切换界面。

| 表面 | 对外称呼 | 用户要完成的事 | 核心结果 |
| --- | --- | --- | --- |
| 第一面板 | 切换器 | 找到并回到内容、动作或工作现场 | 选中后打开、定位或执行 |
| 第二面板 | 工作台 | 查看、刷新和编排信息组件（58 个内置组件 + 组件商店） | 读懂状态、配置布局、恢复现场 |
| 第三面板 | 片段实验室 | 管理、编辑和安全预览 CSS/JS 片段（桌面专属） | 修改草稿、预览、审核后保存 |
| 全局触发器 | 悬浮球 | 在宿主任意位置呼出平台或执行高频动作 | 打开平台、执行动作、恢复来源 |

核心价值排序固定：① 已打开内容的切换速度和可靠性；② 收藏、最近、日记等高频入口；③ 同一搜索页内渐进扩展到全文和全库；④ 工作区恢复等增强；⑤ 低频重型功能暂缓。

**边界**：不替代思源原生搜索、文件树、历史记录或同步服务；在宿主能力之上提供共享的入口、对象、动作和上下文语义。三端（桌面弹窗/侧栏/移动端）共享领域逻辑与核心语义 `搜索 | 收藏 | 最近 | 日记`，日记在任何端不得收进"更多"。

## 2. 设计原则

以下原则按约束力排序；冲突时靠前者优先。

1. **宿主共生**：思源主题变量（`--b3-*`）是唯一颜色来源；插件只做作用域别名（`--sw-platform-*`），不建立第二套视觉系统。复用思源图标、菜单、主题变量和交互语义。
2. **极简而非堆叠**：首屏始终服务于"找到并打开内容"；不放说明性文案、统计图表或营销模块；卡片只用于页签、文档、搜索结果等真实对象；低频动作归入"更多"；新能力默认渐进展示。
3. **键盘优先**：一切高频操作有键盘等价物；快捷键以 `kbd` chip 形式出现在界面里（Raycast/Linear 惯例），不只藏在文档中。
4. **状态可见**：加载、就绪、缓存、过期、未保存、受阻、错误使用统一的六态徽标与回执（ADR 0079）；颜色、图标、文字至少两者同时出现，不单靠颜色传达。
5. **层级克制**：层级靠边框 + 留白，不靠重阴影。常态卡片 = 1px 边框 + 12px 圆角 + 无/极浅阴影；hover 才浮起；只有浮层用中强度阴影。
6. **主动作唯一**：每屏只有一个主色胶囊按钮（保存/添加/应用）；次动作用 soft/text 胶囊。
7. **共享语义，端侧适配**：三端共享命令与状态模型；每个界面保有独立搜索会话；端侧按空间、输入方式和宿主能力选择入口，可减少入口但不得改变命令含义。
8. **稳定性优先**：打开切换器、过滤页签、切换文档、关闭弹窗四条基本路径不得被远程请求阻塞；失败保留已有结果并给轻量错误态；异步结果必须校验请求代际。

## 3. 设计令牌（Design Tokens）

令牌分两层：**编译期常量**（SCSS 变量，动效等固定设计常量）与**运行期变量**（`--sw-platform-*` CSS 自定义属性，随宿主主题/皮肤变化）。实现纪律：颜色/圆角/阴影/间距一律引用运行期变量；动效时长曲线引用编译期常量；禁止硬编码色值（皮肤机制见 §8）。

### 3.1 色彩

颜色**没有自有色板**，全部取自宿主并做语义别名（生产实现：`_platform-shell.scss`）：

| 令牌 | 取值（回退链） | 用途 |
| --- | --- | --- |
| `--sw-platform-accent` | `var(--b3-theme-primary)` | 主色：主动作、激活态、焦点、强调 |
| `--sw-platform-accent-soft` | `color-mix(accent 12%, transparent)` | 激活底色（徽标、导航、chips） |
| `--sw-platform-accent-pressed` | `color-mix(accent 20%, transparent)` | 按下态底色 |
| `--sw-platform-bg` | `var(--b3-theme-background)` | 页面底 |
| `--sw-platform-surface` | `var(--b3-theme-surface)` | 卡片/控件底 |
| `--sw-platform-surface-muted` | `var(--b3-theme-surface-lighter)` | 沉底区（分段控件槽、图标容器） |
| `--sw-platform-surface-raised` | `color-mix(surface 92%, accent-soft)` | 轻微抬升面 |
| `--sw-platform-line` | `var(--b3-border-color)` | 边框/hairline |
| `--sw-platform-text` | `var(--b3-theme-on-background)` | 正文/标题 |
| `--sw-platform-text-muted` | `var(--b3-theme-on-surface-light)` | 元信息、描述 |
| `--sw-platform-text-on-accent` | `var(--b3-theme-on-primary)` | 主色上的文字 |
| `--sw-platform-success` | `var(--b3-theme-success)` | ready 态 |
| `--sw-platform-warning` | `var(--b3-theme-warning)` | stale/警示 |
| `--sw-platform-error` | `var(--b3-theme-error)` | error/危险动作 |

**状态徽标配色公式**（以 ready 为例，其余同构）：文字 = `color-mix(success 72%, text)`，边框 = `color-mix(success 26%, transparent)`，底 = `color-mix(success 9%, transparent)`。loading 用 accent、stale 用 warning、error 用 error；dirty 用警示色系深一档；blocked 用 muted 中性。`color-mix` 保证任意宿主主题/皮肤下自动协调，暗色零额外适配。

### 3.2 字体与文字刻度

字体族沿用宿主 `var(--b3-font-family)`；等宽用 `ui-monospace, Consolas, monospace`（kbd、代码、数值胶囊）。

| 刻度 | 字号/字重 | 用途 |
| --- | --- | --- |
| 屏标题 H1 | 13px / 700 | 面板区标题、卡片主标题（`.rz-h1` → `sw-platform-*`） |
| 卡片标题 | 12.5px / 600 | 组件卡、预览窗格、对话框标题 |
| 正文 | 12~12.5px / 400 | 列表行、表单、摘要 |
| 元信息 meta | 11px / 400，muted | 路径、时间、描述、计数 |
| 分节标签 label | 11px / 700，大写，字距 .07em，muted | 区块分组标题（`.rz-label`） |
| kbd | 10.5px / 600，mono | 快捷键 chip |
| 设置行 | 标题 13px/600 + 描述 12px/400 muted | 设置行三元组 |

行高：单行控件内容 1；正文摘要 1.7；代码 1.8。文字层级通过"字号 × 字重 × 颜色（text / text-muted）"三变量表达，不引入第四种灰色。

### 3.3 间距刻度

五档：`--sw-platform-space-1..5` = **4 / 8 / 12 / 16 / 24px**。使用规则：

- 控件内部留白（chip padding、图标与文字间隙）：4 / 8
- 卡片内边距、卡片间距：10~14（实现取 12 为主，网格 gap 14 属卡片间距的宽档，仅用于 12 列网格）
- 区块间距、表单行距：16
- 外壳边距（面板内容区 padding）：18（桌面全屏外壳横向边距的历史值，新界面优先 16/24）

任何新界面只允许从刻度取值；出现 7px、13px 这类刻度外值视为缺陷（历史值迁移时按最近刻度归并）。

### 3.4 圆角

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--sw-platform-radius-sm` | 8px | 控件：按钮、输入框、小行卡、图标容器 |
| `--sw-platform-radius-md` | 12px | 卡片：页签卡、组件卡、设置组卡、预览窗格 |
| `--sw-platform-radius-lg` | 16px | 面板/外壳、底部 sheet 顶圆角（18px 为 sheet 特许值） |
| `--sw-platform-radius-pill` | 999px | 胶囊：主动作按钮、徽标、值胶囊 |

kbd 特许 5px；分段控件槽 9px、选项 7px（槽 = 选项 + 2 的嵌套关系）。除此之外不得新增圆角值。

### 3.5 层级与阴影

三级层级模型：**line（1px 边框）→ surface（底色差）→ elevated（阴影）**。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--sw-platform-shadow-card` | `0 1px 2px rgb(51 58 83/5%), 0 8px 24px rgb(75 85 120/8%)` | hover 浮起、抬起卡片 |
| `--sw-platform-shadow-floating` | `0 14px 36px rgb(55 65 100/15%), 0 3px 10px rgb(55 65 100/8%)` | 菜单、Action Panel、Dialog、目录浮层 |

规则：常态卡片无阴影或极浅；hover = `translateY(-1px)` + shadow-card；浮层用 shadow-floating；遮罩 = `rgba(15,20,30,.36)` + 2px blur（暗色主题下由皮肤层调深）。

### 3.6 动效

编译期常量（`_00-tokens.scss`），四档两曲线：

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `$sw-dur-fast` | 120ms | 微反馈：hover、focus、颜色与边框 |
| `$sw-dur-base` | 160ms | 标准：阴影、小位移、图标 |
| `$sw-dur-slow` | 200ms | 较大位移与层级变化 |
| `$sw-dur-panel` | 260ms | 面板/抽屉展开收起 |
| `$sw-ease` | `cubic-bezier(0.32, 0.72, 0, 1)` | 默认：快速启动、平滑停止（即时响应） |
| `$sw-ease-sym` | `cubic-bezier(0.65, 0, 0.35, 1)` | 进出对称场景 |

`linear` 仅用于旋转加载动画。`prefers-reduced-motion` 下所有过渡与动画必须关闭或降为即时（现有减动效切片继续有效，新组件同步遵守）。

### 3.7 控件高度与命中区

| 刻度 | 值 | 用途 |
| --- | --- | --- |
| 搜索框 | 38px（移动端 40px） | 切换器主输入，首焦点 |
| 标准控件 | 28px | 输入、下拉、工具栏按钮 |
| 分段控件项 | 26px（槽内 padding 6/12） | 枚举设置 |
| kbd | 18px 高，min-width 18px | 快捷键 chip |
| 行图标容器 | 26~28px，圆角 8 | 结果行/设置行行首图标 |
| 悬浮球动作卡 | 52px，圆角 14 | 首层动作 |
| 触控命中区 | ≥ 44px | 移动端一切可点元素；视觉尺寸可与命中区分离 |

### 3.8 六态语义

对象与区域的状态只许从六态取值（ADR 0079），文案与可用动作统一：

| 状态 | 表达 | 默认可用动作 |
| --- | --- | --- |
| ready | 已就绪/已更新，success 色点 | 打开、编辑、查看 |
| loading | 加载中 + 骨架，accent 色点 | 取消（若有请求） |
| stale | 缓存于 ×× + 过期提示，warning 色点 | 刷新、查看缓存 |
| dirty | 未保存更改，警示深色点 | 保存、另存为、放弃 |
| blocked | 受能力/端侧/安全限制，muted | 查看原因、换入口 |
| error | 失败原因（人类可读），error 色点 | 重试、回退、复制诊断 |

复合维度（如片段的"已保存 · 已启用 · 发布时禁用"）并行展示为组合信息，不压成单一状态值，不画成自动推进的流水线。

### 3.9 焦点环

统一 `:focus-visible` = 2px accent outline + 2px offset + `--sw-platform-focus`（3px accent 24% 光晕）。任何自定义控件不得移除焦点环；触控命中区与焦点可见性各自独立达标。

## 4. 信息架构

### 4.1 平台地图

```text
小驴雷切（PlatformShell）
├── 表面导航 SurfaceNav
│   ├── 切换器 switcher      —— 去哪儿：搜索/页签/收藏/最近/日记/命令
│   ├── 工作台 workbench     —— 看什么：组件网格/编辑布局/组件商店
│   └── 片段实验室 studio    —— 改什么：片段目录/编辑器/预览/AI（桌面专属）
├── 悬浮球（平台入口，非第四表面）—— 从哪里进入 + 高频动作执行器
└── 设置（10 标签，独立 Dialog，各表面工具栏可达）
```

悬浮球不是第四个表面：它是全局触发器与动作执行器。系统级回退入口"打开小驴雷切"不可被用户配置删除；自定义动作失效时自动回退到平台。

### 4.2 平台外壳解剖

桌面三表面共用外壳，公共区只有三层 + 可选回执条：

```text
┌──────────────────────────────────────────────────────────────┐
│ 小驴雷切  [切换器][工作台][片段实验室]     ⋯ 状态徽标  关闭 │ Platform header（52px；侧栏 40px）
├──────────────────────────────────────────────────────────────┤
│ 工作上下文 › 当前表面  表面一句话说明        kbd 提示组       │ Context bar（侧栏隐藏）
├──────────────────────────────────────────────────────────────┤
│                      Surface body                            │ 各表面自有
├──────────────────────────────────────────────────────────────┤
│ 状态回执 / 计数 / 快捷键                            主胶囊    │ Footer receipt（可选）
└──────────────────────────────────────────────────────────────┘
```

纪律：表面专属工具不进平台头部；上下文栏表达"我在哪里"（表面/现场/对象/返回来源）；当前表面用文字 + 图标 + `aria-current="page"` 同时表达。

### 4.3 导航与路由语义

| 触发 | 结果 |
| --- | --- |
| 悬浮球轻触 | 打开平台并恢复上次表面；无可恢复状态时进入切换器 |
| 表面导航点击/Tab/方向键 | 同外壳内切换表面，保留 `returnTo`，不销毁未保存草稿与布局编辑态 |
| Escape | 先关 Action Panel/选择器 → 再退路由 → 有脏稿走统一确认 → 关闭平台 |
| 关闭平台 | 恢复触发来源焦点；无法恢复时回到宿主当前编辑器 |

快捷键：切换器 `Alt+Shift+S`、工作台 `Alt+Shift+P`（均可改）；`Alt+1/2/3` 表面直达为候选项，须核对宿主冲突后才定稿。

### 4.4 端侧形态矩阵

| 维度 | 桌面弹窗（默认全屏，ADR 0080） | 桌面侧栏 | 移动端 |
| --- | --- | --- | --- |
| 容器 | 思源 Dialog，`panelSizeMode` 全屏/自适应/固定 | 右侧 Dock，紧凑 | 全屏/底部表面容器 |
| 平台头 | 完整（品牌+导航+动作） | 40px，隐藏品牌与上下文栏 | 44px，横向可滚表面标签 |
| 核心入口 | 搜索/收藏/最近/日记/排序/全屏/侧栏/设置 | 搜索/收藏/最近/日记/排序 | 搜索/收藏/最近/日记；排序设置入"更多" |
| 全屏切换 | 有 | 不显示 | 不显示 |
| 预览窗格 | 34% 宽，280～480px，sticky | 按宽度降级/隐藏 | 无（直接打开） |
| 悬浮球 | 挂载 | 不挂载（ADR 0072） | 挂载，三层防误触 |
| 片段实验室 | 完整 | 入口可隐藏 | 仅能力状态展示，不提供编辑（ADR 0078） |

### 4.5 设置页信息架构

设置 = 左侧标签 rail（激活态 = 主色 12% 底胶囊）+ 右侧分组卡片内容区；移动端为顶部横滚标签。10 个标签按"看什么 → 怎么动 → 各端与各模块 → 数据"排序：

| 组 | 标签 | 内容域 |
| --- | --- | --- |
| 呈现 | 外观 | 皮肤/密度/列数/侧栏布局/组件强调色/缩略图高度 |
| 呈现 | 面板 | 切换器与工作台尺寸模式、固定尺寸、快捷键绑定展示 |
| 行为 | 行为 | 打开策略、搜索行为、悬浮球联动开关 |
| 内容 | 收藏 | 分组管理、智能分组（参数化条件，不开放任意 SQL） |
| 内容 | 日记 | 默认日记本、自动创建 |
| 动作 | 快捷入口 | 动作目录（内建/思源命令/第三方三级分组）、端侧显示、导入导出 |
| 动作 | 悬浮球 | 预览舞台、外观、动作绑定（单击/双击/长按）、场景预设 |
| 现场 | 文档集 | 集合管理、版本时间轴、恢复/导出 |
| 端侧 | 手机端 | 列数、缩略图、旧 fab 开关（标注"被悬浮球取代"） |
| 数据 | 存储 | 用量分节条、schema 版本戳、配置包导出/导入 |

设置搜索（Linear 式）为已评估候选项，未承诺；新增标签页前先考虑能否并入现有标签的分组卡片。

## 5. 核心界面规范

### 5.1 切换器（桌面，默认全屏）

布局自上而下：平台头 → 搜索区 → 主区（左内容弹性列 + 右预览 `clamp(280px, 34%, 480px)`，间隔 14px）。视觉重心保持已开页签；容器不足 680px 时恢复单列。

- **搜索区**：38px 搜索框（圆角 10、首焦点、左侧搜索图标、行尾筛选按钮）；右侧快捷入口（最近打开、笔记本 · 最近使用软胶囊 + 日记/实验室/设置图标按钮 28px）。查询时结果区顶部出现过滤 chips：`全部 / 页签 / 收藏·最近 / 文档`（纯展示层过滤，`role=tablist`，空查询自动移除）。
- **已开页签**：4 列大卡网格（gap 10），卡片 = 96px 缩略图 + 行图标 + 12.5px/600 标题，右上角数字角标 kbd 化（1-9 直达，不遮内容）；置顶/MRU/分组语义保持。
- **收藏 · 最近**：双列紧凑行卡（26px 图标容器 + 12px 标题 + muted 来源路径 + 行尾数字 kbd）。
- **全库结果**：紧凑行（图标 + 标题含高亮 mark + muted 片段摘要 + kbd），首屏限量 + "查看全部 →" 出口到思源原生搜索页。
- **预览窗格**：280～480px sticky 阅读工具窗格，四边中性 1px 细框、8px 圆角，键盘焦点强调；标题行（预览 + 状态徽标）固定，正文独立滚动，正文固定 13px。高度不超过 60vh、560px 或容器可用高度减 48px。内容为文档标题 + 按原文顺序呈现的正文摘录（标题、段落、列表、引用、代码块，纯文本安全投影）+ 大纲列表；非文档对象给 blocked 回执，请求失败给 error，旧请求不回写。正文最多读取前 12 个可读块、展示 900 字，超出部分从原文打开。
- **搜索三层**（显示优先级 = 执行优先级）：已开页签本地即时过滤 → 已打开文档全文命中（按根文档聚合，每文档 ≤2 片段）→ 全库卡片（每页 ≤12 卡，每文档 ≤2 片段）；已打开文档在后两层去重。`>` 前缀进入命令模式，命令结果分组折叠、与内容结果共享搜索会话。
- **空查询**：优先最近、置顶和当前现场；不请求全库；各分区无结果时不占大块空间。

**侧栏变体**：单列紧凑卡；隐藏品牌/上下文栏；无全屏；预览按宽度降级。**移动端变体**：搜索 40px；行 2 为收藏/历史/设置 chips；单列大卡（110px 缩略图）；底部快捷条 4 入口（图标 + 10px 标签，实底通栏 + safe-area）；长按卡片出动作菜单。

### 5.2 工作台（桌面，默认全屏）

- **头部行**：`查看 / 编辑布局` 分段控件 + 缓存徽标（stale："缓存 · 3 分钟前"）+ 右侧"刷新全部"软胶囊。
- **查看态**：12 列网格（gap 14），组件以完整内容渲染（日历整月/表格多行/天气详情），卡片解剖 = 卡头（名称 + 状态徽标 + 更多点）+ 内容区；组件商店压缩为回执条内入口（"组件商店 · 58 组件 →"）。
- **编辑态**：编辑横幅（主色 9% 底 + 边框：拖动提示 + 恢复默认 + 完成）+ 拖动落点指示 + 尺寸模式分段；移动端用上移/下移按钮替代拖动。
- **底部回执条**：健康汇总（"11/11 组件正常"ready 徽标 + 失败/跳过计数 + 上次刷新时间）。
- 失败回执留在产生它的组件卡内，不用全局 toast 取代上下文；加载用骨架屏。

### 5.3 组件商店

头部 = 总数徽标 + 搜索 + 视图/密度分段；来源 chips 带计数（可用/已添加/需安装/不可用）。卡片 = 38px 渐变图标块 + 名称 + 来源行 + 描述 + 状态徽标行 + 动作（添加 = 主色胶囊，已添加 = soft，配置 = quiet）；不可用卡降透明 + 原因徽标。多选、依赖摘要、实时预览为既有能力，沿用同一卡片语言。

### 5.4 片段实验室（桌面专属，全屏）

布局（R2 定案）：**预览为主区（4fr）+ 下排 属性:编辑器（2fr:3fr）+ AI 右栏（1fr）+ 片段目录为浮层选择器**。

- **工具行**：片段目录软胶囊（开浮层）+ 名称行内编辑输入（200px）+ dirty 徽标 + 比较 + 保存主胶囊。
- **预览区**：卡头（预览 + 类型 chip + 预览状态徽标 + 比较原稿/暗色预览）+ 隔离沙箱画布 + 底部回执（"CSS 隔离沙箱 · 不写入生产文档 · 与原生片段一致"）。
- **属性卡**：名称/类型分段（CSS|JS）/启用/发布时禁用 + 组合状态行（"已保存 · 已启用 · 发布时禁用 · 16 行"）。
- **编辑器**：等宽 12px/1.8，行号 muted，改动行主色 8% 底高亮。
- **AI 右栏**：模式分段（优化/解释/迭代）+ 指令输入 + 生成主胶囊 + 结果区；AI 产出默认"待审核草稿"（blocked 徽标），逐 hunk 接受，接受前不写入；explain 为受限纯文本。
- **目录浮层**：居中浮层 = 搜索（`Esc` kbd）+ 类型计数徽标行 + 行卡（名/类型/行数/启用色点）+ 底部"新建片段"主胶囊；选中行 = 主色 8% 底 + 34% 边框。
- **能力边界常显**：CSS 沙箱预览、JS 禁执行、AI 仅草稿、AI 上下文范围、存储单副本五条说明始终可见（属性区 details），不隐藏。

### 5.5 悬浮球

解剖：球体（主色、双层阴影、按压缩放）+ 首层动作卡（52px、圆角 14、图标 + 短标签）+ 更多面板（搜索框 `/` kbd + 分组：表面/思源命令/第三方 + 行尾 kbd/状态徽标）。

- 状态机视觉：docked（常态，可闲置降透明）/ dragging（跟随 + 吸附提示）/ targeting（动作环展开，豁免隐藏）/ executing / more（面板）/ suspended / hidden；半隐贴边与自由停放（xRatio 持久化）均已有。
- 手势：轻触 = 恢复上次表面；单击/双击/长按可分别绑定动作（设置页三区卡片配置）；上下左右快滑（默认 up=更多、down=快速捕获、left/right=前后页签）；拖动选取动作；右键/`Shift+F10` 开更多面板；1-9 数字槽直达。
- 移动端遵守 touch slop、safe-area、滚动隐藏、三层防误触；浏览器模拟不算真机证据（B-004/B-005）。

### 5.6 设置页

通用语言（全部 10 个标签适用）：

1. **行分组卡片化**：组卡 = 12px 圆角 + 边框 + surface 底 + 组内 hairline 分隔 + hover 提亮；组标题 11px 大写字距 muted。
2. **设置行三元组**：标题（13px/600）+ 描述（12px muted，说明行为/副作用/默认值）+ 右侧控件。
3. **枚举分段化**：2~4 个互斥取值一律分段控件（皮肤/密度/列数/尺寸模式/显示方式/视图模式/单位/间隔）；范围数值用 slider + 主色值胶囊。
4. **每标签唯一主色胶囊**：保存/添加/应用类主动作每区至多一个。

逐标签要点沿用 R2 设计（05~15 屏）：外观全分段化 + 缩略图 slider；行为三分组 + 每开关补描述；面板双尺寸模式 + 快捷键行尾 kbd；收藏行卡 + 智能分组条件摘要 + 命中计数；快捷入口三级分组目录 + 版本化说明；悬浮球保留 T-6782 卡片语言 + 场景预设"当前"徽标；文档集版本时间轴内嵌；日记默认值 + 自动创建；移动端列数分段 + 旧 fab 替代标注；存储用量分节条 + schema 版本戳 + 配置包行。

### 5.7 对话框与浮层

| 浮层 | 规范要点 |
| --- | --- |
| 快速捕获 | 目标段选（日记/当前文档）+ textarea 圆角 10 + 目的地预览行 + 底部 kbd 提示（Enter 保存/Esc 取消）+ 主色保存胶囊 |
| 历史下拉 | 打开/关闭分段（带计数）+ 过滤胶囊 + 行（图标容器 + 名 + 路径时间 muted + 徽标）+ 底部右键提示回执 |
| 筛选菜单 | 条件 chips（激活 = 主色 9% 底 + 勾选）+ 类型/方式分段 + 保存的搜索列表 + "保存当前搜索"主胶囊 |
| 排序菜单 | 两段单选（分组方式/组内排序）+ 当前项主色勾选 + hairline 分组 |
| 组件配置 | 头部（组件名 + 连接徽标 + 关闭）+ 表单行（88px 标签 + 控件）+ 来源与联网说明 + 底部变化回执（dirty 徽标"2 项修改"）+ 应用主胶囊 |
| 目录/动作浮层 | 居中浮层，遮罩 + blur；搜索框首位；行尾 kbd；Esc 逐层关闭 |

通用纪律：每屏一个主胶囊；破坏性动作必须显示副作用与恢复路径；底部 kbd 提示与回执条是标配不是装饰。

## 6. 组件规范

> 命名：平台原语用 `sw-platform-*`（生产，RZ-1 已交付）；设置与各表面用既有 `sw-settings__*` / `sw-home__*` / `sw-studio__*` BEM；提案层的 `rz-*` 类只存在于原型，实现时映射进生产命名，不进生产包。

### 6.1 按钮族（`sw-platform-action`）

| 变体 | 视觉 | 用途 |
| --- | --- | --- |
| `--primary` | 主色实底胶囊，text-on-accent | 每屏唯一主动作（保存/添加/应用/生成） |
| `--soft` | accent 12% 底 + accent 文字胶囊 | 次动作（刷新全部/比较/片段目录） |
| `--quiet` | 透明底，hover 出 muted 底 | 第三级动作、行内动作 |
| `--pill` | 边框胶囊，surface 底 | 可切换的过滤/出口入口 |
| `--danger` | error 色系 | 破坏性动作（须配副作用说明） |
| 图标按钮 | 28px 方，圆角 8，边框 + surface 底 | 工具栏图标入口 |

规格：胶囊高 26~28px，padding 6/14，字号 12px/600，gap 5px 图标；hover 120ms 颜色/位移；disabled 降透明 50% + 禁点；loading 左侧旋转指示（linear 匀速）。

### 6.2 状态徽标（`sw-platform-status`）

色点（6px 圆点）+ 11px/600 文字 + 边框 + 9~10% 同色系底，圆角 999。六态见 §3.8；颜色公式见 §3.1。计数徽标为无语义变体（muted 边框 + surface 底）。规则：徽标文字用状态词（"已就绪/缓存 · 3 分钟前/未保存更改"），不用图标单独表意。

### 6.3 分段控件（`sw-platform-seg`）

槽 = muted 底 + 边框 + 圆角 9 + padding 3；选项 = 圆角 7 + 12px/500，激活 = surface 底 + 600 + 微阴影。2~4 选项为最佳区间；超过 4 个或取值开放时用下拉。选项文案是名词或短词，不用句子。键盘：方向键在选项间移动（`role=tablist`/radiogroup 语义）。

### 6.4 kbd（`sw-platform-kbd`）

18px 高、圆角 5、边框 + surface 底 + muted 文字、10.5px/600 mono。用于：界面内快捷键提示组、结果行数字角标、对话框底部操作提示。多键组合用多个 kbd 并排，不用 "+" 拼接字符串。

### 6.5 输入族

| 控件 | 规格 |
| --- | --- |
| 搜索框 | 38px 高（移动 40）、圆角 10、边框 + surface 底、左图标 14px、行尾可挂筛选按钮；打开即聚焦 |
| 文本输入 | 28px 高、圆角 8、边框、12.5px；行内编辑标题可 600 |
| textarea | 圆角 8~10、padding 7/9、12px、resize:none（受控高度） |
| slider | 主题化 accent 轨道 + 右侧主色值胶囊（数值 + 单位） |
| checkbox/radio | 主题化 accent；标签 12px；与描述分行 |
| 下拉 select | 仅用于 >4 取值或开放取值；28px 高与输入对齐 |

所有可聚焦控件统一 §3.9 焦点环。

### 6.6 卡片族

| 卡片 | 解剖 | 状态 |
| --- | --- | --- |
| 页签大卡 | 96px 缩略图 + 图标 + 12.5/600 标题 + 数字角标 | hover 浮起；选中 = 主色 34% 边框 + 8% 底 |
| 行卡（收藏/最近/全库） | 26px 图标容器 + 标题 + muted 路径/摘要 + 行尾 kbd/徽标 | hover 提亮；行尾动作 quiet |
| 组件卡 | 卡头（名 + 状态徽标 + 更多点）+ 内容区 | 编辑态可拖动 + 落点指示；失败内联重试 |
| 商店卡 | 38px 渐变图标块 + 名 + 来源 + 描述 + 徽标行 + 动作 | 不可用降透明 + 原因徽标 |
| 设置组卡 | 组标题 + hairline 分隔的设置行 | hover 行提亮 |
| 预览窗格 | sticky 34%（280～480px）；轻外框、固定标题行 + 独立滚动的有界结构化摘录 + 大纲 | ready/loading/error 徽标；窄容器单列降级 |

卡片通用态：default（1px 边框，无阴影）→ hover（translateY(-1px) + shadow-card，160ms）→ selected（accent 边框 + accent-soft 底）→ disabled（50% 透明）。卡片只承载真实对象。

### 6.7 弹层族

- **Dialog**：radius-lg 圆角 + shadow-floating + 遮罩（rgba(15,20,30,.36) + 2px blur）；头部 = 标题 + 状态徽标 + 关闭；底部 = 回执 + 主胶囊；Esc 关闭（有脏稿先确认）。
- **菜单/Action Panel**：radius-md + shadow-floating；项 = 图标 + 文案 + 行尾 kbd/勾选；hairline 分组；方向键导航、Enter 执行、Esc 关闭。
- **底部 sheet（移动端）**：18px 顶圆角 + 抓手 + safe-area；内容上滑进入（260ms）。
- **toast vs 回执**：瞬时正向反馈可用 toast；与对象相关的失败/状态一律留在产生它的卡片/行/回执条（FooterReceipt），不用全局 toast 取代上下文。

### 6.8 预览框（`sw-platform-preview`）

`__bar`（标题 + 类型 chip + 状态徽标 + 动作）+ `__canvas`（内容/沙箱）+ `__empty/__loading` 态。三表面复用同一结构：切换器文档预览、工作台组件预览、片段沙箱预览。预览请求必须有取消、代际校验与失败回执。

### 6.9 空 / 加载 / 错误态

- 空态：图标 + 一句话说明 + 一个主动作（可选）；不写营销文案；无搜索词时不展示全库空态。
- 加载：骨架屏（muted 底呼吸块），不用全屏 spinner；局部请求局部骨架。
- 错误：error 徽标 + 人类可读原因 + 重试/回退；保留已有的旧结果（stale 展示），错误不清空内容。

### 6.10 回执条（FooterReceipt）

面板底部通栏：左侧状态徽标 + 计数/时间元信息，右侧出口链接或主胶囊。工作台（健康汇总）、实验室（保存/启用组合态）、商店（安装结果）统一形态；字号 11.5~12px muted，上边框 hairline。

### 6.11 导航族

- **SurfaceNav**：平台头部表面切换；激活 = 文字 + 图标 + `aria-current`；点击/Tab/方向键。
- **设置 rail**：纵向标签，激活 = 主色 12% 底胶囊；方向键循环切换并聚焦；移动端横滚。
- **过滤 chips**：`role=tablist` + `aria-selected`；激活 = 主色 9% 底 + 勾选。

## 7. 关键交互流程

### 7.1 键盘地图（切换器为主）

| 按键 | 行为 |
| --- | --- |
| 方向键 / Tab | 网格与列表间移动焦点 |
| Enter | 打开选中对象 |
| 1–9 | 数字槽直达（页签卡/悬浮球动作） |
| Alt + 点击/Enter | 预览打开（与分屏互斥） |
| Ctrl + 点击/Enter | 右侧分屏打开 |
| Shift + F10 | 卡片动作菜单 |
| `>` | 命令模式（分组折叠） |
| Esc | 关浮层 → 退路由 → 关面板（分层） |
| Alt+Shift+S / Alt+Shift+P | 打开切换器 / 工作台 |

### 7.2 搜索三层时序

输入 → 已开页签立即本地过滤（不跨帧）→ 180ms 防抖后并发已打开文档全文与全库标题请求 → 各层就绪即渲染（后者不阻塞前者）→ 新输入作废旧请求（代际校验）。查询为空/界面销毁/插件卸载时取消计时器与请求并释放监听。

### 7.3 悬浮球手势流

轻触（恢复上次表面）→ 平台；单击/双击（≤300ms 窗）/长按（550ms）→ 各自绑定动作；快滑（方向分类）→ 槽位动作；拖动 → targeting 态 → 松手命中执行 / 空白落位保存；外拨（速度窗口判定）→ sticky targeting 面板保持展开。误触防线：touch slop、safe-area、滚动隐藏、三层防误触（移动端）。

### 7.4 异步与脏稿语义

一切异步：取消 + 代际校验 + 销毁清理；失败回执原地展示。脏稿守卫：实验室关闭/路由切换先经 DirtyGuard 确认；工作台布局编辑态切换表面不丢失；AI 产出接受前不写入，接受后仍标记未保存。

### 7.5 导入导出

配置包（设置白名单 + 文档集）版本化、原子应用、导入需确认；文档集 JSON ≤512KiB 合并需确认；悬浮球设置独立序列化（字节预算校验）。

## 8. 主题、皮肤与暗色

- **暗色**：不维护暗色专用样式表；全部色彩经 `--b3-*` + `color-mix` 自动派生（R2 明暗对照屏 25/26 已验证提案层零改动成立）。
- **皮肤机制**（ADR 0073）：插件根容器作用域重定义 `--b3-*` 别名 + `data-appearance`/`data-palette` 多色板；皮肤只换变量与质感层，不改组件选择器。已验证皮肤：融合基线/苹果液态玻璃/暗夜玻璃/暖纸墨水（原型 `docs/design/skin-prototypes.html`）。
- **纪律**：任何新颜色必须走语义变量；直接写死 `#xxxxxx`（特许的徽标基底色除外，且须 `color-mix` 派生）视为违规。对比度由门禁采样（`tests/skin-contrast.test.cjs`），明暗与皮肤下不回退。

## 9. 可访问性

- 触控命中区 ≥44px（移动端一切可点元素）；桌面密集控件不影响焦点环。
- 焦点环统一（§3.9），键盘可达性与 §7.1 键盘地图一致；aria：`role=tablist/tab`、`aria-selected`、`aria-current="page"`、aria-hidden 装饰元素。
- 状态不单靠颜色（色点 + 文字）；reduced-motion 全量降级（§3.6）。
- 高对比与对比度采样门禁继续有效；新组件须过明暗两主题采样。

## 10. 性能预算（视觉相关）

沿用 ROADMAP §3.5：页签本地过滤单次不跨帧（50ms 告警线）；搜索防抖 180~250ms，每界面同时最多 1 个进行中请求；首屏只渲染有限结果（全库 ≤12 卡），缩略图可视区懒加载；搜索缓存仅内存且有上限；局部加载用骨架，不用全屏遮罩。视觉实现侧：动画只动 transform/opacity；阴影与 blur 限于浮层；避免大面积 backdrop-filter 常驻。

## 11. 扩展性指南

### 11.1 新增一个设置项

1. 归入现有标签的某个组卡（先看能否并入，再考虑新组）；写三元组（标题 + 描述 + 控件）。
2. 2~4 互斥取值用分段控件；连续数值用 slider + 值胶囊；>4 取值用下拉。
3. i18n 双语成对加 key（死 key 门禁）；进入存储 key 白名单与导入导出清单（存储 key 恒 13，改动须按存储兼容矩阵迁移）。
4. 契约测试 + 负向验证（按 `docs/gate-audit-checklist.md`）。

### 11.2 新增一个工作台组件 / 视图类型

照"视图类型接入清单"：`home-model.js` 目录定义 viewType → `home-model.js` 与 `home-view.js` 两处白名单同步 → 渲染分支 → 必要时调 `normalizeHomeViewResult`（条目上限/字段透传/空条目）→ 样式切片加类（遵守 §3 令牌）→ 契约测试 + 负向验证。卡片解剖必须符合 §6.6 组件卡规范（卡头 + 状态徽标 + 更多点）。

### 11.3 新增一个动作

注册进 quick-action registry（内建/思源命令 `global`/第三方 provider 三类），声明端侧与能力（能力检测缺失 → unsupported 降级，不抬 minAppVersion）；在设置"快捷入口"与悬浮球目录自动出现；动作行/徽标/kbd 用平台原语。

### 11.4 新增一个表面或大型面板

先读 §4.2 外壳纪律：接入 PlatformShell（平台头/上下文栏/回执条），表面 ID 进 `platform-surface-model.js`；token 只用 `--sw-platform-*`；六态、kbd、分段、胶囊用既有原语；门禁：契约 + 负向验证 + 明暗对比度采样 + 移动/侧栏降级说明。

### 11.5 命名与文件纪律

- 样式：顺序切片（CSS 顺序即层叠顺序，只能顺序切片）；新主题域开新切片并登记入口 `@use` 清单；源码扫描走 `readStyleSource()`。
- 类名：平台原语 `sw-platform-*`；表面内 `sw-{surface}__{block}--{mod}`；提案层 `rz-*` 不进生产。
- 包体自律：UI 增量按批复核预算（当前 zip 512 KiB 线内余 ~16 KiB）；超线先复核再动。
