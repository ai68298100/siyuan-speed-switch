## 用途

## 记录边界（沿用 `docs/desktop-acceptance-template.md`）

- 只记结论与环境，**不记**令牌、文档标题、文档正文、可识别的个人信息。
- 浏览器模拟不算设备证据；须标注证据来源（真机 / 真实宿主会话 / 模拟）。
- 未通过项保持 queued，不在此处标记完成。

```
- 环境：SiYuan 版本 / 插件版本 / 操作系统与缩放 / 主题

- 遗留问题：
```
