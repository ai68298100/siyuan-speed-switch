# 小驴雷切产品方向与开发规划

- 日期：2026-10-16
- 规划任务：T-7290
- 依据：[产品评审](product-review-2026-10-06.md)、[当期计划](dev-plan-2026-10-06.md)、[第二面板视觉差距复核](research-second-panel-visual-gap-2026-10-16.md)、[ADR 0215](adr/0215-product-positioning-and-roadmap-2026-10-16.md)

## 一、定位收敛

小驴雷切的主定位是 **思源的工作上下文入口层**。它把“找到、预览、打开、执行、恢复当前现场”串成一条本地优先、可解释、可回退的工作路径。

四个表面各自承担清晰职责：

| 表面 | 产品职责 | 主要承诺 |
| --- | --- | --- |
| 第一面板 | 切换器 | 快速找到、预览和打开内容 |
| 第二面板 | 轻量工作台 | 扫一眼当前信息，恢复工作现场 |
| 第三面板 | 片段实验室 | 在安全边界内修改和审查原生片段 |
| 悬浮球 | 全局触发器 | 在已支持的主窗口与手机表面唤回平台或动作 |

统一的是对象、动作、状态和回执语义；不同表面保留适合搜索、查看、编辑和触控的工作方式。

产品不以组件数量、AI 范围或大屏信息密度作为进度指标，也不替代思源原生搜索、文件树、历史和同步服务。

## 二、第二面板的产品合同

第二面板采用查看态与编辑态分离：

- **查看态**是 compact glance board：新装或显式恢复默认时提供七项通用摘要，卡片体量小，默认尺寸按内容类型给出且可由用户布局覆盖，首屏优先让用户快速扫读。
- **编辑态**承载布局、配置、商店、刷新和健康详情；这些能力按需出现，不长期挤占查看态空间。
- 默认七项是默认组合，不承诺七项全部同时首屏可见；v0.47.2 已存双卡、自定义、删除或禁用布局不会自动扩成七项；保留滚动、保存布局、删除、禁用和显式恢复默认。
- 继续吸收 Obsidian 参考中的紧凑间距、异形尺寸、轻材质和低饱和强调色，不复制未知插件的自由画布、归档、小地图或数据格式。

compact 视觉小批只允许改显露层级、尺寸档位、状态标记和已有组件排版，不新增数据源、任意查询语法或组件目录。

## 三、三阶段路线

### 阶段 A：可信核心路径

优先完成 T-7163 FAQ 与脱敏反馈材料，复用已准备好的 T-7168 五条无诱导走查脚本，执行切换、收藏后再找、失败搜索回退、文档集恢复、片段取消/安全保存并收集反馈。真实桌面、Android、读屏、升级回退和外部账号证据分别记录，缺少环境时保持 partial 或 blocked，不用浏览器夹具替代。

同时执行 T-7291 compact visual parity：恢复小/宽/窄高组件的可见层次，收窄 compact 壳层，异常时才展开健康信息，保留现有协议和布局迁移。

### 阶段 B：工作台价值密度与生态

只有拿到真实频率或问题记录后，才从 58 项中选择 5～8 个高频组件进入 T-7144 二轮精修。每项都检查默认内容、配置前置、空态、陈旧、失败、重试、点击和三端密度。

第三方生态先完成至少一个 provider 的注册、配置、失效、卸载、恢复和跨表面证据，再扩展商店分组或目录协议。组件必须显示来源、网络、凭据、缓存和不可用原因。

### 阶段 C：受控智能与可信交付

对新增或扩展的 Agent 能力，优先保持只读上下文、搜索、组件快照和诊断；现有打开文档、批量打开、文档集恢复和受控写入动作，只有在真实确认、权限、取消和失败回执证据齐备时才继续扩展或放量。片段 AI 继续采用草稿、人工接受、CSS 沙箱和 JS 禁止执行。

只有真实 provider、权限、费用、配额、取消和数据外发边界都有证据后，才评估片段之外的 AI；不引入聊天面板、整库隐式上下文、AI 排序或自动写入。

## 四、明确后置项

自由画布、无限画布、小地图、复杂常驻筛选、AI 推荐、行为遥测、云同步、任意 SQL/JS、系统级跨应用悬浮窗、CodeMirror 大依赖和继续扩张组件目录均不进入近期主线。它们只有在核心路径稳定、用户任务成立且数据/权限边界清晰后，才可单独立项。

## 五、验收标准

后续以用户能否完成任务为主，记录步骤、耗时、误点和恢复；不把测试数量或组件数量当产品 KPI。阶段退出至少需要：

1. 五条主路径可独立完成，失败和取消有可操作回退；
2. compact 查看态在桌面、侧栏、窄屏和浅深主题下保持清晰层次；
3. 组件前置条件、来源和数据流对用户可见；
4. 支持材料能说明安装、升级、回退、数据位置和反馈字段；
5. 每项平台兼容或外部服务声明都有对应版本和环境证据。
