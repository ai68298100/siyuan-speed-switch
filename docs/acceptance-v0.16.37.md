## 1. 组件面板新功能（重点）

### 1.1 刷新全部按钮

- [ ] 面板顶栏出现带刷新图标的"刷新全部"按钮（编辑布局按钮旁）。
- [ ] 空面板（删掉全部组件后）按钮自动隐藏。
- [ ] 强制刷新生效：比如在"今日待办"组件里勾掉一个任务后，改动别的文档再回来，点"刷新全部"，数据立即重读（不用等 3 秒缓存过期）。
- [ ] 某组件失败退避期间点"刷新全部"会立即重试（绕过失败退避）。

### 1.2 闪卡待复习组件

前置：至少一个笔记本里有到期的闪卡（或先随便做几张卡让它到期）。

- [ ] 商店"内置"分类里能找到"闪卡待复习"，添加后面板出现时钟图标组件。
- [ ] 默认（全部笔记本）模式：显示待复习总数，下面是各笔记本到期数比例条（无到期的笔记本不显示）。
- [ ] 配置（组件上的配置按钮）→"限定笔记本"选某一个 → 组件变为该笔记本的到期卡片列表，点击条目直达卡片所在文档。
- [ ] 笔记本没有任何到期卡时，列表为空、显示空状态而非报错。

### 1.3 随机回顾组件

- [ ] 添加后面板显示 3 篇文档（默认抽取 90 天未更新的）。
- [ ] 点"刷新全部"→ 换一批新的 3 篇（这是它唯一主动重抽的时机；切换页签不会变）。
- [ ] 配置"多久未看（天）"改成 7 → 出现更近期的文档。
- [ ] 点击条目直达文档。

### 1.4 尺寸菜单预览瓦片

- [ ] 编辑布局 → 任意组件的"尺寸"按钮 → 菜单里每档型号左侧有一个按比例绘制的小矩形（迷你最小、全幅最大），当前档带对勾。

## 2. 智能体能力（需思源支持 Agent，桌面优先）

### 2.1 批量打开文档（open-documents）

- [ ] 让 AI 一次打开 2~5 篇文档（如"帮我把 A、B、C 三篇打开"）。
- [ ] 执行前弹窗逐条列出文档标题；点"拒绝"或等 30 秒超时 → 一篇都不打开。
- [ ] 点"允许" → 文档依次打开；其中某篇不存在时不影响其余篇目。

### 2.2 工作区上下文（workspace-context）

- [ ] 让 AI"看看我现在的工作区状态"→ 返回：设备端、当前活动文档、打开页签、文档集清单、快捷入口、今日日记是否存在。
- [ ] 该能力只读：调用后不会创建今日日记（日记未建时只返回"未找到"，不会静默建档）。

## 3. 回归抽查（旧功能不坏）

- [ ] 搜索：关键词搜索、结果卡片摘要、筛选（笔记本/排序）。
- [ ] 切换器：页签列表、分组、收藏、最近记录。
- [ ] 组件商店：分类页签（全部/内置/插件）、搜索过滤。
- [ ] 时间问候头：组件面板顶部按时间段显示问候。
- [ ] 手机端：组件面板单列堆叠、底栏入口、设置页正常。

## 4. 已知边界（不算 bug）

- 闪卡"全部笔记本"模式最多聚合前 6 个笔记本的到期数。
- 随机回顾只抽根文档；新建库（文档数极少）可能显示空。
- 集成 Agent 的思源版本才有第 2 节能力；旧版宿主无感。
