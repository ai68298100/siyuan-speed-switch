# 悬浮球同类产品调研（2026-09-22）

本轮调研围绕悬浮球的跨端动作、动作呈现、移动端能力和后续联动展开。外部项目用于理解交互和产品边界；用户自有小驴打卡提供可以复用的图标处理经验。

## 参考项目

- [siyuan-toolbar-customizer](https://github.com/HaoCeans/siyuan-toolbar-customizer)：桌面端与移动端独立配置，支持按钮排序、启停、内置命令、插件命令、快捷键、模板、自定义文字和图标。移动端提供顶部/底部工具栏、悬浮球、溢出收纳、键盘避让、快速记录、文档前后切换和滚动到顶部/底部等通用动作。项目为 MIT 许可，行为可以借鉴，代码不直接移植。
- [siyuan-panda-navigation](https://github.com/hqweay/siyuan-panda-navigation)：动作分组、列表/网格、多级菜单、端侧独立显示、标题覆盖、预设、导入导出、编辑器/插件命令和钩子。项目为 GPL-3.0 许可，只吸收可独立重新实现的产品行为和数据模型，不复制其实现。
- [FV / fooView 官网](https://www.fooview.com/fv-cn/)与[官方更新记录](https://www.fooview.com/changelog/)：手势入口、窗口移动与缩小、快捷访问卡、自定义任务和任务分享、键盘避让。官网的[教程索引](https://www.fooview.com/articles/)还链接了详细的手势教程。本轮以这些可确认的一手页面为依据；用户提及的“qv”未能确认独立产品身份，不将同名下载站或 QuickQ 页面作为技术证据。
- 小驴打卡（本地 `D:/AI/Codex/siyuan-checkin`）：`src/shared.ts` 的 `normalizeCustomIcon` / `renderIconMarkup` 与 `src/render/bind-editor.ts` 图标选择交互。采用统一归一化、文字/图片分路、HTTPS 无凭据、base64 图片容量上限和预览；缩短文字长度适配紧凑动作按钮。图标库导入、文件上传、分类与最近使用列入 P1，不把整套编辑器搬入切换插件。

## 对本项目的取舍

### P0：先解决当前悬浮球的四个缺口

1. 主点击动作按 desktop/sidebar/mobile 分开配置，默认打开切换器；配置动作失效时回退切换器，选择“更多”时直接打开更多面板。
2. 动作执行能力与呈现字段分离。每个悬浮球动作可以覆盖有界的显示文字和图标，覆盖只改变 UI，不改变 registry、provider 或执行器。
3. 插件动作没有移动端声明时保持 `unknown`。设置页提供“手机端尝试（未验证）”显式开关，只有用户选择后才允许进入移动端首层或执行路径。
4. 三端设置页保持同一动作目录，但动作列表、主点击和启停状态按端侧独立保存；更多面板继续承担完整键盘入口和能力说明。

### P1：移动端通用动作库

先整理已有搜索、今日日记、组件面板与最近文档入口，避免重复造执行器；再补滚动到顶/底、当前文档大纲、前进/后退、快速记录。附件插入和同步入口在确认宿主 API 后加入。每个动作必须有明确的移动端执行证据，不能以桌面回调存在就推断手机可用。

联动优先使用现有 `registerQuickActionAdapter` 和插件命令：小驴打卡先验证“打开打卡面板 / 快速记录”等已公开入口；若缺公开 API，再在两个自有插件间定义窄接口。Toolbar Customizer / Panda 作为可发现的提供方，沿用来源名、失联保留配置与恢复提示，不依赖对方私有 DOM。图标库采用本地收藏、导入去重和图片压缩，避免多张内联大图超过现有配置传输上限。

### P2：触发器与组织方式

在单击稳定后增加双击、长按、滑动方向等触发器；增加动作分组、二级菜单、阅读/写作/快速记录等预设和端侧布局。触发器需要继续沿用拖动 touch slop，避免把拖动误判为点击。

退出条件：单击延迟可控、双击不会重复执行单击、长按与拖动互斥；手机端保留不依赖手势的更多面板。预设导入只更新显式选择的端侧，并提供预览和恢复默认。

### P3：生态联动与诊断

按“插件 API → 思源命令/快捷键 → 有限 DOM 兼容层”的顺序增加适配器。自定义脚本、模拟点击序列、前置/后置钩子、配置分享和多设备同步必须后置，并具备权限、超时、失败原因和恢复路径。它们不能成为默认动作的隐式依赖。

## 验收边界

Chromium/桌面夹具只能证明 DOM、布局和事件逻辑。真实 SiYuan 桌面会话、窄侧栏和 Android WebView 仍按 `BLOCKERS.md` 的 B-004/B-005 后置；浏览器移动模拟不计作 Android 验收证据。
