# 实验代码片段工作室：研究与实施计划

日期：2026-09-25。用户本轮明确授权研究并开始渐进开发。任务号 T-6859 起；本专项优先于第五波交互升级，不包含发布。

## 用户目标

- 新建实验面板，入口暂只放在页签面板内部；不注册快捷键、宿主顶栏或侧栏按钮。
- 管理 CSS / JS 片段，提供效果预览、内置片段目录、个人导入与经过审核的投稿路径。
- 原生思源 AI 参与需求生成、解释、优化和迭代；AI 产物先作为草稿预览，由用户决定是否应用。
- 宽屏约 4:1：左上效果预览，左下功能说明与片段选择，右侧 AI；选择片段时打开分类筛选目录。
- 研究字体功能的归属和与现有字体插件的兼容，不先复制其完整产品面。

## 当前边界

当前已固定以下实施原则：原生片段为启用状态唯一来源；预览不用生产文档；导入默认禁用；JS 关闭不能声称撤销已有副作用；无社区服务端时只做本地投稿包，不冒充已上传 / 已审核；不读取模型密钥、不自动发起付费模型请求。原生整表接口的读写窗口无法提供原子并发保护，已记录在 ADR 0078。
