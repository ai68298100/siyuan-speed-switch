# 产品方向复核与无需宿主验收的功能深化计划

日期：2026-09-27。规划任务：T-6948。决策：[ADR 0088](adr/0088-local-functional-deepening.md)。

本文件是下一阶段的执行账本，接续 [2026-09-22 账本](dev-plan-2026-09-22.md)。T-6949～T-6961 共 **13 项功能**均为「待开发」，编号已预留；后续新任务从 T-6962 起，不复用预留号。本轮交付产品盘点、方向和计划，不将计划当作实现成果，不自动启动这 13 项。

## 1. 愿景、目标与不做什么

**愿景：让思源用户在同一个本地优先的工作入口中，快速找到内容、理解当前上下文、组织信息并安全调整工作环境。**

插件的身份继续是「统一切换与工作上下文平台」。第一面板解决“我要去哪、先看什么”，第二面板解决“此刻需要关注哪些信息”，第三面板解决“怎样安全编辑和试验片段”，悬浮球解决“从哪里快速进入”。三面板是同一平台的不同工作方式，不是三个独立应用；悬浮球不是第四面板。

| 目标 | 用户能够完成的事情 | 判断方向是否正确的标准 |
|---|---|---|
| 快速到达 | 切换已开内容，找到收藏、最近、日记和搜索结果 | 远程失败不阻塞本地导航；高频入口不被新功能挤走 |
| 看清再行动 | 阅读预览、判断来源、看懂将发生的配置或版本变化 | 信息准确，有明确范围；预览不等于已执行 |
| 可恢复地调整 | 撤销布局和草稿修改，明确处理冲突与离开 | 无静默丢稿；取消零写入；失败不假报成功 |
| 可理解地维护 | 找到设置，定位失败组件，了解缓存与刷新状态 | 状态可定位、可解释、可操作，不能只依赖颜色 |
| 保持轻量一致 | 三面板沿用共同导航、状态、焦点与主题语义 | 不重复外壳、不另造存储真源、不引入重型编辑器 |

不做：另建全文索引、替代思源文件树/编辑器/同步、无边界扩充组件数量、云端账号服务、任意 SQL/JS 执行、自动启用片段、AI 自动保存、系统级跨应用悬浮层。Agent 和外部生态继续复用现有契约，不作为本批扩权方向。

不承诺未经测量的使用率、耗时改善百分比或发布日期。功能成功用可复现的用户路径和失败路径判断；性能以相同夹具的前后对比记录，测试数量不是产品成果。

## 3. UI 整体结构与完善方向

### 3.1 共用外壳

从上到下维持「紧凑平台导航与关闭 → 必要上下文/当前操作 → 主内容 → 按需状态或主要操作」。第二、第三面板不恢复额外的宿主大标题；和第一面板对齐的是顶部起点、控件语义与间距，不要求三种主体同构。

状态说明尽量贴近对象。全局只汇总，详情按需展开；同一状态不再堆成多行标题、横幅、徽标和说明卡。焦点可见、关闭可达、空/加载/失败/不可用/未保存可区分，颜色之外必须有文字。主题沿用 `--b3-*`；不引入另一套视觉系统。此次也对照了工作区尚未提交的 UI 手册与原型审查资料，但它们不作为本计划的必需依赖，原型建议不是生产缺陷的自动证据。

### 3.2 第一面板：选择为主，预览辅助判断

- 保留搜索、收藏、最近、日记等高频入口；结果列仍负责选择和打开。
- 预览继续采用已交付的 34%、280～480px、1px 中性边框、固定头部和正文滚动。不再无依据放大，避免压缩结果列；窄于 680px 的既有单列降级保持。
- 将“固定预览”和“在预览中查找”收进预览头部的紧凑操作，不另加整屏工具栏。固定状态必须带文档名，明确它可能与当前选择不同。
- 保存搜索的管理从现有对象入口进入，避免再次添加一个常驻导航标签。
- 不改变全局数字快捷键含义；原型数字提示冲突单独后置，不能为新功能静默抢键。

### 3.3 第二面板：内容、编辑、健康各有位置

- 顶部保留编辑、刷新、商店；主区展示组件；底部汇总运行状态。已移除的问候行、开发邀请和重复标题不恢复。
- 撤销/重做只在布局编辑态出现，完成后退出编辑工具组。刷新状态不进入布局历史。
- 点击健康汇总才打开失败/加载/缓存详情，提供定位和已有重试动作；详情关闭恢复触发点焦点。
- 继续区分“旧内容可读”与“此次刷新失败”，不把缓存回退显示成刷新成功。
- 组件配置已具备变化计数、原生字段有效性和首个无效字段聚焦，不再把这些当新项目。各组件的后续特化优化须有真实缺口，再另立任务。

### 3.4 第三面板：编辑、效果和保存风险清晰分层

- 保持目录入口、编辑区、CSS 预览、属性/AI 辅助区和唯一底部保存按钮；名称保持单一编辑源。
- 未保存标识与原生启用状态分别表意。主要缺口是“保存并继续/放弃/取消”、草稿撤销、冲突比较及保留副本。
- 查找替换属于编辑器局部工具；CSS 场景属于预览局部工具，不再增加顶部标题行。
- AI 建议沿用人工差异接受，接受后作为一次草稿编辑事务；AI 对话历史不充当普通撤销历史。
- 五条安全说明继续保留。CSS 使用静态隔离样例，JS 不执行预览；不承诺复刻用户实际主题。移动端不借此批次开放实验室编辑。

### 3.5 悬浮球与设置

- 悬浮球只承载已有动作和对象引用；默认回到平台的路径始终保留。真实触控、旋转、键盘避让仍属设备证据。
- 设置页在现有十组上方加入搜索定位，结果显示“设置名 + 所属组 + 简要说明”，进入后聚焦真实控件。敏感值不进入索引。
- 配置包从“导入后才知道变化”升级为“先看差异、选择范围、确认应用”；保持现有白名单，不扩大导入权限。

### T-6949 固定与解除固定当前预览

- **已有 → 增量**：当前跟随结果悬停/焦点；增加会话级固定，让阅读不因鼠标移到其他条目而丢失。
- **UI**：预览头部固定按钮及“已固定 · 文档名”；解除后跟随当前有效选中对象。窄窗隐藏再恢复时，同一会话保留固定对象；会话销毁时释放。
- **边界**：不增加正文上限、不持久化正文、不打开新页签、不新增宿主端点。列表重建不能偷偷换掉固定对象；对象不可用保留明确回执。
- **本地验收 / 完成定义**：mock 现有两路取数，验证固定后悬停/键盘选择/查询重建均不覆盖正文，解除后恢复跟随；验证慢响应乱序、半失败、非文档对象、窄宽切换和销毁清理。操作可用键盘完成，控制读出的确是固定文档。

### T-6950 预览内查找与命中导航

- **已有 → 增量**：现有有界正文/大纲只能阅读；增加本窗格纯文本查找、命中计数、上一处/下一处和清除。
- **UI**：预览头部按需展开查找条，标注“仅当前预览”；不抢占宿主全局查找快捷键。
- **边界**：不重新取全文，不把未载入正文当作“全文无结果”；不支持正则，文本安全高亮，不使用未转义 HTML。
- **本地验收 / 完成定义**：中文、大小写约定、空词、无结果、特殊字符、多命中循环、预览目标切换和固定态；DOM 验证当前命中滚入正文视口且不带动结果列表，清除后恢复原文结构。

### T-6951 设置全局搜索与精确定位

- **已有 → 增量**：现有十组浏览式设置；增加跨组设置项索引与定位，不是另做一套设置编辑器。
- **UI**：设置顶部搜索，结果按组归属展示；选中后切到对应组、滚入视口、短暂强调并聚焦现有控件。空词返回正常分组浏览。
- **边界**：索引只收标题、说明、预设关键词，不收 token、用户输入值、笔记内容。条件不可用项显示原因，不强行开启依赖开关。关键词跟随中英文文案。
- **本地验收 / 完成定义**：测试跨组同名项、隐藏项、无匹配、中英文、返回清空和键盘选择；用 mock 设置宿主验证定位到生产控件，搜索本身不保存配置。结果数量有界。

### T-6952 保存搜索的重命名与条件编辑

- **已有 → 增量**：当前按查询文本命名，已有保存、回放和删除；新增可读名称编辑，以及已支持的查询/笔记本条件修改。
- **UI**：现有保存搜索对象的更多操作中加入“编辑”；显示名称、查询、已有笔记本约束和保存/取消，不新增常驻页签。
- **边界**：保持原 ID，不将保存搜索注册成动作；不假装支持未保存的更多筛选维度。名称与查询长度沿用模型限制；同名允许但明确显示条件，空查询拒绝。
- **本地验收 / 完成定义**：内存设置验证取消零写入、保存后 ID 不变、超长/空值有可见提示；模拟数字槽仍按同 ID 回读新条件，删除目标仍不可用，不静默改指向。回放复用既有过滤模型。

### T-6953 工作台布局编辑撤销/重做

- **已有 → 增量**：当前拖动、增删和尺寸调整直接更新布局；新增一次编辑会话内的布局操作历史。
- **UI**：编辑态工具组显示撤销/重做及可理解的操作名；一次拖拽结束计一次，连续过程中不刷满历史。
- **边界**：只恢复组件实例存在性、位置、尺寸以及删除实例所必需的既有配置快照；不撤销组件内部任务写入、刷新结果或第三方服务操作。历史最多 30 步并设置总内存上限，退出会话释放，不新增持久化真源。配置快照不输出到日志。
- **本地验收 / 完成定义**：mock 布局保存和组件注册，覆盖拖动/添加/删除/尺寸、重做分支清除、上限、保存失败、外部布局改变。提供方已卸载时显示不可用占位或拒绝恢复并解释，不运行不存在的组件；刷新完成不污染历史。

### T-6954 组件健康详情、定位与脱敏诊断

- **已有 → 增量**：当前有健康数量和失败重试；新增从汇总到具体组件的明细路径。
- **UI**：点击底部健康汇总，按失败/加载/正常列出组件；显示已有的失败分类、缓存标记、可取得的成功/尝试时间；提供定位卡片、单项重试、复制脱敏摘要。
- **边界**：复用已有控制器结果，不增加探测请求或自动重试频率。不知道的时间显示“未知”，不编造。诊断白名单仅含组件类型、状态、错误分类和时间，不含原始异常文本、响应正文、笔记标题、URL 查询参数或凭据。
- **本地验收 / 完成定义**：fake clock + 成功/超时/缓存回退/重试 fixture，确保旧内容可见但仍计失败、状态能实时更新，点击定位与回焦正确。复制前可检查摘要；取消/剪贴板失败有回执；恶意错误文本和密钥 fixture 不得泄露。

### T-6955 文档集历史版本差异预览

- **已有 → 增量**：已有有界版本和可逆回滚；新增回滚之前与当前集合比较的只读视图。
- **UI**：历史版本列表提供“查看差异”，按新增/移除/顺序变化分组；现有快照可表达的布局/活动项变化逐项显示，然后选择回滚或取消。
- **边界**：仅比较现有快照字段，不新采集正文、不调用文档打开、不借此承诺恢复滚动位置。缺失的历史元数据标为“未记录”；标题改名与文档身份按稳定 ID 区分。
- **本地验收 / 完成定义**：纯模型覆盖增删、重排、同 ID 标题变更、重复/畸形条目和旧 schema；DOM 验证预览零写入、取消零副作用，确认才调用已有回滚入口，保留其可逆历史语义。实际恢复页签不在此任务范围。

### T-6956 脏稿保存并继续 / 放弃 / 取消

- **已有 → 增量**：当前 `canDiscard` 使用同步确认放弃；改为可等待保存结果的三选一路径。
- **UI**：切换片段、新建、导入、刷新、跨面板导航或关闭遇到脏稿时，统一显示三动作，默认聚焦取消。唯一底部保存仍保留。
- **边界**：必须先梳理同步 `canClose` 与异步保存的接线，用待执行意图协调，而不是简单把布尔函数改成 Promise。保存失败/冲突不继续导航；连续点击不得重复写入或执行两个导航。放弃只放弃当前草稿，不删除原生条目。
- **本地验收 / 完成定义**：store mock 驱动成功、拒绝、异常、冲突、超时；用 Dialog/平台适配器 mock 覆盖每条离开路径。失败保留正文和焦点、取消零写入、成功先保存再且只导航一次；宿主发起关闭必须先被同步阻止，再经明确结果继续，不允许 Promise 被当作 true。

### T-6957 片段草稿撤销/重做

- **已有 → 增量**：普通 textarea 编辑与 AI 对话历史已有；新增覆盖名称、类型、正文的统一会话草稿历史。
- **UI**：编辑区局部撤销/重做按钮；焦点位于编辑器时协调原生撤销快捷键，输入法组合提交前不截断事务。
- **边界**：AI 分块接受、整段接受、导入和后续替换各作为明确事务；不回滚原生启用状态或远端保存。最多 50 步且总量受限（实现前根据 `SNIPPET_CODE_MAX` 确认快照或差量策略），不新建持久化片段副本。
- **本地验收 / 完成定义**：模型和生产编辑 DOM 覆盖合并输入、IME、名称/类型、AI 接受、分支、内存上限；保存建立新 baseline，撤销至旧内容时 dirty 真实变化；切片经过 T-6956，不能把 A 的历史应用到 B。

### T-6958 片段保存冲突比较与保留副本

- **已有 → 增量**：当前 conflict/changed/missing/duplicate 主要呈现错误文案；新增可判断和处理的冲突界面。
- **UI**：显示编辑基线、本地草稿、最新读取版本的差异；提供继续编辑、保留为禁用副本、明确放弃后重新载入，保留取消出口。
- **边界**：复用现有读取/保存/diff，不自动合并、不提供绕过并发检查的强制覆盖。另存不修改冲突原件、不自动启用；重名走现有校验。重新读取后再次冲突仍返回界面，不宣称服务端 CAS 或跨端原子保证。
- **本地验收 / 完成定义**：模拟外部修改、删除、重复、读取失败、二次冲突、另存失败；验证每条路径保留本地草稿或取得明确放弃，副本保存为禁用且原件不变。无真实思源写入即可完成行为验收。

### T-6959 片段内查找与替换预览

- **已有 → 增量**：目录搜索已有，正文无插件级查找替换工具；新增当前草稿内的纯文本定位与替换。
- **UI**：编辑区按需展开查找条，显示命中数、上一处/下一处；替换全部前显示数量及有界差异，确认才修改草稿。
- **边界**：不跨片段、不做正则替换、不改变原生已保存数据、不引入 Monaco 等编辑器依赖；替换事务接入 T-6957。空搜索词禁用替换。
- **本地验收 / 完成定义**：中文、多行、CRLF、字面特殊字符、无命中、大文本上限与重叠命中规则；取消不变、确认只改草稿、一次撤销恢复，dirty 与光标/选区一致。

### T-6960 CSS 预览场景和视口切换

- **已有 → 增量**：目前固定综合样例且已有明暗/基线能力；新增可选择的“阅读文档 / 表格与代码 / 界面控件”静态场景和有限宽度档位。
- **UI**：预览头部场景选择与宽度选择，复用已有明暗和基线对照；明确“示例环境”，宽度不足时单视图呈现。
- **边界**：固定白名单样例，不拉取个人文档或实际主题资源，不执行脚本，不新增 iframe 权限。静态控件只用于样式观察，不能误导为真实宿主操作。
- **本地验收 / 完成定义**：普通 Chromium 挂载生产预览模块，验证切场景/宽度/主题不丢草稿，表格代码溢出可读；用外链、`</style>`、脚本和 CSS URL 输入验证隔离与禁止网络边界，JS 仍不能进入执行预览。浏览器样例不记为宿主主题兼容通过。

### T-6961 配置包差异预览与分组选择应用

- **已有 → 增量**：当前文件解析后统一确认导入；新增导入前比较与白名单分组选择。
- **UI**：展示版本、包含范围，以及设置、保存搜索、文档集等既有可迁移组的新增/替换/保持；整组勾选，默认列清后果、手动确认。数组按既有组级替换语义展示，不暗示逐项智能合并。
- **边界**：沿用文件大小、schema 和白名单约束，不扩展到凭据/第三方私有数据；未选组不变，不支持秘密值预览。先完整校验再请求写入；确认前若当前状态已变化，重新比较，不应用旧预览。多 key 持久化不是现有原子事务，必须如实反馈应用/失败范围，不能展示“任一失败零写入”的虚假保证。
- **本地验收 / 完成定义**：纯模型比较和内存存储适配器覆盖旧版本、畸形、未知字段、空包、数组替换、选择子集、取消、并发变化和保存失败；校验失败/取消无写入，成功仅变更选中组，部分持久化失败不报全部成功。复用现有导出提供操作前备份入口，不偷偷另存敏感快照。

## 6. “无需宿主实际验证”的验收合同

本批 **13/13 项均可在不启动思源内核、不安装到个人思源、不连接 AI/第三方服务的条件下完成开发验收**。这不是取消验证，而是把每项增量限制在既有适配边界以内：

1. 纯模型：输入、输出、边界、旧数据兼容、取消和失败场景用 Node 测试。
2. DOM 行为：生产 UI 模块使用内存 store、Dialog/导航/剪贴板/取数适配器 mock；检查交互结果，而不只搜索源码字符串。
3. 普通 Chromium：加载真实生产样式和模块的本地 fixture，检查键盘、焦点、明暗、宽窄和短高布局。不能默认复用需要启动隔离思源的 E2E 脚本；夹具缺少注入点时，在对应任务内补最小测试接缝，不以测试设施单独凑功能项。
4. 生产接线：构建/类型与既有集成契约验证真实调用位置，不能只把模型写好却不接按钮。分别标注“模型通过 / UI 夹具通过 / 生产接线通过 / 宿主未复验”。
5. 每个任务须覆盖成功、空/不可用、失败、取消、重复操作以及受影响的生命周期；任务按风险选择必要场景。新增或修改门禁/契约测试必须按 [门禁审计清单](gate-audit-checklist.md) 负向注入，记录预期失败和恢复；本轮仅改规划，不新增门禁。

本地开发完成的退出条件：生产功能已接入、相关测试通过、类型/构建及受影响 smoke 通过、阶段全量回归和发布质量检查通过、任务证据与剩余集成范围记账。发布质量检查通过不代表本轮发布。

真实宿主样式、Dialog/关闭事件差异、原生片段并发保存、真实存储失败、Android 手势与第三方服务可用性仍有集成风险。沿用 [BLOCKERS](../BLOCKERS.md) 的 B-004～B-007 及对应任务后置记录，不把 fixture 当实装证据，也不因这些记录停掉整个本地队列。若某项必须引入新宿主接口才能兑现，先收窄到本文件定义的增量；仍无法收窄时记阻塞并转向下一项，不伪造本地完成。
