## 环境

- SiYuan 版本：
- 插件提交/版本：
- 操作系统与窗口缩放：
- 主题（默认明/暗、Neo 等）：
- 端口/认证方式：仅记录端口与“已认证/未认证”，不要记录令牌

## 路径筛选（T-103/T-107）

- `/api/filetree/listDocsByPath` 能力探测：`通过 / 缺失 / 未认证 / 超时`
- 成功响应是否包含 `data.box`、`data.path`、`data.files`：
- 笔记本切换是否清理旧路径 chip：
- 取消请求后是否保留原筛选结果：
- 失败是否显示非阻塞降级，而不是“空目录”：

## 侧栏与状态区（T-080/T-093）

- 最窄可用侧栏宽度（px）：
- 路径 chip、清除按钮和键盘焦点是否可见：
- 长文案是否遮挡重试/折叠控件：
- 真实截图或录屏位置（不要把敏感文档内容提交到仓库）：
