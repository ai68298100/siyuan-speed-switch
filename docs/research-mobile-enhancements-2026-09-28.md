# 移动端增强与面板尺寸待办研究（2026-09-28）

## 结论

本轮只做研究和登记，不改生产代码。公开目标仓库为 [wmy2981/some-settings-siyuan](https://github.com/wmy2981/some-settings-siyuan)，项目名为 Some Settings，最低版本声明为 3.8.6-alpha.4，采用每个功能独立启停、独立配置和按前端挂载的机制。

当前本插件已经具备较完整的悬浮球动作底座：移动端可用的同步、快速记录、切换页签、滚动、收起键盘、标记位置、剪贴板等内建动作；思源宿主命令还覆盖大纲、书签、标签、收集箱、反链、最近文档、文档树、主菜单和全局搜索。外部插件中“立即同步”和“移动端日志”不应直接复制成第二套入口。

## 面板尺寸现状

| 表面 | 当前状态 | 现有选项 | 需要用户判断的缺口 |
| --- | --- | --- | --- |
| 切换器 | 已支持 | 自适应、固定尺寸、全屏；新装默认全屏 | 是否保留全屏默认，以及自适应比例/固定宽高的默认值 |
| 工作台 | 已支持 | 跟随/自适应/固定尺寸/全屏；新装默认全屏 | 是否把“跟随”继续作为独立选项，还是收敛为明确的三档 |
| 片段实验室 | 当前固定铺满视口 | 生产代码直接取视口宽高并挂 `sw-dialog--fullscreen` | 是否补齐自适应与固定尺寸，及编辑器、预览、AI 栏在窄尺寸下的最小布局 |

因此 T-6983 的主要工作不是重做前两面板，而是先定第三面板的尺寸策略，再决定是否统一三面板的设置文案、预览和持久化字段。默认全屏的既有决策见 ADR 0080；本轮不推翻该决策。

## 外部插件可借鉴项

| 功能 | 外部插件做法 | 对本项目的价值 | 初步建议 |
| --- | --- | --- | --- |
| `mobile-longpress-menu-label` | 给移动端长按菜单的图标按钮补可见文字，返回按钮保留纯图标 | 提升触控发现性和可读性，风险低 | **优先候选**；只处理已知动作，保留 aria 与 44px 命中区 |
| `mobile-tab-doc-icon` | 对无文档图标的移动页签提供跟随思源、SVG 或 emoji 三种显示 | 与本项目的页签卡、移动切换器直接相关 | **候选**；只接管默认占位图标，绝不覆盖用户已有图标 |
| `mobile-ref-panel-height` | 观察引用/搜索候选浮层的内联高度，按视口比例加高并设置最小值 | 移动端搜索和引用操作更容易浏览 | **候选**；必须处理软键盘、横屏和可视视口，不能只改 CSS |
| `mobile-select-native` | 将思源自己的 `select.b3-select` 转为原生 `Menu`，选择后回写 input/change | 解决 WebView 下拉体验差 | **候选但需谨慎**；范围只能是思源设置下拉，不能全局劫持原生 select |
| `mobile-sync-button` | 恢复移动顶栏已有的原生同步按钮，点击仍走宿主同步引导 | 与现有 `sync-now` 动作重合 | **不新增独立入口**；保留现有动作，若用户需要再研究顶栏显性化 |
| `mobile-bar-animation` | 顶栏、面包屑、dock 栏滚动显隐加过渡 | 视觉提升 | **低优先级可选**；必须有 `prefers-reduced-motion` 回退，且 dock 整体显示/隐藏 |
| `mobile-dock-blur` / `mobile-sidebar-blur` | 对移动 dock 或侧面板加可调模糊和透明度 | 主题质感提升 | **低优先级可选**；需要性能和主题对比度取证 |
| `mobile-block-icon-always` | 保持当前操作块的块标可见 | 依赖思源内部块操作 DOM | **暂不内置**；宿主内部结构脆弱，收益低于维护成本 |
| `hide-mobile-exit` | 隐藏移动侧面板的退出按钮 | 减少误触 | **不默认内置**；会降低退出路径可发现性，除非用户明确选择 |
| `mobile-console-log` | 环形缓冲收集控制台日志，设置页可查看、复制、清空 | 解决移动端无法方便取日志的问题 | **诊断候选**；只做开发/高级设置入口，不放进悬浮球首层 |

外部仓库的代码只作为交互研究依据，不直接复制实现。所有候选都要重新通过本项目的宿主版本、卸载清理、主题、无障碍和移动 smoke 门禁。

## 悬浮球内容建议

建议把候选内容分三层，由用户决定是否继续：

1. **现有能力确认层**：同步、快速记录、全局搜索、文档树、主菜单、大纲、书签、标签、收集箱、反链、最近文档、收起键盘等已经在动作目录或宿主命令目录中；不再重复造第二套入口。
2. **移动工作效率层**：长按菜单文字、默认页签图标、引用/搜索候选浮层高度、移动端原生下拉菜单。这四项最接近“手机端增加”插件的高价值内容，且能直接改善现有移动切换器/工作流。
3. **诊断和外观层**：移动控制台日志、顶栏/面包屑过渡、dock/侧栏模糊。它们可选，但不应占用悬浮球首层；日志只进入“更多”或设置页，外观功能必须可关闭。

暂不建议放入悬浮球首层：隐藏退出、强制保持块标、重复的同步按钮，以及无法证明移动端宿主支持的第三方动作。

## 待用户判断

- T-6983：片段实验室是否与切换器、工作台统一提供“自适应 / 固定尺寸 / 全屏”，以及全屏是否继续作为新装默认。
- T-6984：移动增强优先级选哪一档：A=长按菜单文字+页签图标+候选浮层高度；B=A 加原生下拉接管；C=B 加诊断日志；D=同时加入视觉模糊/过渡。
- 悬浮球首层是否维持当前少量高频动作，还是允许增加一个“移动工具”分组；若增加，建议只放用户选中的动作，不按外部插件整包搬运。

在用户选定前，批次⑨ C/D 组施工顺延至第三面板专项（T-6985~T-6996）阶段性收口后，改排为 T-6997。
