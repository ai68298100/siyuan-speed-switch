# 批量验收 Runbook（v0.21 真机/真实宿主集中执行清单）

> 本文档把 `docs/archive/TODO.md` 中 11 个分散的真机/真实宿主验收任务整合为**按会话类型分组**的批量执行清单。
> 每一项都标注：验证点、来源任务、对应自动化门禁、通过标准。
> 执行环境与证据边界遵守 `docs/desktop-acceptance-template.md`：不记录令牌/文档正文，浏览器模拟不算设备证据。

## 0. 准备（一次）

- 记录环境：SiYuan 版本、插件版本（当前 main 头 = 6315 项测试 / 212 文件）、操作系统与缩放、主题、端口与认证状态（只记"已认证/未认证"）。
- 从 `main` 构建一次 `pnpm build`，确认 `package.zip` 尺寸与 `docs/release-readiness.md` 快照一致（当前以 docs/release-readiness.md 最新快照为准）。
- 每完成一组就在本清单对应条目标注结论，并在 `docs/acceptance-log.md` 追加不含敏感内容的摘要。

| # | 验证点 | 通过标准 |
