## 一、 看不到入口或快捷键无反应

### Q1: 按快捷键打不开切换器？
1. **排查快捷键冲突**：
   - 默认快捷键为 `Alt+S`（或旧版 `Alt+Tab`）；
   - 请在思源笔记进入：**设置 ➔ 快捷键 ➔ 插件**，搜索“小驴雷切”或“切换器”，核对当前实际绑定的快捷键；
   - 若与其他系统全局热键（如微信、输入法或浏览器热键）冲突，请在思源快捷键设置中重新绑定。
2. **顶栏图标找不到？**：
   - 检查思源顶栏右侧是否开启了“折叠更多”，插件图标可能被收纳在 `...` 下拉菜单中；
   - 进入思源 **设置 ➔ 插件 ➔ 小驴雷切**，确认插件状态处于“已启用”。

### Q2: 悬浮球没有显示？
1. 悬浮球默认策略是**独立端侧开关**：
   - 打开小驴雷切 **设置 ➔ 悬浮球**；
   - 分别核对“桌面端启用”与“手机端启用”开关是否打开；
2. 检查屏幕边缘吸附：
   - 悬浮球具备平滑边缘吸附机制，请检查是否贴在窗口最右侧或底部边缘；
   - 若坐标发生异常偏移，可在设置页点击“重置悬浮球位置”。

## 二、 搜索卡顿或响应缓慢

### Q1: 输入搜索词时有轻微延迟？
- **正常机制解释**：
  - 小驴雷切采用三层递进架构：
    1. **第 1 层：已打开页签**（本地内存秒级即时过滤，0 延迟）；
    2. **第 2 层：已打开文档全文检索**（内核受限请求）；
    3. **第 3 层：全库文档检索**（内核原生全文请求，带 180~250ms 防抖）。
  - 防抖是为了防止连续敲击键盘向思源内核发起几十次并发 SQL 请求导致内核卡死。连续输入时仅最后一次按键会触发全库查询。
- **优化建议**：
  - 若仅需在当前已打开的标签页中切换，可直接使用方向键或直接输入标题关键词，前几项命中无需等待全库返回。

### Q2: 超大笔记本或数十万字大库首次检索较慢？
- 首次搜索大库时，思源内核需加载 SQLite FTS 索引缓存；内核返回后插件会将结果缓存至有界内存中，后续同类查询将直接命中内存缓存。

## 三、 搜不到想要的内容或无结果

### Q1: 明确存在的文档却搜不出来？
1. **检查顶部筛选标签（Filter Chips）**：
   - 检查输入框下方是否激活了特定的笔记本筛选（如 `[笔记本A ×]`）或路径筛选；
   - 若激活了特定范围，只有该路径下的文档会被返回。点击标签上的 `×` 或点击“全部”重置范围。
2. **新建文档尚未被内核写入索引**：
   - 刚创建或刚刚从外部导入的大量文档，思源内核写入 FTS5 全文索引通常有 1~3 秒异步落盘延迟；稍等数秒后重新检索即可命中。
3. **输入词为中文拼音但未命中？**：
   - 插件内置 `tiny-pinyin` 轻量拼音引擎，支持全拼与首字母匹配文档标题；
   - 但若使用拼音搜索文档**正文块**，需依赖思源原生检索能力。

## 四、 小组件显示“不可用”或刷新失败

### Q1: 某个小组件显示“提供方未注册”或“不可用”？
- **原因**：该组件为第三方联动组件（例如小驴打卡、Task Horizon 等外部插件提供的组件）；
- **排查**：
  - 若您未安装或禁用了对应的来源插件，小驴雷切会保留该卡片在工作台的位置（防止您重新启用插件后丢布局），并以非阻塞占位符显示；
  - 只要重新安装或启用对应的来源插件，小组件将自动恢复；
  - 若您不再需要它，可在看板进入“编辑布局”模式，点击卡片右上角 `×` 移除。

### Q2: 天气或网络组件显示“缓存”或“刷新超时”？
- **离线与降级保证**：
  - 天气（Open-Meteo）、RSS 订阅、Bangumi 等依赖外部 API 的组件具备严格的超时与缓存机制；
  - 当遭遇网络断开或代理超时时，插件**绝对不会让界面报错崩溃**，而是自动保留最后一次成功的缓存数据（标注 Stale），保障您的离线使用；
  - 恢复联网后，点击卡片上的“重试”或工作台的“刷新全部”即可绕过缓存重新获取。

## 五、 片段、设置或布局“没保存”

### Q1: 在片段实验室修改的 CSS 怎么没生效？
1. **检查“草稿未保存”状态**：
   - 片段实验室严格执行安全沙箱规范：在编辑器修改后，顶栏会显示橙色“草稿未保存”；
   - 必须显式点击顶栏的 **“保存”** 按钮，改动才会真正写入思源的原生代码片段中；
2. **确认片段是否“已启用”**：
   - 保存后，请检查片段左侧列表的开关状态是否为“已启用”；未启用的片段不会被思源加载。

### Q2: 调整的小组件位置重启思源后恢复了？
- 小驴雷切采用防抖保存策略（Save Debounce 400ms）；
- 调整小组件布局后，请点击工具栏的“完成”退出编排态，确保状态落盘；
- 避免在拖动小组件的瞬间立即强制强杀思源进程。

## 六、 插件升级后报错或版本不一致

### Q1: 集市更新后提示报错？
1. **彻底重启思源**：
   - 部分宿主内核在热重载大型插件时可能残留旧版内存闭包；请通过思源菜单 **“退出”** 并重新启动思源客户端；
2. **宿主最低版本边界**：
   - 小驴雷切自 `v0.24.0` 起，声明的最低兼容宿主版本为 **思源 v3.8.0**；
   - 若您的思源客户端低于 3.8.0，部分底层只读与交互 API 不可用，请先将思源升级至最新稳定版。

## 七、 如何获取脱敏诊断信息并反馈 Bug

为了在保障您**隐私绝对安全**的前提下让开发者能够极速排查定位问题，小驴雷切内置了**全脱敏诊断生成与预览机制**：

### 1. 复制脱敏诊断摘要（零敏感泄漏）
- **操作路径**：
  - 打开第二面板（工作台） ➔ 底部点击 **“查看详情”** ➔ 点击 **“复制脱敏诊断”**；
  - 弹窗将向您展示即将复制的内容（包含插件版本、端侧平台、宿主版本、各组件健康状态代码等）；
  - **安全承诺**：诊断内容中**绝对不包含**您的思源 API Token、笔记正文、文档标题、完整系统私密路径或联网凭据。

### 2. 提交 GitHub Issue
- 前往仓库：[GitHub Issue 反馈页面](https://github.com/ai68298100/siyuan-speed-switch/issues/new/choose)；
- 选择对应的模板：
  - **Bug 报告 / Bug report**：粘贴上面复制的脱敏诊断摘要，并按模板补充操作系统、主题和复现步骤；
  - **功能需求 / Feature request**：描述您期望的场景与建议；
- 再次检查：**请勿在公开 Issue 粘贴任何工作区真实敏感截图或 Token！**
