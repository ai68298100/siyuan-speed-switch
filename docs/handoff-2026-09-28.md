## A. T-6979 切换器三问题（2026-09-28 用户截图反馈，**未修复，下一步优先**）

### ① 片段实验室 chips 行位置重估
- **现象**：切换器底部回执区出现「片段实验室」行（聚焦段落/待办圆圈-颜色/标题颜色-neo蓝色…六枚 chips），与上方「工作台 · 当前文档相关」内容无上下文关联。
- **代码锚点**：`src/index.ts:5020-5033`（T-6878 引入的无查询态片段 chips 行，`fillSnippetObjects`/`renderSnippetObjects`）+ `src/index.ts:5081`（T-6881 查询态片段分区 `renderSnippetSearchSection`）。
- **候选方案（需定夺）**：(a) 无查询时**不再**在回执区占位——片段入口保留在搜索态分区（关键词命中才出现）；(b) 片段实验室面板**内部**加「最近片段」快速切换（承接原 chips 价值）；(c) 完全移除回执区行。倾向 (a)+(b) 组合。

### ② 收藏分组折叠钮/计数被缩略图遮挡
- **现象**：收藏夹分组头（如「收集箱」）的折叠箭头/计数显示不全，被缩略图卡片盖住（截图②：↓ 按钮压在缩略图右上）。
- **代码锚点**：`src/index.ts:9011` `appendFavGroup`（组头 `.sw__fav-group-head` = 箭头 + 组名 + `.sw__fav-count`；折叠态 `.sw__fav-collapsed`；持久化 `favCollapsed`）。方向：组头与缩略图网格的 z-index/定位/溢出关系（switcher 缩略图卡片可能绝对定位溢出压住组头），修 CSS 层叠与点击命中区。

### ③ 文档速览不渲染任务列表
- **现象**：右侧「文档速览」把待办事项渲染成普通项目符号列表，无复选框、不分已完成/未完成；部分任务内容缺失。
- **代码锚点**：文档速览渲染链路（`src/index.ts` 文档速览/`doc-preview` + `src/doc-search-ui.ts`，T-6936~T-6938 阅读窗格）。方向：渲染器补任务块形态——思源任务块 `data-subtype="t"` + `[ ]`/`[x]` 标记 → 复选框（禁用态）+ 已完成删除线；确认 SQL 投影是否携带 subtype 与任务标记。
