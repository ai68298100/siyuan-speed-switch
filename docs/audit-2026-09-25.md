# 全方位审查报告：性能 × UI × 功能（2026-09-25）

> 方法：真实内核截图审查（`SWSS_AUDIT=1 pnpm run test:e2e`，截图在 `.tmp/audit/`）+ 代码级走查 + 同类产品模式调研。截图工具已入库（tests/e2e/audit-screenshots.spec.mjs），可随时重放。

## 发现与处置

### P-A 命令模式 `>` 列表视觉粗糙【已修】
**证据**：05-desktop-command.png（修复前：全宽居中细条、无图标/描述/分组，裸按钮态）。
**根因**：列表项复用 `.sw__doc-item` 类，但该类样式作用域是 `.sw__doc-results/.sw__unified-section`——`.sw__command-list` 内完全不生效。
**修复**：重做为 quick pick 式行（左图标 + 左对齐标签 + 右侧 `↵` 激活提示），专用 `.sw__command-item` 样式（40px 行高、边框卡片、hover 主色描边）。参考 VS Code Quick Pick / [Mobbin 命令面板图谱](https://mobbin.com)。

### P-B 标题关键词高亮视觉强度不足【已修】
**证据**：02-desktop-results.png（修复前：22% 透明底在 1440p 下几乎不可见）。
**修复**：底色 22%→30% 且命中字着主色（对齐搜索引擎/VS Code 命中强度）；截图复验清晰可辨。

### P-C 预览窗格碎片感【已修】
**证据**：03 截图（修复前：无标题头、高度随内容缩成一小条、空态文案裸露）。
**修复**：常驻头部（"Outline preview" + 分隔线）与独立 body（内容轮换不清掉头部）；min-height 200px；空态带引导文案。

### P-D 预览大纲只显示一级标题【已修·功能 bug】
**证据**：03/04 截图只出现 h1；探针（scripts/e2e/probe-outline.mjs）实证内核行为：
1. `preview:false` **恒返回空**（须 `preview:true`，副作用=顶层多一项合成文档名，正好当窗格标题）；
2. 返回嵌套树，**子项标题文本在 `content` 字段而非 `name`**（顶层项在 name），层级在 `depth`；
3. 刚创建的文档 SQL blocks 可能查不到（事务队列未 flush），大纲端点内部会 flush 所以可用——预览首段 SQL 对秒级新文档可能有延迟，可接受。
**修复**：调用改 `preview:true`；模型递归拍平 + `name||content` 双字段 + depth 层级；补真实形状单测与契约断言。

### P-E 工作台关联行纯 spinner 观感【已修】
**证据**：01-desktop-empty.png（块引索引延迟期 ~12.5s 只剩转圈）。
**修复**：首轮为空即把骨架换成"暂无关联内容"弱提示（i18n workbenchRelatedEmpty），后台继续有界轮询，数据到达照常替换。

### P-F 快速动作栏中英混排【待查】
E2E 英文前端下底栏显示"日记/搜索/设置"（中文）而其余 UI 为英文。嫌疑=快速动作默认标签硬编码中文（quick-actions.js 内建目录 label 即中文）。待核实是否走 i18n 化路径；用户界面为中文时无感，暂不阻塞。

### P-G 头部"By notebook · Recently ..."截断【接受】
分组摘要过长省略号截断，信息仍有可读性；与窄宽优先级权衡后接受，不改。

## 性能走查结论

- 搜索输入防抖已在 applySearch 内部（compositionend 补触发），无新增风险。
- 文档结果区为整区重建式渲染，跳动问题已由 T-6825 视口锚定补偿；当前结果规模（≤ 数十行）DOM 重建成本可接受，暂不做增量 diff。
- 预览窗格 300ms debounce + 代际计数丢弃过期回包，快速方向键扫视不级联请求（截图复验）。
- 包体 1003641 B < 1024 KiB 自律线；zip 452620 B < 512 KiB 硬上限。
