## 自由停放与外拨展开评估（2026-09-22 用户需求，仅评估不实施）

用户需求：悬浮球可挪动至任意位置（不固定贴边）尝试一段时间（保证时间长度）；从球往外滑动可展开动作按钮，且滑动方向要有足够空间放下全部按钮。

### 评估结论：可行，且地基大半已在

| 需求点 | 结论 | 代码证据 |
|---|---|---|
| 挪动至任意位置 | ✅ 已随 B7 交付 | `floating-ball-model.js` 位置含可选 `xRatio`；`floating-ball-ui.ts positionFromPointer` 在 `snap=false` 时写入归一化 xRatio；位置经 `onPositionChange` 持久化，窗口 resize 按比例恢复；设置页"拖动后吸附边缘"开关已注明"关闭后可在可视区域自由放置"（i18n floatingBallSnapTip） |
| 保证一定时间长度 | ✅ 无需代码 | 自由位置本就长期持久化、重启保留，不存在"一会儿回弹"；"尝试一段时间"作为试验观察承诺登记（T-6784），不设自动回撤 |
| 滑动方向空间放下全部按钮 | ✅ 布局层已有降级链 | `floating-ball-layout.js`：`arcTargets/verticalTargets/gridTargets` + `fits()` 空间检查，放不下自动换排布；缺"滑动方向偏好"输入（当前方向只认左右 edge） |
| 往外滑动展开面板 | ⚠️ 新触发器，需开发 | 现状：拖动中按钮弹出+拖到按钮松手执行（已有）；但松手未命中时球落位、按钮消失——没有"松手后面板保持展开"（sticky targeting）态；无速度/方向判定 |

### 风险与缓解

- WebView pointermove 事件频率不稳 → 速度用时间窗口均值，不用最后两帧；
- 外拨与搬运误判 → 外拨成立时球回弹原位（复用 applyPosition）；位移与速度双条件判定，阈值进配置可调；
- sticky 态与滚动显隐/闲置降透明互斥 → targeting 态已在 hiddenReasons 豁免清单，沿用；
- 手机端宿主侧滑冲突 → 依赖 T-6778 先行（ADR 0071 结论），不抢跑。
