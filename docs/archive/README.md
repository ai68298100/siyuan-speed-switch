# 归档区（docs/archive）

> 建立：2026-09-17｜依据 ADR 0051《治理文档归档与根目录体积门禁》

## 本目录的性质

**冻结快照，只读，不追加。** 这里的文档记录的是"当时的事实"，不随项目继续演进。
修改它们等于篡改历史——需要修订结论时，请在新的事实源里写一条新记录并指向旧条目。

## 归档清单

- `docs/archive/TODO.md` — 历史任务账本（T-0001…T-6289，8175 行，6186 项已勾选 / 84 项未勾选）
- `docs/archive/DECISIONS.md` — 历史决策账本（D-001…D-396，539 行）
- `docs/archive/PROGRESS.md` — 历史进度与发版流水（565 行）

> 清单是本目录的事实源：`tests/root-doc-budget.test.cjs` 直接读取本节，
> 校验"每一项都在 `docs/archive/` 内、且根目录不得存在同名文件"。新增归档项请在此登记。

## 归档理由

三份文件合计 920,925 字节、占根目录 Markdown 总量约 89%，且互相覆盖、必然过期：

| 症状 | 说明 |
|---|---|
| 互相覆盖 | 同一件事在 TODO / PROGRESS / DECISIONS 各记一遍，三处必然不同步 |
| 必然过期 | 条目只增不删，历史锚点（如"当前 300 KiB 上限"）会随时间失真 |
| 体积失控 | 单文件最大 454,957 字节，超出人工可审阅范围 |
