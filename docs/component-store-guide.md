# 组件商店使用说明

这份说明是组件商店中所有“数据来源、联网和前置条件”组件的统一入口。商店卡片上的来源徽标与筛选页签和本页保持一致。

## 先看来源分类

| 分类 | 含义 | 使用前需要做什么 |
| --- | --- | --- |
| 离线可用 | 只读取思源本地数据或设备时间，不发起网络请求 | 直接添加即可 |
| 本机服务 | 访问本机回环服务（例如 ActivityWatch） | 先启动服务，并确认端口；数据不会发往公网 |
| 外部 API | 访问互联网或用户填写的远程端点 | 阅读端点、隐私和缓存说明，确认网络可用 |
| 插件组件 | 由其他已安装插件注册 | 安装并启用对应插件，再刷新商店 |
| 条件可用 | 需要特定字段、日记格式或配置 | 按组件卡片的前置条件配置后再添加 |

分类可以叠加：例如“外部 API + 条件可用”表示既要联网，又必须先填写端点。

商店状态还会区分“可直接使用、需要配置、需要本机服务、暂不可用、仅供参考”。“添加”只会出现在可选择状态；需要配置的组件显示“配置”，本机服务组件显示启动提示，暂不可用组件保留“重试”，参考项目只提供说明跳转，不会伪装成可安装组件。

## 内置联网组件

### 近期天气（Open-Meteo）

填写城市名称后才会请求天气数据；使用 Open-Meteo 公共接口，显示当前温度、体感、天气状态和 2–5 日预报。远程请求使用 HTTPS、固定字段、6 秒超时、128 KiB 响应上限和 15 分钟缓存。只发送你填写的城市，不读取笔记内容。

### 热搜事件（DailyHotApi）

需要填写你信任的自建 DailyHotApi 完整端点。未配置时不会联网；远程端点必须 HTTPS，并限制在热榜查询路由。响应最多 128 KiB、8.5 秒超时、30 分钟缓存；仅展示公开榜单标题和热度。

### 实时资讯（NewsNow）

需要填写你信任的 NewsNow `/api/s?id=...` 完整端点。未配置时不会联网；只请求公开资讯标题、来源和时间，不发送笔记内容。请求同样受 HTTPS、128 KiB、8.5 秒和 30 分钟缓存保护。

### 每日放送（Bangumi）

从 Bangumi 公共节目表读取今日、明日或本周条目，使用官方 3:4 封面。请求采用 HTTPS 白名单、图片懒加载和 30 分钟缓存；它是节目表，不是个性化推荐。

## 本机服务组件

### 使用时长（ActivityWatch）

先在电脑上启动 ActivityWatch（默认 `http://127.0.0.1:5600`），然后在组件配置中选择统计小时数和排行数量。插件只允许 `localhost`、`127.0.0.1` 或 `[::1]`，通过思源本机正向代理调用固定聚合 Query，只显示应用级时长，不读取窗口标题。服务未启动时会显示空状态或最近缓存，不会访问公网。

## 离线与条件组件

时间与日期、日历月视图、今日待办、日记、文档、标签、书签、统计、倒计时、学习和采集类组件均默认离线。它们读取思源已公开给插件的本地数据；“今日待办”依赖今日日记任务项或近期全库扫描设置，日历依赖日记文档日期/属性。

## 常见操作

1. 在组件商店先用“离线可用 / 本机服务 / 外部 API / 插件 / 条件”筛选，再按功能分组浏览。
2. 点击卡片中的“预览效果”查看真实布局；选择尺寸后，点击独立的“添加组件”按钮提交。
3. 已添加组件显示“配置”按钮；修改端点、城市或统计范围后保存即可刷新。
4. 组件显示“过期缓存”时，先检查网络或本机服务；删除组件不会删除笔记数据。

## 隐私与故障排查

- 组件卡片上的隐私徽标优先于本页概览；未配置的外部组件保证零网络请求。
- 远程 API 返回异常时，组件保留最近一次有界缓存，并显示可识别的失败状态。
- ActivityWatch 无法连接时，确认服务监听 5600 端口且思源桌面允许本机代理；不要把地址改成公网服务。
- 插件组件缺失时，安装并启用卡片标记的插件，再重新打开商店。
- 外部组件的状态标签、健康状态和下一步动作来自同一份来源模型；遇到“过期缓存”或“暂不可用”时可直接使用卡片上的重试入口，不会重复添加实例。

## 下一批候选

GitHub 高 Star 候选（Hacker News、RSS/Miniflux、Uptime Kuma、iCal、Syncthing、Jellyfin 等）的许可、API 和隐私边界记录在 [`external-widget-source-audit.md`](./external-widget-source-audit.md)。候选在完成真实接口与许可复核前只用于规划，不会伪装成可直接添加的组件。

手机品牌候选（Apple、Huawei、OPPO、Xiaomi）也集中记录在同一份审计表，包含天气、电池、日历、提醒事项、世界时钟、照片、屏幕使用时间、音乐、设备状态和主题等 10+ 个方向。品牌榜单会按地区和机型变化，因此只借鉴高频形态，不固化排名。

手机端组件面板采用单列纵向模式：每行只放一个组件，并使用统一尺寸；组件商店在手机端也只展示该尺寸。页签列表的列数设置不会改变组件面板布局。

旧版本如果保存过横向坐标或多列宽度，打开面板时会自动迁移为 `x=0`、全宽 `w=12` 的顺序行，不会改变组件先后顺序或折叠状态。

手机端组件内部按钮统一保留约 44px 触控高度；长标题、状态和上下文允许换行，避免在窄屏被截断。页签列表仍可按原设置使用单列、双列或自动布局。
