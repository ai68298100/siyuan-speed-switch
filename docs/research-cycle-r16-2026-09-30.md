# R16 UI 专项质感与合理性复核（2026-09-30）

> 本轮只读检查生产 SCSS、三面板 DOM 接线、现有设计规范与 T-7147～T-7197，专门寻找“更有质感、更合理、更美观”的可执行 UI 事项。用户尚未说“开始开发”，因此只登记待办，不修改生产界面、测试或发布包。

## 复核结论与去重

- T-7148～T-7159 已覆盖高保真方向、58 个组件内容、工作台整体构图、商店视觉、皮肤和视觉验收；本轮把尚未拆开的生产样式切口细化，不把“原型有了”当作完成。
- T-7192～T-7196 已覆盖桌面浮层键盘、折叠语义、卡片结构、Dialog 名称和第一面板高对比；本轮聚焦视觉层级、材质、尺度、动效和阅读舒适度，不重复交互语义任务。
- 证据来自源码静态检查和样式层叠审计，没有把个人宿主、屏幕阅读器、Android 或低端设备的观感写成已验证结果。

## 生产 UI 证据

1. **设计令牌存在重复覆盖**：`_03-switcher-mobile.scss:49-54` 对 `--sw-page-bg`、`--sw-surface-muted`、`--sw-accent-soft` 各定义两次，后值静默覆盖前值；同一批样式与 `_04`、`_snippet-studio.scss` 仍散落 7/10/13px 间距、10/14/16px 圆角和多套阴影。
2. **浮层材质没有统一层级**：设置浮层在 `_05-settings-widgets.scss:92-116/395-399` 使用两套硬编码遮罩，片段 picker 在 `_snippet-studio.scss:163-164` 另有一套 `rgb(.../.36)+blur`，移动商店详情在 `_08-home-store-cards.scss:751-779` 只有显示切换，缺少遮罩、过渡和安全区视觉。
3. **悬浮球有独立的旧视觉系统**：`_04-fab-fullscreen-soft.scss:3-19/224-243/349-364/473-487` 使用多套固定阴影、透明度、圆角和高 z-index，和平台壳 token、暗亮皮肤及面板层级没有完整对账。
4. **第一面板控件尺度不统一**：桌面搜索框在 `_03-switcher-mobile.scss:132-153` 高 34px，固定/查找按钮在 `1230-1242` 为 20px，查找输入在 `1291-1300` 为 26px；移动端另有 36/40px 规则，视觉密度随入口变化。
5. **设置页仍保留旧式分区密度**：`_02-settings.scss:236-714` 固定 132px 标签栏、多个独立 group/card/row 规格，与平台头、商店和工作台的 14/16/18px 层级及状态语言没有统一验收；移动端虽改为横向标签，但搜索、保存状态和分组卡的层级未形成同一套视觉节奏。
6. **小字号和硬编码值过多**：商店、侧栏、工作台和片段样式广泛使用 10px、10.5px、11px 元信息；部分状态、阴影和卡片圆角未引用 token。英文变长、系统缩放和窄栏下容易出现信息层级失衡。
7. **第三面板视觉层级仍偏工程表单**：`_snippet-studio.scss:39-180` 同时承载预览、详情、编辑器、AI、diff、picker，桌面 4fr/1fr 与移动 900/560px 断点是结构规则，缺少“当前任务→主编辑区→效果→风险操作”的视觉主次合同。
8. **第一面板预览已有结构但缺少阅读版式专项**：现有窗格空间和内容保真任务已登记，正文的段落宽度、标题层级、代码/表格/任务块、查找命中和固定头部的阅读节奏仍未形成独立视觉验收项。
