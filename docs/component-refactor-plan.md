## 每组件重构维度

1. **UI 密度与层级**：信息优先级、留白节奏、字号/字重阶梯、视觉动线
2. **功能增强**：缺失的交互（点击深入/悬停预览/拖拽调整）、数据维度补充、配置项完善
3. **状态完备**：加载/空/失败/缓存回退四态的视觉差异化
4. **微交互**：过渡动画（reduced-motion 降级）、hover 反馈、焦点管理

## 每批次流程

原型 HTML（自包含、明暗双主题、真实数据 mock）→ 用户过目 → 实现 → 契约+负向验证 → 全量门禁 → 账本+commit。
