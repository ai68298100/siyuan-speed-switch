## 通用模板

**标题**：[邀请] 小驴速切「组件面板」开放组件接入协议，欢迎 {插件名} 上架小组件

**正文**：

你好！我是思源插件「小驴速切 (LvSpeed Switch)」的维护者。

小驴速切近期上线了**组件面板**：一个 iPad 式的小组件主页，用户可以把各类数据组件自由添加到 12 列网格画布上（固定尺寸型号、拖拽布局、自动归位）。我们希望把更多插件的数据能力带进这个面板，因此开放了**组件接入协议**——你的插件只需在 `onload` 里调用一次 `registerHomeModule`，就能出现在组件面板的**组件商店**里：

- 只读数据契约：返回 `{items: [{label, value}]}` 形式的有界快照（平台负责超时、缓存、失败退避与渲染）；
- 固定尺寸型号声明（迷你 2×3 ～ 全幅 12×6，按模块声明支持的子集）；
- 条目点击行为：支持思源块 ID 跳转、执行指定插件命令（`command: "插件名::命令key"`）等；
- 失败兜底：读取失败时面板展示"打开插件"按钮（`open` 回调或 `clickCommand` 字符串）。

完整接入指南（含可复制的完整示例）：https://github.com/ai68298100/siyuan-speed-switch/blob/main/docs/widget-protocol.md

对 {插件名}，我们设想的组件形态是：**{组件设想}**。如果方向合适，欢迎按指南接入；有任何协议上的诉求（缺字段、想加能力），也欢迎直接在本条 issue 下讨论，协议会持续演进。

## 1. task-horizon（任务管理器）

**标题**：[邀请] 小驴速切组件面板 × Task Horizon：把「今日任务」变成桌面小组件

**正文**：

你好！小驴速切的组件面板（iPad 式小组件主页）希望能聚合各插件的数据能力，Task Horizon 是我们最希望接入的插件之一——**「今日任务 / 逾期任务」清单组件**天然适合放在主页：

- 组件设想：今日到期与逾期任务清单（大尺寸型号可带完成率汇总），点击条目直接定位到任务所在文档；
- Task Horizon 已经与底栏番茄钟打通了跨插件数据查询，组件面板的 `registerHomeModule` 协议正好可以把这类点对点集成**标准化**：注册一次，任何装了两个插件的用户都能在面板上看到；
- 你也可以用协议 v2 的 `configSchema` 让用户自选清单过滤条件（如只看某笔记本），面板会代为渲染配置表单。

接入指南：https://github.com/ai68298100/siyuan-speed-switch/blob/main/docs/widget-protocol.md （数据契约非常小：`read` 返回 `{items: [{label, value}]}` 即可）。协议诉求欢迎随时提 issue 讨论。

## 2. docktomato（底栏番茄钟）

**标题**：[邀请] 小驴速切组件面板 × DockTomato：「今日专注」小组件

**正文**：

你好！小驴速切的组件面板想聚合各插件的今日数据，番茄钟的**「今日专注」组件**（今日番茄数、专注分钟数，点击打开计时）是非常合适的首批组件——尤其 DockTomato 已与 Task Horizon 打通专注统计，组件面板的 `registerHomeModule` 协议可以把这类数据以标准化方式暴露给用户主页：

- 只读契约很小：`read` 返回 `{items: [{label: "🍅 08:30-09:10 报告写作"}]}` 形式即可，平台负责超时/缓存/失败退避；
- 支持 `refreshOn` 声明刷新时机（页签切换/打开/关闭），专注结束后主页自动更新；
- 尺寸型号自选（迷你 2×3 显示计数，或更大列出专注记录）。

接入指南：https://github.com/ai68298100/siyuan-speed-switch/blob/main/docs/widget-protocol.md

## 3. calendar（日历面板）

**标题**：[邀请] 小驴速切组件面板 × Calendar：把周期笔记日历搬进组件面板

**正文**：

你好！小驴速切的组件面板（小组件主页）希望接入一个**真正的日历组件**——Calendar 插件的周期笔记能力（日/周/月/年记 + 文档属性定位 + 多笔记本）比我们内置的"本月日记"列表完整得多，是组件商店最理想的日历来源：

- 组件设想：`medium`/`wide` 型号的月历网格，点击日期创建/跳转周期笔记（复用你的面板逻辑即可）；
- 协议 v2 的 `configSchema` 可以让用户在面板里直接选择笔记本与每周起始日，无需你再做设置入口；
- 协议现有条目点击约定覆盖了思源块跳转，日期→周期笔记的定位若需要更细的回调通道，欢迎提 issue 我们加字段。

接入指南：https://github.com/ai68298100/siyuan-speed-switch/blob/main/docs/widget-protocol.md

## 4. sireader（电子书阅读）

**标题**：[邀请] 小驴速切组件面板 × SiReader：「最近阅读」小组件

**正文**：

你好！小驴速切的组件面板想聚合各插件的"今日状态"，SiReader 的**「最近阅读」组件**（书名 + 阅读进度百分比，点击续读）是非常典型的阅读类小组件：

- 只读契约很小：`read` 返回最近 N 本书的 `{items: [{label: "书名 · 67%", value: "书籍或定位 id"}]}`；
- 尺寸型号建议 `small`/`medium`；点击行为如需精确续读到章节，协议 v2 支持条目级 `command`（执行你插件的打开命令）；
- 失败兜底：面板会显示"打开插件"按钮。

接入指南：https://github.com/ai68298100/siyuan-speed-switch/blob/main/docs/widget-protocol.md
