# 小驴雷切产品与开发进度评审

日期：2026-10-06。评审任务：T-7124。实施清单：[当期计划](dev-plan-2026-10-06.md)。当前任务状态只维护在 [current-status-index.json](current-status-index.json)。取舍：[ADR 0147](adr/0147-product-quality-roadmap.md)。

## 1. 评审结论

核心功能已经从页签切换器发展为可用的导航与工作上下文平台；本地架构、数据边界和自动化基础较成熟。接下来最有价值的工作，是让高频路径可靠、让第一次使用容易理解、让误操作可以恢复、让支持范围和发布材料可信。继续增加组件或扩大 AI 范围不能代替这些工作。

目前不能宣称“精品完成”或“全部平台已验收”。已发现可复现的键盘行为问题和设置语义缺口；真实桌面最终观感、读屏、Android、升级回滚和部分外部服务仍有证据空白。大批本地增量尚未进入用户正式安装。没有充分依据给出整体完成百分比。

本次只读评审源码、文档、现存产物与 GitHub 元数据，并落地规划及必要的状态契约修正。下列历史测试结果来自已有记录；本次没有重跑完整产品门禁。生产缺口列入下一阶段任务，并不因列入清单而视为已修复。

## 7. 去重及停止扩张的边界

预览扩大/固定/查找、设置搜索/保存回执、布局撤销/健康详情、片段脏稿守卫/冲突副本/回收站/备份、组件内联预览、分组与标签树均已有实现。新计划只为它们的可复现缺口、用户理解或未覆盖验收增量立项。

复用旧任务：T-7115 桌面、T-7116 Android、T-7117 外部服务、T-7118 发布与升级、T-7119 编辑器评估、T-7120 新 AI 场景。后两项继续明确后置，T-6996 JS runner 保持关闭。社区目录需真实 URL 与维护者；兄弟插件业务在各自工作区开发；小驴常用完整内容库不并入切换器。

不新增云账号、另建全文索引、自动遥测、任意 JS/SQL、自动启用片段或自动上传正文。新增设置、新组件及重型依赖必须由具体用户任务证明价值；本轮不放宽预算或改变这些边界。

## 8. 下一阶段衡量办法

衡量五条主路径：切换文档、收藏后再次找到、失败搜索回到本地、恢复文档集、片段修改后取消或安全保存。记录任务是否独立完成、耗时/步骤、误点与恢复，不预设虚假的成功率或改善百分比。

工程测量复用已有首开、搜索聚合和生命周期基准。现有首开测试使用冷 1 次/热 5 次，实际断言热启动中位数 300ms；不要把注释中的 p95 描述当测得 p95。扩展持续会话、100+ 页签与慢机证据时，保存原始样本、p50/p95、环境和取数语义，只有确认瓶颈再优化。

对外质量同时检查：图标在 16/24/32px 能辨识；截图来自实际产品且脱敏；新用户通过 README 完成第一次切换；可选联网/凭据/数据位置可查；每个支持声明有端侧与版本证据；升级失败有可操作的恢复说明。具体执行和验收见当期计划。
