# 链滴 CSS 片段挖掘 → 内置片段库商店（用户指令 2026-09-30 立项）

## 目标

从链滴社区（ld246.com）挖掘优秀的思源笔记 CSS 片段，筛选、优化后作为内置片段，打造片段库商店。

## 当前状态（2026-10-04，T-7097 复核）

本地商店已由 T-7094/ADR 0134 交付：26 个随包 MIT CSS 示例与本机原生片段可筛选、只读预览，并经脏稿守卫新建禁用草稿。目录元数据归 T-7092，输入/部分保存恢复归 T-7098。商店与原生启用状态分别负责浏览和实际启用。

当前示例不宣称来自链滴作者授权。社区片段收集、来源/许可核验及真实目录获取仍需已建立的维护渠道（B-009）；已有本地投稿包与用户指定 Gist 不等于社区目录已上线。以下研究步骤保留为后置方向，不能用“本地商店完成”替代它们。

## 现有基础设施

## 社区来源研究与准入步骤（后置）

### 1. 链滴调研（第一步）
- 访问 ld246.com → 思源笔记 → 分享版块，搜索关键词：
  - "CSS 片段" / "css 美化" / "代码片段" / "样式分享"
- 重点关注的已知帖子方向：
  - 用户积累的 CSS/JS 代码片段合集帖
  - 备注样式、分割线、代码块、标签页、导出样式等具体美化方向
  - GitHub 主题仓库（tsundoku/notion/darkness 等）中的可复用 CSS
- CSDN 等博客平台的思源 CSS 片段整理帖

### 2. 筛选标准
- 必须记录可核验的来源链接、作者及允许再分发的许可；未声明许可时不随包分发
- 纯 CSS（无 JS 依赖）优先
- 不修改内核 DOM 结构（只改样式）
- 有明确的使用场景和视觉效果
- 代码量有界（< 200 行/片段）
- 不与内置主题/皮肤冲突

### 3. 优化方向
- 统一使用 CSS 变量（`--b3-*` / `--sw-platform-*`）替代硬编码色值
- 添加暗色主题适配
- 添加注释和使用说明
- 确保与皮肤层（ADR 0073）兼容

### 4. 实现为内置片段
- 在 `BUILTIN_SNIPPETS` 或专用注册表中登记
- 每个片段附：名称（双语）、描述、分类标签、预览截图
- 片段实验室中浏览、只读预览，明确创建禁用草稿后手动保存与启用

### 5. 商店呈现
- 复用已交付的实验室内部商店（T-7094），不再新造同名入口
- 分类：排版优化 / 编辑器增强 / 界面美化 / 导出样式
- 每个片段可预览→创建禁用草稿→手动保存为原生 CSS 片段

## 安全边界（不变）

- 纯 CSS，无 JS
- 不自动启用，需用户手动确认
- 原生片段开关为唯一启用真源
- 不读取个人数据或网络资源
