# 链滴 CSS 片段挖掘 → 内置片段库商店（用户指令 2026-09-30 立项）

## 目标

从链滴社区（ld246.com）挖掘优秀的思源笔记 CSS 片段，筛选、优化后作为内置片段，打造片段库商店。

## 现有基础设施

- 片段实验室（第三面板）已具备：CSS 沙箱预览、原生片段读写、AI 生成、导入导出
- T-6962~T-6964 已规划片段商店概念（内置精选/我的/社区/标签），但未实施
- `BUILTIN_SNIPPETS`（home-model）已有内置片段注册机制
- ADR 0096 定义了片段安全边界（CSS 沙箱、JS 禁执行）

## 下一会话执行步骤

### 1. 链滴调研（第一步）
- 访问 ld246.com → 思源笔记 → 分享版块，搜索关键词：
  - "CSS 片段" / "css 美化" / "代码片段" / "样式分享"
- 重点关注的已知帖子方向：
  - 用户积累的 CSS/JS 代码片段合集帖
  - 备注样式、分割线、代码块、标签页、导出样式等具体美化方向
  - GitHub 主题仓库（tsundoku/notion/darkness 等）中的可复用 CSS
- CSDN 等博客平台的思源 CSS 片段整理帖

### 2. 筛选标准
- 纯 CSS（无 JS 依赖）优先
- 不修改内核 DOM 结构（只改样式）
- 有明确的使用场景和视觉效果
- 代码量有界（< 200 行/片段）
- 不与内置主题/皮肤冲突

### 3. 优化方向
- 统一使用 CSS 变量（`--b3-*` / `--sw-platform-*`）替代硬编码色值
- 添加暗色主题适配
- 添加注释和使用说明
- 确保与皮肤层（ADR 0073）兼容

### 4. 实现为内置片段
- 在 `BUILTIN_SNIPPETS` 或专用注册表中登记
- 每个片段附：名称（双语）、描述、分类标签、预览截图
- 片段实验室中可浏览、预览、一键应用

### 5. 商店呈现
- 片段实验室内新增「片段库」视图（T-6962 概念的落地）
- 分类：排版优化 / 编辑器增强 / 界面美化 / 导出样式
- 每个片段可预览→一键应用为原生 CSS 片段

## 安全边界（不变）

- 纯 CSS，无 JS
- 不自动启用，需用户手动确认
- 原生片段开关为唯一启用真源
- 不读取个人数据或网络资源
