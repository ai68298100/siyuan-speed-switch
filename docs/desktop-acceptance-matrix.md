# T-7115 真实桌面与最窄侧栏验收矩阵

本矩阵把本地自动化证据、真实思源 API 证据和仍需桌面宿主走查的项目分开。Chromium 可以证明 DOM、键盘、响应式和主题夹具，但不能证明最窄原生侧栏的宽度、宿主窗口观感或读屏行为。

机器可读清单是 [`tests/fixtures/desktop-acceptance-matrix.json`](../tests/fixtures/desktop-acceptance-matrix.json)，门禁入口是 `pnpm run desktop:acceptance`，并已接入 `pnpm verify:release`。

当前矩阵有 11 项：10 项本地已验证、1 项本地准备，真实宿主 5 项部分具备证据、6 项等待 B-005。部分证据表示 API、普通桌面路径或真实 dock 已有思源取证，但还不足以覆盖最窄侧栏最终结论。

| 区域 | 当前本地证据 | 真实宿主状态 | 关键待证内容 |
| --- | --- | --- | --- |
| 路径筛选端点与响应 | 模型、硬化和 UI 契约 | 部分通过 | API 已有真实只读证据；仍需在桌面会话复核筛选交互 |
| 路径 chip、清除、焦点 | 设计与契约已准备 | 待证 | 最窄侧栏中 chip、清除按钮和焦点是否可达 |
| 三面板导航、返回、关闭 | 真实思源 E2E | 部分通过 | 复核用户窗口中的层级与关闭观感 |
| 明暗主题 | Chromium 明暗 smoke | 待证 | 真实思源主题变量和宿主浮层层级 |
| 键盘、滚动、状态 | 可访问性门禁与 E2E | 待证 | 真实宿主焦点顺序、Esc 和预览滚动 |

本轮普通桌面真实思源 E2E 使用端口 `19303`、隔离工作区和独立产物目录，7 个场景全部通过；证据为 `.artifacts/t7115-desktop/results.json`。另有显式 opt-in 的真实 dock E2E 使用端口 `19314` 和独立工作区，实际把宿主侧栏从 `340px` 调窄至 `245px`，并验证控件命中、键盘焦点、横向溢出和筛选重置；脱敏摘要见 [`docs/native-sidebar-host-evidence.md`](native-sidebar-host-evidence.md)。这些证据仍不覆盖原生桌面最终视觉、主题、读屏和人工最窄可用宽度，因此对应待证项继续保持 pending，不放宽路径生产门禁，也不把本地截图写成宿主通过。
