T-6971 · 2026-09-28 · 今日写作 / 近期写作活跃度 / 写作打卡 / 笔记统计

本批规格要点

  1. 材质：写作打卡/今日写作 = accent（强状态数值，本批提议扩展 HOME_TILE_MATERIALS：today-writing → accent）；近期写作活跃度/笔记统计 = plain。
  2. 数据口径：字数统计为本地计算（基于块内容长度），零网络；跨日重置瞬间（00:00）数值正确迁移；无写作如实显示 0，不编造。
  3. 事务/性能：数据随面板打开与刷新读取，无独立轮询；大库统计有界（既有 SQL 外层 LIMIT 纪律）。
  4. 验收基线：明暗采样 ≥ AA；数字 tabular-nums；空数据 = 状态区文案，不渲染空图。

moduleId / 声明档位
today-writing · 建议 sizes = [small, medium]（目标型组件，上限 M）
内容布局（各档位）
S（默认）：今日字数大数字 + 目标进度条 + 目标值；medium：加写作时长与最近编辑文档计数
状态呈现
ready；无写作 = 0 字如实显示（不隐藏组件不编造）；跨日重置瞬间数值正确迁移

「今日写作」；无 chip（无网络语义）

跨日零点重置正确；字数本地计算零网络；accent 白字对比度采样 ≥ AA

近期写作活跃度 plain · wide(8×3)，声明档位 M/W/L

moduleId / 声明档位
recent-writing-activity · sizes = [medium, wide, large]（12 个月回看 + 逐年分页，T-6461 口径）
内容布局（wide 默认）
微标头（识别名 + 年份 chip）→ 12 个月条形图（月标签 + 活跃高度）→ 底部年度合计行
内容布局（各档位）
medium：近 6 个月条形；large：12 个月 + 逐年分页（‹ ›）；X：不适用
状态呈现
loading 骨架；ready；empty = 状态区文案（不渲染空图）；error + 重试 + 保留旧图
数据与隐私
本地 SQL 有界聚合（外层 LIMIT 纪律）；逐年分页不逐月全量重查
验收要点
条形高度与数值线性对应；分页切换不闪空；明暗采样 ≥ AA

笔记统计 plain · medium(4×4)，声明档位 M/W

moduleId / 声明档位
note-stats · sizes = [medium, wide]（建议口径）
内容布局（medium 默认）
微标头（识别名 + 笔记本数 chip）→ 块数大数字 → 附件/标签/文档三行明细

数值格式化（千分位）；SQL 超时 → error + 重试不清空旧值；明暗采样 ≥ AA
