列表流家族通用规范（五组件共享，一次定清）

  1. 材质/档位：一律 plain · wide(8×3) 默认（已在 HOME_TILE_DEFAULT_SIZES 登记）；行流组件不做 accent/dark/vibrant（大面积彩底伤可读性）；声明档位均为 M/W/L。
  2. 行解剖：标题（有界省略，单行）+ 来源·时间 meta（右侧 10.5px muted）；行 hairline 分隔；条目上限首屏 ≤5，加载更多沿用既有语义。
  3. 安全红线：远端标题/摘要一律文本节点渲染，绝不作 HTML 插入；外链跳转需用户点击；来源名清洗截断。
  4. 状态：loading 骨架 / ready / empty（窗口内无条目）/ error + 重试 + 保留旧值（stale chip「N 前」）。
  5. 刷新：15 分钟心跳族 + 可见性/连接性双重门控（既有纪律）；请求有界缓存，不并发打爆。

共享行规范（列表流家族）plain · wide(8×3) 默认，声明档位 M/W/L

行解剖
标题（单行省略）+ 来源·时间 meta；条目上限首屏 ≤5（L 档 ≤8）；行 hairline 分隔；悬停/聚焦提亮
状态
loading 骨架 / ready / empty（窗口内无条目）/ error + 重试 + 保留旧值 stale chip
安全
远端文本一律文本节点渲染（防 HTML 注入）；外链新页打开需点击；来源名清洗 ≤20 字
刷新
15 分钟心跳族 + 可见性门控；有界内存缓存；请求失败不清空既有列表

RSS 订阅 plain · wide(8×3)

moduleId
external-rss-subscription · sizes = [medium, wide, large]
家族差异
多源自选聚合 + 已读记忆（T-6685）+ 来源标注行 meta；已读/未读在行 meta 与计数 chip 表达
验收要点
已读状态跨会话保留；源增删后列表即时重建；条目上限有界

未读文章（Miniflux）plain · wide(8×3)

moduleId
external-rss-miniflux · sizes = [medium, wide, large]
家族差异
Miniflux 自建服务（配置表单鉴权通道）；未读数 chip；分类发现（T-6466）
验收要点
凭据走配置表单鉴权通道不入日志；服务不可达 = error + 保留旧值
