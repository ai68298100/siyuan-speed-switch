组件规格卡 · 批次④打卡桥接系列

T-6971 · 2026-09-28 · 今日打卡 / 连续记录 / 本周打卡 / 本月打卡 / 打卡热力图 / 近期事项（均只读桥接小驴打卡）

本批规格要点（打卡桥接全家桶通用约束）

  1. 只读桥接（ADR 0057）：六个组件全部只读展示小驴打卡数据——打卡/补签等写操作一律不在本插件内发生，界面动作只有「打开小驴打卡」指引。
  2. 提供方未安装 = blocked：单元显示 blocked 占位 + 「需安装小驴打卡」说明（延续既有 availability 语义），不运行不存在的组件、不轮询。
  3. 材质：状态/连续类 = accent（今日打卡/连续记录/本周打卡）；统计/列表类 = plain（热力图/本月/近期事项）。批次建议扩展 HOME_TILE_MATERIALS：checkin-today、checkin-weekly → accent。
  4. 默认档位（本批提议，落格时登记 HOME_TILE_DEFAULT_SIZES）：今日打卡 S / 连续记录 wide / 本周打卡 medium / 本月打卡 medium / 热力图 large / 近期事项 medium。
  5. 验收基线：accent 白字对比度单独采样；提供方卸载→blocked 占位→重装后自动恢复全链路单测覆盖。

今日打卡 accent · S(4×3)，声明档位 S/M/T/W/L

moduleId / 声明档位
checkin-today · sizes = [small, medium, tall, wide, large]（availability: external，只读桥接）
内容布局（S 默认）
微标头（识别名）→ 打卡态大字（✓ 已打卡 08:15 / 未打卡）→ 指引行「打卡请前往小驴打卡」
状态呈现
已打卡 = ready；未打卡 = warn；提供方未安装 = blocked 占位 + 安装说明；读取失败 = error + 重试
材质/事务
accent；状态随打卡插件事件刷新，无独立轮询
三端收缩
三端一致（S）；侧栏/手机同款
验收要点
跨日零点状态翻转正确；accent 白字对比度采样；只读边界——不得出现任何写打卡数据的入口

连续记录 accent · wide(8×3)，声明档位 S/M/W

moduleId / 声明档位
checkin-streak · sizes = [small, medium, wide]（材质已登记 accent）
内容布局（wide 默认）
微标头（识别名 + 今日态 chip）→ 连续天数大数字 → 7/14 日点阵 → 本月 x/y 行
内容布局（各档位）
small：连续天数 + 今日态（无点阵）；medium：天数 + 7 日点阵；wide（默认）：14 日点阵 + 本月统计
状态呈现
今日已打卡 = ready chip；未打卡 = warn chip「今日待打卡」；中断 = 天数重算如实显示
三端收缩
三端一致；手机点阵 7 列压缩不换行
验收要点
连续天数计算跨月/跨年正确；点阵当日之后必须为空（不得预填）；accent 白字对比度采样

本周打卡 accent · medium(4×4)，声明档位 S/M/W

moduleId / 声明档位
checkin-weekly · sizes = [small, medium, wide]
内容布局（medium 默认）
微标头（识别名 + x/7 chip）→ 周一~周日七列（完成 ✓ / 缺卡 — / 未到 —）→ 本周合计行
内容布局（各档位）
small：仅完成计数（x/7）；wide：加单日事项数
状态呈现
完成列 = 主色 14% 底 + ✓；缺卡列 = 灰；未到期列 = muted；不单靠颜色（有 ✓/— 字形）
三端收缩
三端一致（medium）；手机双列配置下占整行
验收要点
周起点按用户设置的周起始日；跨周边界（周日→周一）列重置正确

本月打卡 plain · medium(4×4)，声明档位 S/M/W

moduleId / 声明档位
checkin-monthly · sizes = [small, medium, wide]
内容布局（medium 默认）
微标头（识别名 + x/30 chip）→ 三行统计：打卡率 / 最长连续 / 补记次数
状态呈现
数据缺失（当月无记录）= 状态区「暂无记录」；提供方未安装 = blocked 占位
三端收缩
三端一致（medium）
验收要点
打卡率分母按自然月天数；百分比 tabular-nums；除零（月初）显示 0% 不 NaN

打卡热力图 plain · large(8×5)，声明档位 M/W/L/X

moduleId / 声明档位
checkin-year-heatmap · sizes = [medium, wide, large, full]（viewType: heatmap）
内容布局（large 默认）
微标头（识别名 + 周期 chip）→ 热力网格（列=周，行= weekday，5 级色阶）→ 三统计（总次数/最长连续/本期）
内容布局（full）
通栏扩至 24~26 周 + 图例；每面板至多 1 个 X 约束同样适用（此处为 L/X 语义，非 ADR 0091 的 X 档）
状态呈现
loading 骨架；ready；empty（无打卡记录）状态区；error + 重试
三端收缩
侧栏/手机降级 M（近 8 周摘要）；色阶格子最小 8px 保可点/可读
验收要点
5 级色阶每级文字图例（色盲替代）；格子渲染数量有界；暗色下空格与满格区分度采样

近期事项 plain · medium(4×4)，声明档位 S/M/T

moduleId / 声明档位
checkin-occasions · sizes = [small, medium, tall]
内容布局（medium 默认）
微标头（识别名 + 条数 chip）→ 事项行 ≤5（事项名 + 最近打卡时间），hairline 分隔
状态呈现
ready / empty（暂无事项）/ error + 重试；提供方未安装 = blocked 占位
三端收缩
三端一致（medium）；长事项名单行省略
验收要点
事项名来自打卡插件数据，展示前清洗（控制字符/超长截断）；时间渲染本地时区
