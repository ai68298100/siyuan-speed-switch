组件规格卡 · 批次②日历与日程

T-6971 · 2026-09-28 · 日历月视图（journal-calendar）/ iCal 日程（external-ical-events）

本批规格要点

  1. 材质：两者均为 plain（信息型组件，阅读对比度优先）；不使用彩色渐变材质。
  2. 默认档位：日历月视图 = L(6×4)（模块声明仅 L/X，内容密度决定下限）；iCal 日程 = M(6×2)。
  3. 既有契约沿用：六周网格行数恒定（既有 Chromium 冒烟断言）；RRULE/TZID/EXDATE 展开语义沿用 T-6460/T-6462 门禁；今日跨日瞬间数值正确。
  4. 验收基线：明暗双主题对比度采样；三端收缩 = 侧栏 2 列降级、手机单列/双列按既有列数配置。

日历月视图 plain · L(6×4)，声明上限 X

moduleId / 声明档位
journal-calendar · sizes = [large, full]（内容密度决定下限，无 S/M）
内容布局（L 默认）
微标头（识别名 + 日记计数 chip）→ 月头（‹ 2026年9月 › 导航）→ 星期行 → 六周日期网格（今日主色圆、日记日主色点）→ 底部月统计（N 篇日记）
内容布局（X）
通栏放大：字号 +1 级、单元格留白加大、同结构；每面板至多 1 个 X（Slice 3 约束强制）
状态呈现
loading 骨架（沿用既有骨架行）；ready；当月无日记 = 状态区「暂无日记」；失败 = error + 重试，保留上月网格
微标头
「日历月视图」识别名 + 计数 chip；导航按钮在月头行内（‹ ›），不占工具栏
三端收缩
侧栏 2 列降级（单列月网格、隐藏农历行）；手机降级为 M 尺寸月网格（隐藏非当月日期）
验收要点
六周网格行数恒定（既有冒烟）；今日跨日瞬间（00:00）今日圈正确迁移；日记点 ≤1/日不叠加；明暗采样 ≥ AA

iCal 日程 plain · M(6×2)，声明档位 M/W/L/X

moduleId / 声明档位
external-ical-events · sizes = [medium, wide, large, full]（availability: external）
内容布局（M 默认）
微标头（识别名 + 「未来 7 天 · N」chip）→ 日程行 ≤5（标题 + 本地时间），行 hairline 分隔
内容布局（W/L）
W：加来源日历标注；L：条目 ≤8 + 地点行；X：不适用（列表流通栏价值低）
状态呈现
loading 骨架；ready；empty（窗口内无日程）状态区文案；error + 重试 + 缓存旧值标注（stale 语义）
数据与隐私
RRULE/TZID/EXDATE 展开走 T-6460/T-6462 既有门禁；时间渲染本地时区；URL/凭据不入展示与摘要
三端收缩
三端一致（M）；侧栏同款；手机双列配置下占整行
验收要点
15 分钟刷新心跳沿用；展开上限有界（防 RRULE 爆炸）；跨时区日程显示源时区偏移标注
