生产档位对照（ADR 0101）：本卡的 S/M/L/X 仅为设计审查速记，产品语义以七档为准—— S→small · M→medium · L→large · X→full； 卡面出现的 tall/wide/xs 直接采用七档词。完整词汇：xs(2×3)/small(4×3)/medium(4×4)/tall(4×6)/wide(8×3)/large(8×5)/full(12×6)。

本批规格要点

  1. 材质：两者均 plain（数据密集型，阅读对比度优先；不使用彩色渐变）。
  2. 默认档位：GitHub 贡献 = large(8×5)；使用时长 = large(8×5)——均已在 HOME_TILE_DEFAULT_SIZES 登记（Slice 2），且都在各自 def.sizes 白名单内。
  3. 数据边界：GitHub 仅按用户配置的用户名请求公开 API；ActivityWatch 仅访问本机回环服务（127.0.0.1:5600），数据只在本机。两者失败均保留旧值 + stale 标注，不误报成功。
  4. 验收基线：色阶必须配文字图例；本机服务未运行 = blocked 占位（非 error）；明暗采样 ≥ AA。
