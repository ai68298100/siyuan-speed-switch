重构决策（对照设计审查 2026-09-27 的问题项）

  1. 主从结构：满屏密集卡片网格 → 左目录（400px）+ 右详情预览窗格。与切换器「结果列 + 预览」同构，复用 sw-platform-preview 原语；行内只留 图标 + 名称 + 一句描述 + 状态，信息噪音收敛。
  2. 每屏唯一主色（修复 G3）：「添加组件」主色胶囊只出现在详情窗格；列表行零按钮，已添加行仅显示 ✓。
  3. 徽标语义修正（修复 G6）：需要联网 / 完全离线 / 本机服务 / 隐私说明一律为中性能力 chip；六态徽标只表进行态与数据新鲜度。
  4. 筛选一条化：搜索框 + 单行来源 chips（带计数，沿用现有 tab 语义）；砍掉独立视图模式 / 密度分段；排序收入 chips 行尾菜单。
  5. 前置依赖显性（呼应 W4）：需安装组件行内 warn 色点 + 「需安装」徽标，详情窗格给完整前置说明。
  6. 异常态全覆盖（补审查缺口）：加载骨架 / 空搜索 / 目录失败重试 / 批量模式底栏，见屏②；移动端为列表 + 底部 sheet 详情，见屏③。
