生产档位对照（ADR 0101）：本卡的 S/M/L/X 仅为设计审查速记，产品语义以七档为准—— S→small · M→medium · L→large · X→full； 卡面出现的 tall/wide/xs 直接采用七档词。完整词汇：xs(2×3)/small(4×3)/medium(4×4)/tall(4×6)/wide(8×3)/large(8×5)/full(12×6)。

逐组件规格 共享列表型规范之上，仅列差异

最近打开 plain · wide

布局：行 ≤8（标题 + 打开时间）；点击打开文档。

差异：时间相对化（今天/昨天/日期）；已关闭与仍开分区沿用历史入口语义。

验收：跨日时间刷新；失效文档「已失效」不静默消失。

置顶文档 plain · medium

布局：行 ≤6（置顶顺序持久化）；置顶/取消置顶沿用卡片钉语义。

差异：置顶上限 64（既有容量）；顺序拖拽仅编辑布局态。

验收：取消置顶后列表即时重建；容量边界裁剪提示。

收藏 plain · medium

布局：组内行 ≤8（分组名 + 计数 chip）；点击打开，组管理在设置页。

差异：与切换器收藏同数据源（不复制数据）。

验收：分组变更即时同步；容量 512 上限沿用。

标签 plain · small

布局：标签胶囊云（名 + 计数），点击跳标签筛选。

差异：计数排序；上限首屏 ≤12。

验收：计数与真实命中一致；空标签不出现。

书签 plain · small

布局：书签行 ≤6（标题 + 块引用摘要 ≤1 行）。

差异：点击跳块级定位（定位失败回退打开文档）。

验收：块删除后降级为打开文档不报错。

文档集 plain · medium

布局：集行 ≤5（名称 + 篇数 + 更新时间）；动作 = 打开（受控恢复）。

差异：复用文档集恢复管线（预检/回执/可逆），组件内不做管理动作。

验收：恢复回执 restored/skipped/failed 语义沿用。

指定文档 plain · S

布局：单文档入口卡（图标 + 标题 + 打开）。

差异：文档删除 = 失效占位 + 重新指定指引。

验收：失效态不 crash 不空卡。

当前文档大纲 plain · wide/高

布局：标题树（层级缩进 ≤4 级）；点击滚动定位。

差异：仅当前活动文档；无活动文档 = 空态。

验收：大纲刷新防抖；点击定位不重排文档。

文档关系摘要 plain · medium

布局：反链/提及两组摘要（条数 chip + 条目 ≤3）。

差异：有界投影沿用（T-6814）；点击直达关系目标。

验收：无关系 = 空态；不泄露笔记正文。
