生产档位对照（ADR 0101）：本卡的 S/M/L/X 仅为设计审查速记，产品语义以七档为准—— S→small · M→medium · L→large · X→full； 卡面出现的 tall/wide/xs 直接采用七档词。完整词汇：xs(2×3)/small(4×3)/medium(4×4)/tall(4×6)/wide(8×3)/large(8×5)/full(12×6)。

时间与日期 dark · M(6×2)

内容布局（各档位）
S：星期 + 日期 + 农历（单行时刻）；M（默认）：加秒数与干支；L/X：不适用（该组件声明上限 M）
状态呈现
恒 ready（内核时间源，无网络）；无缓存语义
微标头
「时间与日期」识别名；无状态 chip
三端收缩
侧栏 S=1 列宽；手机 S=半宽；不提供 X
验收要点
数字 tabular-nums；秒数走 T-6935 局部补丁；明暗采样 ≥ AA

世界时钟 dark · X(12×3) 英雄位

内容布局（各档位）
X（默认）：日期行 + 56px 大时刻 + 秒 + 城市行（≤4 城，昼夜圆点）；M：时刻 + 城市摘要单行；L：双列城市（≤8 城）；S：仅本地时刻
状态呈现
恒 ready；城市数 chip；夏令时城市加 warning 色点
微标头
「世界时钟」；X 档置首行，每面板至多 1 个（Slice 3 约束强制）
三端收缩
侧栏降级 M（城市 ≤2）；手机 M（时刻 + 单城市摘要）；X 仅桌面
验收要点
昼夜圆点区分度不依赖颜色（加「昼/夜」文字 title）；离线城市表数据不外发

每日引言 dark · S(3×2)

内容布局（各档位）
S（默认）：引言 ≤3 行截断省略 + 作者；M：引言 + 日期角标；L/X：不适用

倒数日 accent · S(3×2)

S（默认）：大数字天数 + 目标名；M：加目标日期行；L：加里程碑列表（≤3 条）

负天数显示「已过 N 天」语义；双模式（倒数/正数）沿用既有配置
