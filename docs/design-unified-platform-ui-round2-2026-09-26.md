## 1. 参考系与提炼的应用模式

参考 Raycast / Linear（键盘优先、命令面板、设置搜索）、Things 3 / Craft（卡片层级、留白）、macOS System Settings（分段控件、行分组）、Vercel Geist / shadcn（状态徽标、中性色阶）。落到本插件的六条模式：

1. **键盘可见性**：快捷键以 `kbd` chip 形式出现在界面里（切换器上下文栏、结果行数字、对话框底部），而不是只藏在文档里（Raycast/Linear 惯例）。
2. **枚举设置分段化**：2~4 个互斥取值的设置用分段控件（segmented control）替代下拉，取值一眼可见、一次点击切换（macOS System Settings 模式）。
3. **设置行三元组**：每行 = 标题（13px 加重）+ 描述（12px muted，说明行为与副作用）+ 右侧控件；行按"组卡片"聚合（圆角 12 + 边框 + surface 底 + 组内 hairline 分隔 + hover 提亮）（Linear/Things 模式）。
4. **状态徽标语言**：ready/loading/stale/dirty/blocked/error 六态统一为"色点+文字"胶囊（复用 ADR 0079 状态语义），在预览窗格、组件卡、商店、片段实验室、设置页同一形态出现。
5. **层级靠边框+留白，不靠重阴影**：常态卡片 = 1px 边框 + 12px 圆角 + 无阴影或极浅阴影；hover 才浮起（translateY(-1px) + 软阴影）；只有浮层（菜单/面板/Dialog）用中强度阴影。
6. **主动作唯一且为主色胶囊**：每屏只有一个主色胶囊按钮（保存/添加/应用），次动作用 text/soft 胶囊。
