## 一、 评测目标与无诱导原则

本手册用于规范化检验新老用户在操作小驴雷切核心表面时的认知负荷、操作卡点与自愈恢复能力。

### 1. 核心底线纪律
1. **中性无诱导（Neutral Probing）**：
   - 主持人仅按任务卡宣读目标线索，**严禁提前演示功能入口、快捷键或专有术语**（如不得说“试试按 Alt+S”或“点击 Filter Chip”）；
   - 用户停顿犹豫时，仅提供中性提示：“你接下来想尝试什么？”或“请按你认为最自然的方式继续”。
2. **严守事实真相，拒绝虚假数据**：
   - 若当前会话无外部真人受试者参与，客观标注“**脚本与基准夹具就绪，真实外部反馈待补充**”，严禁将自动化测试或内部模拟推断伪造成真实用户访谈。
3. **零隐私泄漏**：
   - 评测在一次性隔离测试工作区进行，测试文档使用脱敏示例标题（如“练习项目 A”、“2026 交付规划草稿”），禁止记录任何系统私密路径、笔记正文或 Token。

## 二、 五条核心主路径任务卡 (U1 ~ U5)

### 任务 U1：切换器主路径 —— 极速找到并打开目标文档
- **参加者任务卡**：
  > “请在当前工作区找到并打开与‘**练习项目路线图**’有关的文档。请自己决定从哪里开始，完成后告诉我。”
- **预期认知路径**：
  呼出切换器（快捷键或顶栏图标） ➔ 查看已开页签或键盘输入关键词 ➔ 查看右侧 34% 预览窗格确认 ➔ 按 `Enter` 打开文档。
- **观察度量指标**：
  - 首次动作类型（鼠标点击 / 键盘热键）；
  - 从呼出到成功打开的相对耗时（秒）；
  - 是否被缩略图或多余边框干扰；
  - 误选非目标文档后的返回恢复能力。
- **完成判定**：成功将目标文档激活为主编辑视窗。

---

### 任务 U2：搜索主路径 —— 分层检索与无命中自愈
- **前置夹具准备**：在切换器预置一个限制在空范围内的 Filter Chip（如过滤某无匹配笔记本），同时目标文档可通过全文回退检索到。
- **参加者任务卡**：
  > “请找到与‘**季度复盘草稿**’有关的练习文档并打开。当前界面保留了一些已有条件，请从这里继续，按你认为合适的方式完成。”
- **预期认知路径**：
  输入查询 ➔ 发现当前“无匹配结果” ➔ 识别到顶部激活的筛选标签 ➔ 点击标签上的 `×` 或点击“全部”清空范围 ➔ 触发全库/已开文档全文检索 ➔ 打开目标。
- **观察度量指标**：
  - 发现无匹配到主动清除条件的延迟（秒）；
  - 是否能理解“当前无匹配”不等于“全库无此文档”；
  - 是否能发现并使用底部的思源原生搜索出口。
- **完成判定**：用户独立清空条件并打开目标文档，或明确指出下一步去原生搜索。

---

### 任务 U3：历史与收藏路径 —— 收藏、最近关闭恢复与清空确认
- **U3-A（收藏分支）**：
  > “这篇练习文档之后还会经常用到。请把它放到你认为适合以后快速找到的位置，关闭它，再把它重新打开。”
  - *观察重点*：是否发现收藏图标（☆）、能否理解收藏分组、再次打开是否顺畅。
- **U3-B（最近关闭分支）**：
  > “请关闭这篇练习文档，然后把刚才误关闭的那一篇重新打开。”
  - *观察重点*：能否在历史入口中清晰区分“仍打开”与“最近已关闭”两个不同语义分区。
- **完成判定**：成功将目标文档重新打开。

---

### 任务 U4：文档集路径 —— 工作区快照保存、缺失项跳过与整单恢复
- **前置夹具准备**：预置一个包含 3 篇文档的“项目写作现场”文档集，其中 1 篇文档被故意设为已删除（模拟 404 缺失项）。
- **参加者任务卡**：
  > “请把之前保存的‘**项目写作现场**’恢复到当前工作区；其中可能有项目当前不可用，请按你认为安全的方式处理。”
- **预期认知路径**：
  打开设置/快捷入口 ➔ 选择文档集 ➔ 触发恢复预检 ➔ 看到预览列表与 1 篇“缺失跳过”警示 ➔ 确认执行 ➔ 2 篇可用文档按序打开。
- **观察度量指标**：
  - 缺失项警示是否清晰易懂（是否引起恐慌）；
  - 恢复后是否产生重复页签。
- **完成判定**：可用文档成功恢复，缺失项被安全跳过。

---

### 任务 U5：片段实验室路径 —— 安全草稿编辑、差异比对与保存/放弃
- **U5-A（放弃修改分支）**：
  > “请在练习 CSS 片段上做一个小的字体颜色修改并查看预览，然后让这次修改不写入保存结果，回到可以继续工作的状态。”
  - *观察重点*：是否能理解“草稿未保存（Dirty）”提示、能否找到“比较差异”或安全放弃修改。
- **U5-B（安全保存分支）**：
  > “请在练习 CSS 片段上修改一个数值并保存，确认保存结果仍然可以找到并已生效。”
  - *观察重点*：保存按钮是否显眼、能否区分“保存草稿”与“启用片段”。
- **完成判定**：U5-A 原内容未被篡改；U5-B 保存成功且可通过回读确认。

## 三、 增量任务 U6：全新小组件看板与画廊商店走查 (2026-10-17 增量)

针对最新重构的第二面板（看板）与小组件画廊抽屉，增加专项评测观察点：

### 任务 U6-A：看板日常扫读与待办原地勾选
- **参加者任务卡**：
  > “请查看当前看板，告诉我当前的时间、天气以及有几项待办；然后直接在看板上将第一项待办标记为已完成。”
- **预期认知路径**：
  呼出第二面板 ➔ 0 干扰扫读 10:24 与 23° 晴 ➔ 视线落到待办卡片 ➔ 直接点击待办复选框打勾 ➔ 文字划线、计数即时响应。
- **观察重点**：
  - 是否感受到 36px 顶栏带来的视野开阔度；
  - 是否被多余的折叠箭头、齿轮或后台状态文字干扰；
  - 原地打勾交互是否跟手。

### 任务 U6-B：内嵌式画廊抽屉挑选与一键添加
- **参加者任务卡**：
  > “请为当前看板添加一个‘目标与里程碑倒数’小组件；完成后停下并告诉我。”
- **预期认知路径**：
  进入编排态 ➔ 点击“+ 添加小组件” ➔ 右侧滑出半透明画廊抽屉 ➔ 浏览 1:1 动态渲染预览 ➔ 点击“+ 添加到看板” ➔ 抽屉收起，新小组件平滑入场。
- **观察重点**：
  - 抽屉呼出动效是否自然；
  - 是否能理解 1:1 真实尺寸预览；
  - 添加到桌面后的正向反馈是否充分。

## 四、 标准量化记录表格 (Observation Sheet)

| 结果代码 | 语义定义 | 判定依据 |
| :---: | :--- | :--- |
| **`I`** | 独立完成 (Independent) | 0 外部功能提示，完全独立完成任务卡结束状态 |
| **`N`** | 中性提示后完成 (Neutral Prompt) | 仅接受了“你接下来想尝试什么”等中性引导后完成 |
| **`A`** | 直接协助后完成 (Assisted) | 主持人明确指出了入口或操作步骤后才完成 |
| **`P`** | 部分完成 (Partial) | 达到了部分目标，但未完成关键闭环 |
| **`F`** | 未完成 (Failed) | 超过 5 分钟软性上限或主动放弃 |
| **`NA`** | 条件不符未执行 (Not Applicable) | 环境缺少特定能力（如移动端测桌面特定特性） |
